## 071. 쌍둥이 소수

3과 5, 11과 13처럼 차이가 2인 소수의 쌍을 쌍둥이 소수라 합니다. 쌍둥이 소수가 무한히 많은지는 아직 풀리지 않은 문제입니다. 2013년 장이탕은 '차이가 7천만 이하인 소수 쌍은 무한히 많다'는 것을 증명해 수학계를 놀라게 했습니다.

**문제** `is_prime(n)` 함수를 정의하고 이를 이용해, 자연수 n 이하에서 두 수가 모두 n 이하인 쌍둥이 소수 쌍 (p, p+2)의 개수를 출력하십시오.

**제한** 1 ≤ n ≤ 10⁵

**예제 입력 1**

```
20
```

**예제 출력 1**

```
4
```

**예제 입력 2**

```
5
```

**예제 출력 2**

```
1
```

<details>
<summary>💡 힌트 보기</summary>

34번 문제의 소수 판별을 함수로 감싸고 `return True` / `return False`로 결과를 돌려주십시오. 그다음 p = 2부터 n − 2까지 `is_prime(p) and is_prime(p + 2)`를 세면 됩니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
def is_prime(n):
    if n < 2:
        return False
    i = 2
    while i * i <= n:
        if n % i == 0:
            return False
        i += 1
    return True

n = int(input())
print(sum(1 for p in range(2, n - 1) if is_prime(p) and is_prime(p + 2)))
```

함수 안의 `return`은 값을 돌려주는 동시에 함수를 즉시 끝냅니다. 그래서 34번의 `break`와 `else`가 필요 없어졌습니다. 한 번 잘 만든 함수는 이름만으로 쓸 수 있습니다. `is_prime(p) and is_prime(p + 2)`는 거의 수학 문장처럼 읽힙니다. **추상화**의 힘입니다. 20 이하의 쌍은 (3,5), (5,7), (11,13), (17,19) 네 쌍입니다. n이 수백만으로 커지면 101번에서 배울 에라토스테네스의 체가 필요합니다.

</details>

## 072. 매미의 주기

북아메리카의 주기 매미는 13년 또는 17년마다 한꺼번에 땅 위로 나옵니다. 주기가 소수인 덕분에 천적의 주기와 겹치는 일이 드물다는 가설이 있습니다. 13년 매미와 17년 매미가 함께 나오는 해는 최소공배수인 221년마다 한 번뿐입니다.

**문제** `gcd(a, b)`와 `lcm(a, b)` 함수를 직접 정의하십시오. 첫째 줄에 N, 둘째 줄에 N개의 자연수가 주어질 때 이들 모두의 최소공배수를 출력하십시오.

**제한** 1 ≤ N ≤ 100, 1 ≤ 각 수 ≤ 100

**예제 입력 1**

```
2
13 17
```

**예제 출력 1**

```
221
```

**예제 입력 2**

```
3
4 6 10
```

**예제 출력 2**

```
60
```

<details>
<summary>💡 힌트 보기</summary>

lcm(a, b) = a × b ÷ gcd(a, b)이고, 여러 수의 최소공배수는 lcm(lcm(a, b), c)처럼 앞에서부터 차례로 구합니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

def lcm(a, b):
    return a // gcd(a, b) * b

n = int(input())
result = 1
for x in map(int, input().split()):
    result = lcm(result, x)
print(result)
```

`a * b // gcd(a, b)` 대신 `a // gcd(a, b) * b`로 쓰면 중간값이 작아집니다. 파이썬에서는 상관없지만, 정수 크기가 제한된 언어에서는 오버플로를 막는 중요한 습관입니다. 1부터 100까지의 최소공배수는 무려 41자리 수입니다. 파이썬 3.9부터는 `math.lcm(*nums)`가 이 일을 한 번에 합니다.

</details>

## 073. 진법 변환기

컴퓨터는 2진법, 사람은 10진법, 프로그래머는 둘을 잇는 16진법을 즐겨 씁니다. 16진법 두 자리가 정확히 1바이트(8비트)이기 때문입니다.

**문제** 함수 `to_base(n, b)`를 정의하여, 0 이상의 정수 n을 b진법 문자열로 바꾸어 출력하십시오. 10 이상의 자리는 `A`~`F`로 나타냅니다.

**제한** 0 ≤ n ≤ 10¹⁸, 2 ≤ b ≤ 16

**예제 입력 1**

```
255 16
```

**예제 출력 1**

```
FF
```

**예제 입력 2**

```
10 2
```

**예제 출력 2**

```
1010
```

<details>
<summary>💡 힌트 보기</summary>

`n % b`가 맨 끝자리이고 `n // b`가 나머지 부분입니다. 끝자리부터 모은 뒤 뒤집으십시오. 자리 문자는 `"0123456789ABCDEF"[d]`로 얻을 수 있습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
DIGITS = "0123456789ABCDEF"

def to_base(n, b):
    if n == 0:
        return "0"
    out = []
    while n > 0:
        n, d = divmod(n, b)
        out.append(DIGITS[d])
    return "".join(reversed(out))

n, b = map(int, input().split())
print(to_base(n, b))
```

n = 0일 때 반복문이 한 번도 돌지 않아 빈 문자열이 되는 함정을 따로 처리했습니다. **경계값**을 먼저 의심하는 습관이 중요합니다. 11번 문제(초 → 시:분:초)와 같은 원리입니다. 파이썬에는 `bin()`, `oct()`, `hex()`가 있고, 거꾸로 b진법 문자열을 정수로 바꾸는 `int("FF", 16)`도 있습니다.

</details>

## 074. 요약 통계

파이썬 함수는 값 여러 개를 한꺼번에 돌려줄 수 있습니다. 사실은 튜플 하나를 돌려주는 것이고, 받는 쪽에서 그것을 풀어 담는 것입니다.

**문제** 함수 `summary(nums)`가 최솟값, 최댓값, 평균을 **한꺼번에 돌려주도록** 정의하십시오. 첫째 줄에 N, 둘째 줄에 N개의 정수가 주어질 때 `최솟값 최댓값 평균`을 출력하되 평균은 소수점 아래 둘째 자리까지 나타냅니다.

**제한** 1 ≤ N ≤ 1000, |각 수| ≤ 10⁶

**예제 입력**

```
4
3 -1 4 1
```

**예제 출력**

```
-1 4 1.75
```

<details>
<summary>💡 힌트 보기</summary>

`return min(nums), max(nums), sum(nums) / len(nums)`처럼 쉼표로 이어 쓰면 됩니다. 받을 때는 `lo, hi, avg = summary(nums)`.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
def summary(nums):
    return min(nums), max(nums), sum(nums) / len(nums)

n = int(input())
lo, hi, avg = summary(list(map(int, input().split())))
print(f"{lo} {hi} {avg:.2f}")
```

`return a, b, c`는 `return (a, b, c)`와 같습니다. 이것을 세 변수로 나누어 받는 **언패킹**은 7번 문제의 `a, b = map(...)`과 같은 원리입니다. 함수가 계산과 출력을 함께 하지 않고 **값만 돌려주게** 만들면 그 함수를 다른 곳에서도 다시 쓸 수 있습니다. 좋은 함수 설계의 첫 원칙입니다.

</details>

## 075. 룬 알고리즘

1954년 IBM의 연구원 한스 페터 룬이 고안한 검사법은 오늘날에도 신용카드 번호 등에서 숫자 하나를 잘못 입력한 오류를 잡아냅니다. 마지막 자리는 앞 숫자들로부터 계산된 **검사 숫자**입니다.

**문제** 숫자로만 된 문자열이 주어집니다. 아래 규칙에 따라 유효하면 `유효`, 아니면 `무효`를 출력하는 함수 `luhn(s)`를 만들어 쓰십시오.

1. 맨 오른쪽 자리부터 왼쪽으로 가며, 오른쪽에서 **두 번째, 네 번째, …** 자리의 숫자를 두 배로 합니다.
2. 두 배 한 값이 9보다 크면 9를 뺍니다.
3. 모든 자리의 합이 10의 배수이면 유효합니다.

**제한** 1 ≤ 길이 ≤ 100

**예제 입력 1**

```
79927398713
```

**예제 출력 1**

```
유효
```

**예제 입력 2**

```
79927398710
```

**예제 출력 2**

```
무효
```

<details>
<summary>💡 힌트 보기</summary>

문자열을 뒤집어 `enumerate()`로 돌리면, 인덱스가 홀수인 자리가 '두 배 할 자리'가 됩니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
def luhn(s):
    total = 0
    for i, ch in enumerate(reversed(s)):
        d = int(ch)
        if i % 2 == 1:
            d *= 2
            if d > 9:
                d -= 9
        total += d
    return total % 10 == 0

print("유효" if luhn(input()) else "무효")
```

`enumerate()`는 (인덱스, 원소) 쌍을 함께 내놓습니다. 그래서 '몇 번째 자리인가'를 따로 세지 않아도 됩니다. 두 배 한 값에서 9를 빼는 것은 그 값의 두 자릿수를 더하는 것과 같습니다(예: 16 → 1 + 6 = 7 = 16 − 9). 룬 알고리즘은 숫자 하나를 잘못 친 오류는 모두 잡아내고, 이웃한 두 숫자를 바꾸어 친 오류도 대부분 잡아냅니다(09 ↔ 90만은 놓칩니다). 함수가 `True`/`False`만 돌려주고 출력 문구는 바깥에서 정하도록 나눈 점에도 주목하십시오.

</details>
