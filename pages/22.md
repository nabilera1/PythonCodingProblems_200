## 106. 글 속의 숫자

1951년 수학자 스티븐 클레이니가 제안한 **정규 표현식**은 '숫자가 하나 이상 이어진 것'처럼 문자열의 패턴을 짧은 기호로 나타냅니다. 오늘날 거의 모든 프로그래밍 언어와 편집기에 들어 있습니다.

**문제** 영어 소문자와 숫자가 섞인 문자열에서, 연속된 숫자들을 하나의 수로 보아 모든 수의 합을 출력하십시오. 앞자리의 0은 무시합니다(`045`는 45).

**제한** 1 ≤ 길이 ≤ 10⁵

**예제 입력 1**

```
abc12de3f045
```

**예제 출력 1**

```
60
```

**예제 입력 2**

```
python
```

**예제 출력 2**

```
0
```

<details>
<summary>💡 힌트 보기</summary>

`re.findall(r"\d+", s)`는 연속된 숫자 덩어리를 모두 찾아 리스트로 돌려줍니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import re
print(sum(map(int, re.findall(r"\d+", input()))))
```

`\d`는 숫자 한 글자, `+`는 '하나 이상 반복'입니다. 패턴 문자열 앞의 `r`은 3번에서 배운 raw 문자열로, 역슬래시를 그대로 정규 표현식 엔진에 넘기기 위해 씁니다. 정규 표현식 없이 풀려면 현재 숫자를 누적하다가 숫자가 아닌 글자를 만나면 합에 더하고 0으로 되돌리면 됩니다. 이때도 49번처럼 **마지막 덩어리 처리**를 잊지 마십시오.

</details>

## 107. 파나마 운하

"A man, a plan, a canal: Panama!"는 공백과 문장부호, 대소문자를 무시하면 거꾸로 읽어도 같은 유명한 회문입니다. 파나마 운하 건설을 이끈 인물을 기리는 문장이라고 합니다.

**문제** 문장 한 줄이 주어집니다. 영문자와 숫자(그리고 한글)만 남기고 대소문자를 무시했을 때 회문이면 `회문`, 아니면 `회문 아님`을 출력하십시오.

**예제 입력 1**

```
A man, a plan, a canal: Panama!
```

**예제 출력 1**

```
회문
```

**예제 입력 2**

```
Hello, World
```

**예제 출력 2**

```
회문 아님
```

<details>
<summary>💡 힌트 보기</summary>

`[ch.lower() for ch in s if ch.isalnum()]`으로 걸러 낸 뒤 41번처럼 뒤집어서 비교하십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
t = [ch.lower() for ch in input() if ch.isalnum()]
print("회문" if t == t[::-1] else "회문 아님")
```

문자열을 새로 만들지 않고 투 포인터로 양 끝에서 안쪽으로 오며 비교할 수도 있습니다. 그러면 추가 메모리 없이 절반만 비교합니다. `isalnum()`은 한글도 문자로 인정합니다. 50번에서 함정이었던 성질이 여기서는 도움이 됩니다. '다시 합창합시다'는 우리말의 대표적인 회문 문장입니다.

</details>

## 108. 가장 긴 공통 접두사

자동 완성 기능은 사용자가 입력한 앞부분을 공유하는 단어들을 찾아 줍니다. 여러 단어가 함께 가진 가장 긴 앞부분, 곧 **공통 접두사**는 이런 기능의 기본 재료입니다.

**문제** 영어 소문자 단어들이 공백으로 구분되어 한 줄로 주어집니다. 모든 단어의 가장 긴 공통 접두사를 출력하고, 없으면 `없음`을 출력하십시오.

**제한** 단어 1개 이상 1000개 이하, 각 길이 ≤ 100

**예제 입력 1**

```
flower flow flight
```

**예제 출력 1**

```
fl
```

**예제 입력 2**

```
dog car race
```

**예제 출력 2**

```
없음
```

<details>
<summary>💡 힌트 보기</summary>

`zip(*words)`는 각 단어의 첫 글자끼리, 둘째 글자끼리 묶어 줍니다(82번). 묶음의 글자가 모두 같은 동안만 이어 가십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
words = input().split()
prefix = []
for chars in zip(*words):
    if len(set(chars)) != 1:
        break
    prefix.append(chars[0])
print("".join(prefix) or "없음")
```

`zip`은 가장 짧은 단어의 길이에서 멈추므로 인덱스 범위를 따로 걱정할 필요가 없습니다. `"".join(prefix) or "없음"`은 빈 문자열이 거짓으로 취급된다는 점을 이용한 관용구입니다. 다른 풀이로, 단어들을 정렬한 뒤 **첫 단어와 마지막 단어**의 공통 접두사만 구해도 됩니다. 사전 순서로 가장 멀리 떨어진 두 단어의 공통 부분이 곧 전체의 공통 부분이기 때문입니다.

</details>

## 109. 압축 풀기

49번에서 만든 런 길이 부호를 거꾸로 풀어 봅니다. 압축과 해제는 언제나 짝을 이루어야 합니다. 둘을 이어 붙였을 때 원래 데이터가 그대로 나오는지 확인하는 것이 압축 프로그램 시험의 기본입니다.

**문제** `글자 개수`가 반복되는 문자열(예: `a12b3`)이 주어질 때 원래 문자열을 출력하십시오. 개수는 여러 자리일 수 있습니다.

**제한** 글자는 영어 소문자, 1 ≤ 각 개수 ≤ 10⁴, 풀린 문자열의 길이 ≤ 10⁵

**예제 입력 1**

```
a3b1c2d4
```

**예제 출력 1**

```
aaabccdddd
```

**예제 입력 2**

```
x12y1
```

**예제 출력 2**

```
xxxxxxxxxxxxy
```

<details>
<summary>💡 힌트 보기</summary>

`re.findall(r"([a-z])(\d+)", s)`는 (글자, 개수) 쌍들을 돌려줍니다. 괄호로 묶은 부분이 따로 잡힙니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import re
s = input()
print("".join(ch * int(k) for ch, k in re.findall(r"([a-z])(\d+)", s)))
```

정규 표현식의 괄호는 **그룹**을 만듭니다. 그룹이 둘이면 `findall`은 튜플의 리스트를 돌려줍니다. `a2a2`처럼 같은 글자가 나뉘어 나와도 문제없이 `aaaa`가 됩니다. 49번의 압축기는 이런 출력을 만들지 않지만, 해제기는 너그러워야 합니다. '보낼 때는 엄격하게, 받을 때는 너그럽게'라는 포스텔의 원칙(1980)이 이것입니다.

</details>

## 110. 레일 펜스 암호

레일 펜스 암호는 글자를 여러 줄의 울타리에 지그재그로 적은 뒤 줄별로 이어 읽습니다. 글자 자체는 바꾸지 않고 순서만 뒤섞는 **전치 암호**의 대표입니다.

**문제** 첫째 줄에 레일 수 k, 둘째 줄에 평문이 주어집니다. 평문을 위에서 아래로, 다시 아래에서 위로 지그재그로 k개의 줄에 배치한 뒤, 맨 윗줄부터 차례로 이어 붙인 암호문을 출력하십시오.

**제한** 1 ≤ k ≤ 100, 평문은 공백 없는 영어 대문자 1000자 이하

**예제 입력**

```
3
WEAREDISCOVEREDFLEEATONCE
```

**예제 출력**

```
WECRLTEERDSOEEFEAOCAIVDEN
```

<details>
<summary>💡 힌트 보기</summary>

줄 번호 r을 0에서 시작해 보폭 +1로 움직이다가 맨 아래 줄(k−1)에 닿으면 보폭을 −1로 바꾸고, 맨 위에 닿으면 다시 +1로 바꾸십시오. k = 1이면 움직이지 않습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
k = int(input())
text = input()
rails = [[] for _ in range(k)]
r, step = 0, 1
for ch in text:
    rails[r].append(ch)
    if k > 1:
        if r == 0:
            step = 1
        elif r == k - 1:
            step = -1
        r += step
print("".join("".join(row) for row in rails))
```

`[[] for _ in range(k)]` 대신 `[[]] * k`로 쓰면 **같은 리스트 하나를 k번 가리키게 되어** 모든 줄에 같은 글자가 쌓입니다. 파이썬 초보자가 가장 자주 빠지는 함정 가운데 하나입니다. k = 1을 따로 처리하지 않으면 맨 위 줄과 맨 아래 줄이 같아서 보폭이 계속 바뀌다가 인덱스가 벗어납니다. 한계 사례를 먼저 생각하는 습관이 여기서도 필요합니다. 복호화도 같은 지그재그 규칙으로 각 줄의 길이를 먼저 계산하면 할 수 있습니다. 도전해 보십시오.

</details>
