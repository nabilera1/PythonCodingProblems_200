## 166. 군도

그래프 탐색의 첫걸음은 격자 위의 '덩어리 세기'입니다. 한 칸에서 출발해 이어진 칸들을 모두 방문하면 덩어리 하나가 끝납니다. 아직 방문하지 않은 땅이 남아 있으면 그곳에서 새 덩어리가 시작됩니다.

**문제** R×C 지도에서 `#`은 땅, `.`은 바다입니다. 상하좌우로 이어진 땅을 하나의 섬으로 볼 때, 섬의 개수와 가장 큰 섬의 넓이(칸 수)를 공백으로 구분해 출력하십시오. 섬이 없으면 `0 0`을 출력합니다.

**입력** 첫째 줄에 R과 C, 이어서 R줄에 지도가 주어집니다.

**출력** 섬의 개수와 가장 큰 섬의 넓이를 출력합니다.

**제한** 1 ≤ R, C ≤ 700, 시간 제한 3초

**예제 입력**

```
4 5
##..#
#...#
..#..
.###.
```

**예제 출력**

```
3 4
```

<details>
<summary>💡 힌트 보기</summary>

방문 표시 배열을 두고, 방문하지 않은 땅을 만나면 BFS로 그 섬의 모든 칸을 방문하면서 넓이를 세십시오. 파이썬에서는 재귀 DFS보다 `deque`를 쓴 BFS가 안전합니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
from collections import deque
input = sys.stdin.readline
r, c = map(int, input().split())
g = [bytearray(input().rstrip(), 'ascii') for _ in range(r)]
LAND = ord('#')
count = best = 0
for i in range(r):
    row = g[i]
    for j in range(c):
        if row[j] != LAND:
            continue
        count += 1
        row[j] = 0
        q = deque([(i, j)])
        size = 0
        while q:
            x, y = q.popleft()
            size += 1
            for nx, ny in ((x + 1, y), (x - 1, y), (x, y + 1), (x, y - 1)):
                if 0 <= nx < r and 0 <= ny < c and g[nx][ny] == LAND:
                    g[nx][ny] = 0
                    q.append((nx, ny))
        best = max(best, size)
print(count, best)
```

큐에 **넣을 때** 방문 표시를 해야 같은 칸이 여러 번 큐에 들어가지 않습니다. 꺼낼 때 표시하면 칸이 중복으로 들어가 시간과 메모리가 폭증합니다. 가장 흔한 BFS 실수입니다. 지도 자체를 `bytearray`로 바꾸어 방문한 땅을 0으로 덮어쓰면 별도의 방문 배열이 필요 없습니다. 700×700이 모두 땅인 숨은 테스트에서 재귀 DFS를 쓰면 깊이가 49만에 이르러 파이썬이 멈춥니다. 그래서 반복문으로 된 BFS가 안전합니다. 완전 탐색 검증용 풀이는 같은 문제를 유니온 파인드라는 전혀 다른 방법으로 풉니다.

</details>

## 167. 미로의 최단 경로

BFS는 시작점에서 가까운 칸부터 차례로 방문합니다. 그래서 모든 이동의 비용이 같다면, 어떤 칸을 **처음 방문한 순간**의 거리가 곧 최단 거리입니다. 1959년 에드워드 무어가 미로 문제를 연구하며 이 방법을 정리했습니다.

**문제** R×C 미로에서 `.`은 길, `#`은 벽입니다. 왼쪽 위에서 오른쪽 아래까지 상하좌우로 한 칸씩 움직일 때 최소 이동 횟수를 구하십시오. 갈 수 없으면 −1을 출력합니다.

**입력** 첫째 줄에 R과 C, 이어서 R줄에 미로가 주어집니다.

**출력** 최소 이동 횟수를 출력합니다.

**제한** 1 ≤ R, C ≤ 700, 시작 칸과 도착 칸은 `.`, 시간 제한 3초

**예제 입력 1**

```
4 6
..#...
.##.#.
....#.
##....
```

**예제 출력 1**

```
8
```

**예제 입력 2**

```
2 2
.#
#.
```

**예제 출력 2**

```
-1
```

<details>
<summary>💡 힌트 보기</summary>

거리 배열을 −1로 채우고 시작 칸을 0으로 둔 뒤 BFS를 하십시오. 이웃 칸의 거리는 현재 칸의 거리 + 1입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
from collections import deque
input = sys.stdin.readline
r, c = map(int, input().split())
g = [input().rstrip() for _ in range(r)]
dist = [[-1] * c for _ in range(r)]
dist[0][0] = 0
q = deque([(0, 0)])
while q:
    x, y = q.popleft()
    d = dist[x][y] + 1
    for nx, ny in ((x + 1, y), (x - 1, y), (x, y + 1), (x, y - 1)):
        if 0 <= nx < r and 0 <= ny < c and dist[nx][ny] < 0 and g[nx][ny] == '.':
            dist[nx][ny] = d
            q.append((nx, ny))
print(dist[r - 1][c - 1])
```

BFS의 큐에는 언제나 거리가 d인 칸들 뒤에 거리가 d+1인 칸들이 놓입니다. 이 '층별' 성질 덕분에 처음 방문한 거리가 최단 거리임이 보장됩니다. 마지막 숨은 테스트는 지그재그 통로로 된 미로로, 경로 길이가 25만에 가깝습니다. 재귀 DFS로 최단 거리를 구하려 하면 시간도 깊이도 감당할 수 없습니다. 최단 거리는 BFS의 일입니다. 완전 탐색 검증용 풀이는 거리가 더 이상 줄지 않을 때까지 모든 칸을 반복 갱신하는 단순한 방법입니다.

</details>

## 168. 두 팀으로 나누기

사이가 나쁜 사람끼리는 같은 팀이 될 수 없다는 조건으로 모두를 두 팀으로 나눌 수 있을까요? 그래프로 말하면 **이분 그래프** 판정입니다. 한 사람을 빨강으로 칠하고, 이웃은 파랑, 그 이웃은 빨강…으로 칠해 나가다 충돌이 나면 불가능합니다.

**문제** N명의 사람과 '사이가 나쁜' 관계 M개가 주어집니다. 사이가 나쁜 두 사람이 같은 팀이 되지 않도록 모두를 두 팀으로 나눌 수 있으면 `YES`, 아니면 `NO`를 출력하십시오. 그래프는 연결되어 있지 않을 수 있습니다.

**입력** 첫째 줄에 N과 M, 이어서 M줄에 두 사람의 번호가 주어집니다(1부터).

**출력** `YES` 또는 `NO`를 출력합니다.

**제한** 1 ≤ N ≤ 10⁵, 0 ≤ M ≤ 2×10⁵, 자기 자신과의 관계는 없음, 시간 제한 3초

**예제 입력 1**

```
4 4
1 2
2 3
3 4
4 1
```

**예제 출력 1**

```
YES
```

**예제 입력 2**

```
3 3
1 2
2 3
3 1
```

**예제 출력 2**

```
NO
```

<details>
<summary>💡 힌트 보기</summary>

색 배열을 0(미정)으로 두고, 색이 정해지지 않은 사람마다 BFS를 시작하십시오. 이웃의 색이 미정이면 반대 색을 칠하고, 이미 같은 색이면 실패입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
from collections import deque
data = sys.stdin.buffer.read().split()
n, m = int(data[0]), int(data[1])
adj = [[] for _ in range(n + 1)]
for i in range(m):
    a, b = int(data[2 + 2 * i]), int(data[3 + 2 * i])
    adj[a].append(b)
    adj[b].append(a)
color = [0] * (n + 1)
ok = True
for s in range(1, n + 1):
    if color[s] or not ok:
        continue
    color[s] = 1
    q = deque([s])
    while q and ok:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == 0:
                color[v] = -color[u]
                q.append(v)
            elif color[v] == color[u]:
                ok = False
                break
print('YES' if ok else 'NO')
```

그래프가 이분 그래프일 필요충분조건은 **홀수 길이의 사이클이 없는 것**입니다. 예제 2의 삼각형이 가장 작은 홀수 사이클입니다. 연결되지 않은 그래프에서는 덩어리마다 따로 칠해야 하므로 모든 정점에서 BFS 시작을 시도했습니다. 첫 정점에서만 시작하면 다른 덩어리의 충돌을 놓칩니다. 색을 1과 −1로 두면 반대 색이 `-color[u]` 한 번으로 끝납니다. 작은 요령이지만 코드가 깔끔해집니다.

</details>

## 169. 수강 순서

선수 과목이 있는 교육과정에서 과목을 듣는 순서를 정하는 것은 **위상 정렬**입니다. 1962년 칸이 제안한 방법은 '선수 과목이 모두 끝난(진입 차수가 0인) 과목을 하나씩 꺼내는' 것입니다. 여러 과목이 동시에 가능할 때 번호가 작은 것부터 고르면 순서가 하나로 정해집니다.

**문제** N개의 과목과 M개의 선수 관계 `a b`(a를 들어야 b를 들을 수 있음)가 주어집니다. 모든 과목을 듣는 순서 가운데 **사전 순으로 가장 앞서는** 순서를 출력하십시오. 순환이 있어 불가능하면 −1을 출력합니다.

**입력** 첫째 줄에 N과 M, 이어서 M줄에 a와 b가 주어집니다.

**출력** 과목 번호를 순서대로 한 줄에 출력하거나 −1을 출력합니다.

**제한** 1 ≤ N ≤ 10⁵, 0 ≤ M ≤ 2×10⁵, 시간 제한 3초

**예제 입력 1**

```
4 3
4 2
3 1
2 1
```

**예제 출력 1**

```
3 4 2 1
```

**예제 입력 2**

```
3 3
1 2
2 3
3 1
```

**예제 출력 2**

```
-1
```

<details>
<summary>💡 힌트 보기</summary>

진입 차수가 0인 과목들을 최소 힙에 넣고, 가장 작은 번호를 꺼내 출력한 뒤 그 과목에서 나가는 간선을 지우십시오. 새로 진입 차수가 0이 된 과목을 힙에 넣습니다. 꺼낸 과목이 N개보다 적으면 순환이 있는 것입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys, heapq
data = sys.stdin.buffer.read().split()
n, m = int(data[0]), int(data[1])
adj = [[] for _ in range(n + 1)]
indeg = [0] * (n + 1)
for i in range(m):
    a, b = int(data[2 + 2 * i]), int(data[3 + 2 * i])
    adj[a].append(b)
    indeg[b] += 1
heap = [v for v in range(1, n + 1) if indeg[v] == 0]
heapq.heapify(heap)
order = []
while heap:
    u = heapq.heappop(heap)
    order.append(u)
    for v in adj[u]:
        indeg[v] -= 1
        if indeg[v] == 0:
            heapq.heappush(heap, v)
print(*order) if len(order) == n else print(-1)
```

힙 대신 보통의 큐를 쓰면 올바른 위상 순서는 나오지만 '사전 순으로 가장 앞서는' 순서는 보장되지 않습니다. 여러 후보 가운데 가장 작은 것을 고르는 일을 힙이 O(log N)에 해 줍니다. 완전 탐색 검증용 풀이는 사전 순서대로 모든 순열을 만들어 처음으로 조건을 만족하는 것을 고릅니다. 그 결과가 힙 방식과 항상 같다는 것이 이 그리디의 정당성을 보여 줍니다. 자기 자신으로 가는 간선 `a a`도 순환이므로 −1이 되어야 합니다. 무작위 검증에는 이런 입력도 섞여 있습니다.

</details>

## 170. 산불과 탈출

불은 매분 사방으로 번지고, 사람은 매분 한 칸씩 움직입니다. 두 BFS를 따로 돌린 뒤 비교하는 것이 요령입니다. 먼저 모든 칸에 '불이 도착하는 시각'을 기록해 두면, 사람은 불보다 **먼저** 도착할 수 있는 칸으로만 가면 됩니다.

**문제** R×C 숲에서 `#`은 바위, `.`은 빈 땅, `J`는 사람(한 명), `F`는 불(여러 곳 또는 없음)입니다. 매분 사람은 상하좌우로 한 칸 움직이고(머무를 수 없음), 동시에 불은 상하좌우의 빈 땅으로 번집니다. 바위로는 사람도 불도 갈 수 없습니다. 사람은 불이 붙어 있거나 **그 분에 불이 번지는** 칸으로 갈 수 없습니다. 가장자리 칸에서 숲 밖으로 나가는 데에도 1분이 걸립니다. 탈출에 걸리는 최소 시간을, 불가능하면 `IMPOSSIBLE`을 출력하십시오.

**입력** 첫째 줄에 R과 C, 이어서 R줄에 숲이 주어집니다.

**출력** 최소 탈출 시간 또는 `IMPOSSIBLE`을 출력합니다.

**제한** 1 ≤ R, C ≤ 700, 시간 제한 4초

**예제 입력 1**

```
4 4
####
#JF#
#..#
#..#
```

**예제 출력 1**

```
3
```

**예제 입력 2**

```
3 3
###
#J#
###
```

**예제 출력 2**

```
IMPOSSIBLE
```

<details>
<summary>💡 힌트 보기</summary>

① 모든 불에서 동시에 시작하는 BFS로 칸마다 불이 도착하는 시각 fire[x][y]를 구합니다(다중 시작점 BFS). ② 사람의 BFS에서 시각 t+1에 칸 (x, y)로 가려면 t+1 < fire[x][y]여야 합니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
from collections import deque
input = sys.stdin.readline
r, c = map(int, input().split())
g = [input().rstrip() for _ in range(r)]
INF = 1 << 30
fire = [[INF] * c for _ in range(r)]
q = deque()
for i in range(r):
    for j in range(c):
        if g[i][j] == 'F':
            fire[i][j] = 0
            q.append((i, j))
        elif g[i][j] == 'J':
            start = (i, j)
while q:
    x, y = q.popleft()
    t = fire[x][y] + 1
    for nx, ny in ((x + 1, y), (x - 1, y), (x, y + 1), (x, y - 1)):
        if 0 <= nx < r and 0 <= ny < c and fire[nx][ny] == INF and g[nx][ny] != '#':
            fire[nx][ny] = t
            q.append((nx, ny))
dist = [[-1] * c for _ in range(r)]
sx, sy = start
dist[sx][sy] = 0
q = deque([start])
answer = 'IMPOSSIBLE'
while q:
    x, y = q.popleft()
    t = dist[x][y] + 1
    if x == 0 or y == 0 or x == r - 1 or y == c - 1:
        answer = t
        break
    for nx, ny in ((x + 1, y), (x - 1, y), (x, y + 1), (x, y - 1)):
        if dist[nx][ny] < 0 and g[nx][ny] == '.' and t < fire[nx][ny]:
            dist[nx][ny] = t
            q.append((nx, ny))
print(answer)
```

'그 분에 불이 번지는 칸으로 갈 수 없다'는 규칙이 `t < fire[nx][ny]`의 **엄격한 부등호**로 옮겨졌습니다. `<=`로 쓰면 불과 같은 순간에 도착하는 칸으로 들어가게 되어 오답이 됩니다. 가장자리 칸에 도착한 사람은 1분 뒤 밖으로 나가므로, 가장자리 칸을 큐에서 꺼낼 때 `거리 + 1`이 답입니다. BFS는 거리 순으로 꺼내므로 처음 꺼낸 가장자리 칸이 최단입니다. 완전 탐색 검증용 풀이는 매분 불과 사람의 상태를 집합으로 직접 시뮬레이션합니다. 규칙을 문장 그대로 옮긴 이런 시뮬레이션과 두 BFS의 결과가 일치해야 비로소 규칙 해석이 옳다고 확신할 수 있습니다.

</details>
