## 066. 단어의 빈도

1935년 언어학자 지프는 어느 언어든 가장 흔한 단어가 두 번째로 흔한 단어보다 약 두 배, 세 번째보다 약 세 배 자주 쓰인다는 경험 법칙을 발견했습니다. 이 '지프의 법칙'도 단어마다 횟수를 세는 일에서 시작됩니다.

**문제** 영어 소문자 단어들이 공백으로 구분되어 한 줄로 주어집니다. 각 단어의 등장 횟수를 **횟수가 많은 순서로**, 같으면 단어의 사전 순서로, 한 줄에 하나씩 `단어 횟수` 형식으로 출력하십시오.

**예제 입력**

```
the cat and the hat and the bat
```

**예제 출력**

```
the 3
and 2
bat 1
cat 1
hat 1
```

<details>
<summary>💡 힌트 보기</summary>

딕셔너리 `count`에서 `count[w] = count.get(w, 0) + 1`로 셉니다. 정렬할 때는 58번처럼 `(-횟수, 단어)`를 기준으로 삼으십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
count = {}
for w in input().split():
    count[w] = count.get(w, 0) + 1
for neg, w in sorted((-c, w) for w, c in count.items()):
    print(w, -neg)
```

`get(키, 기본값)`은 키가 없을 때 오류 대신 기본값을 돌려줍니다. 처음 보는 단어도 0에서 세기 시작할 수 있는 이유입니다. `items()`는 (키, 값) 쌍들을 돌려줍니다. 같은 일을 `collections.Counter`가 한 줄로 해 줍니다. 91번에서 다룹니다.

</details>

## 067. 전화번호부

종이 전화번호부는 이름순으로 정렬되어 있어 반씩 펼쳐 가며 찾을 수 있었습니다. 딕셔너리는 그보다도 빠릅니다. 이름을 해시로 바꾸어 곧바로 해당 칸을 찾아가기 때문입니다.

**문제** 첫째 줄에 N, 이어서 N줄에 `이름 번호`가 주어집니다. 다음 줄에 질의 수 Q, 이어서 Q줄에 이름이 주어집니다. 각 질의마다 번호를 출력하되, 없는 이름이면 `없음`을 출력하십시오. 같은 이름이 두 번 등록되면 **나중 번호**가 유효합니다.

**제한** 1 ≤ N, Q ≤ 10⁵

**예제 입력**

```
3
kim 010-0000-1111
lee 010-0000-2222
kim 010-0000-3333
3
kim
park
lee
```

**예제 출력**

```
010-0000-3333
없음
010-0000-2222
```

<details>
<summary>💡 힌트 보기</summary>

딕셔너리에 `book[이름] = 번호`로 넣으면 같은 이름은 덮어쓰입니다. 찾을 때는 `book.get(이름, "없음")`.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
input = sys.stdin.readline
n = int(input())
book = {}
for _ in range(n):
    name, number = input().split()
    book[name] = number
q = int(input())
print("\n".join(book.get(input().rstrip(), "없음") for _ in range(q)))
```

`sys.stdin.readline`으로 읽은 줄은 끝에 줄바꿈 문자가 붙어 있습니다. 그래서 이름만 읽을 때는 `.rstrip()`이 필요합니다. 이것을 빠뜨리면 `"kim\n"`을 찾게 되어 모두 `없음`이 나옵니다. 제3부에서 가장 흔한 실수입니다. 번호를 정수로 바꾸지 않는 것도 중요합니다. 맨 앞의 0이 사라지기 때문입니다. 전화번호, 우편번호, 학번처럼 **셈을 하지 않는 숫자**는 문자열로 다루는 것이 원칙입니다.

</details>

## 068. 모스 부호

1844년 새뮤얼 모스는 워싱턴에서 볼티모어로 "What hath God wrought"(하나님이 무엇을 이루셨는가)라는 성경 구절을 전신으로 보냈습니다. 점과 선 두 가지만으로 모든 글자를 나타내는 모스 부호의 시작이었습니다.

**문제** 영어 대문자와 공백으로 된 문장을 국제 모스 부호로 바꾸어 출력하십시오. 글자 사이는 공백 하나, 단어 사이는 ` / `(공백-빗금-공백)로 구분합니다. A부터 Z까지의 부호는 다음과 같습니다(복사해서 쓰십시오).

```
.- -... -.-. -.. . ..-. --. .... .. .--- -.- .-.. -- -. --- .--. --.- .-. ... - ..- ...- .-- -..- -.-- --..
```

**예제 입력 1**

```
SOS
```

**예제 출력 1**

```
... --- ...
```

**예제 입력 2**

```
HELLO WORLD
```

**예제 출력 2**

```
.... . .-.. .-.. --- / .-- --- .-. .-.. -..
```

<details>
<summary>💡 힌트 보기</summary>

`dict(zip("ABCDEFGHIJKLMNOPQRSTUVWXYZ", 부호문자열.split()))`로 표를 만들 수 있습니다. 단어마다 변환한 뒤 `" / ".join()`으로 이으십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
CODES = ".- -... -.-. -.. . ..-. --. .... .. .--- -.- .-.. -- -. --- .--. --.- .-. ... - ..- ...- .-- -..- -.-- --..".split()
MORSE = dict(zip("ABCDEFGHIJKLMNOPQRSTUVWXYZ", CODES))
words = input().split()
print(" / ".join(" ".join(MORSE[ch] for ch in w) for w in words))
```

`zip`은 두 순서열을 지퍼처럼 맞물려 쌍을 만들고, `dict()`는 그 쌍들로 딕셔너리를 만듭니다. 26줄짜리 딕셔너리를 손으로 쓰지 않아도 됩니다. 모스 부호는 영어에서 자주 쓰이는 글자에 짧은 부호를 주었습니다(E는 점 하나, T는 선 하나). 나중에 배울 허프만 부호화와 같은 발상입니다.

</details>

## 069. 아나그램 모임

글자의 순서만 바꾸어 다른 단어를 만드는 것을 아나그램이라 합니다. listen과 silent, evil과 live가 그렇습니다. 두 단어가 아나그램인지는 글자를 정렬해 보면 단번에 알 수 있습니다.

**문제** 첫째 줄에 N, 둘째 줄에 N개의 영어 소문자 단어가 주어집니다. 서로 아나그램인 단어끼리 한 모임으로 묶을 때, **모임의 수**와 **가장 큰 모임의 크기**를 공백으로 구분해 출력하십시오. (같은 단어가 두 번 나오면 같은 모임에 두 번 들어갑니다.)

**제한** 1 ≤ N ≤ 10⁵, 단어 길이 ≤ 10

**예제 입력**

```
6
listen silent evil live vile enlist
```

**예제 출력**

```
2 3
```

<details>
<summary>💡 힌트 보기</summary>

`"".join(sorted(단어))`를 딕셔너리의 키로 삼아 개수를 세십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
groups = {}
for w in input().split():
    key = "".join(sorted(w))
    groups[key] = groups.get(key, 0) + 1
print(len(groups), max(groups.values()))
```

정렬된 글자열은 아나그램 모임마다 하나뿐인 **대표값(정규형)** 입니다. 여러 대상을 묶어야 할 때 '같은 모임이면 같아지는 값'을 찾아 딕셔너리 키로 삼는 기법은 매우 널리 쓰입니다. `sorted("listen")`은 글자 리스트 `['e', 'i', 'l', 'n', 's', 't']`를 돌려주므로, 키로 쓰려면 `join`으로 다시 문자열로 만들어야 합니다(리스트는 키가 될 수 없습니다).

</details>

## 070. 학생별 평균

성적 처리 프로그램은 '학생 → 점수 목록' 형태의 자료를 다룹니다. 딕셔너리의 값으로 리스트를 두면 이런 일대다 관계를 자연스럽게 담을 수 있습니다.

**문제** 첫째 줄에 N, 이어서 N줄에 `이름 과목 점수`가 주어집니다. 학생 이름의 사전 순서로, 각 학생의 평균 점수를 소수점 아래 첫째 자리까지 `이름 평균` 형식으로 출력하십시오.

**제한** 1 ≤ N ≤ 1000, 0 ≤ 점수 ≤ 100, 한 학생의 과목 수는 3개 이하

**예제 입력**

```
5
kim math 90
lee math 85
kim eng 81
lee eng 70
kim sci 100
```

**예제 출력**

```
kim 90.3
lee 77.5
```

<details>
<summary>💡 힌트 보기</summary>

`scores.setdefault(이름, []).append(점수)`를 쓰면 처음 보는 이름에 빈 리스트를 만들어 주면서 곧바로 점수를 추가할 수 있습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
scores = {}
for _ in range(n):
    name, subject, score = input().split()
    scores.setdefault(name, []).append(int(score))
for name in sorted(scores):
    s = scores[name]
    print(f"{name} {sum(s) / len(s):.1f}")
```

`setdefault`는 키가 없으면 기본값을 넣고, 있으면 기존 값을 돌려줍니다. `collections.defaultdict(list)`를 쓰면 `scores[name].append(...)`만으로 같은 일을 할 수 있습니다. 딕셔너리를 `sorted()`에 넣으면 키들이 정렬되어 나옵니다. 딕셔너리 자체는 파이썬 3.7부터 **넣은 순서**를 기억합니다.

</details>
