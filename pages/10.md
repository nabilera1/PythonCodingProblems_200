## 046. 카이사르의 편지

로마의 역사가 수에토니우스에 따르면, 율리우스 카이사르는 기밀 서신을 쓸 때 알파벳을 세 자리씩 밀어 적었다고 합니다. A는 D가 되고, X는 다시 처음으로 돌아가 A가 됩니다.

**문제** 첫째 줄에 정수 k, 둘째 줄에 영어 문장이 주어집니다. 알파벳을 k칸 밀어 암호화한 문장을 출력하십시오. 대문자는 대문자로, 소문자는 소문자로 두고, 알파벳이 아닌 글자는 그대로 둡니다. k가 음수이면 거꾸로 밉니다.

**제한** −25 ≤ k ≤ 25

**예제 입력 1**

```
3
Veni, vidi, vici.
```

**예제 출력 1**

```
Yhql, ylgl, ylfl.
```

**예제 입력 2**

```
-3
Yhql, ylgl, ylfl.
```

**예제 출력 2**

```
Veni, vidi, vici.
```

<details>
<summary>💡 힌트 보기</summary>

`ord()`는 글자를 번호로, `chr()`은 번호를 글자로 바꿉니다. 'a'를 0번으로 맞춘 뒤 k를 더하고 `% 26`을 하면, 끝에서 처음으로 돌아가는 것을 자연스럽게 처리할 수 있습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
k = int(input())
s = input()
result = []
for ch in s:
    if "a" <= ch <= "z":
        result.append(chr((ord(ch) - ord("a") + k) % 26 + ord("a")))
    elif "A" <= ch <= "Z":
        result.append(chr((ord(ch) - ord("A") + k) % 26 + ord("A")))
    else:
        result.append(ch)
print("".join(result))
```

`% 26`은 음수에도 0~25를 돌려주므로 k가 음수여도 같은 식이 통합니다. 23번 문제에서 본 순환과 같은 원리입니다. 문자열에 `+=`로 한 글자씩 붙이면 매번 새 문자열이 만들어집니다. 그래서 리스트에 모은 뒤 `"".join()`으로 한 번에 잇는 것이 파이썬의 관용구입니다. k = 13은 ROT13이라 불리며, 두 번 적용하면 원문으로 돌아옵니다.

</details>

## 047. 어순 뒤집기

영어 문장은 대개 '주어-동사-목적어' 순서를 따르지만, 언어학자들의 조사에 따르면 세계 언어의 상당수, 한국어를 포함해, '주어-목적어-동사' 순서를 따릅니다. 어순은 언어마다 다른 약속일 뿐입니다.

**문제** 영어 문장 한 줄이 주어질 때 **단어의 순서**를 거꾸로 뒤집어 출력하십시오. 단어 사이는 공백 하나로 출력합니다.

**예제 입력 1**

```
the quick brown fox
```

**예제 출력 1**

```
fox brown quick the
```

**예제 입력 2**

```
hello
```

**예제 출력 2**

```
hello
```

<details>
<summary>💡 힌트 보기</summary>

`split()`으로 단어 리스트를 만들고, 뒤집은 뒤 `" ".join()`으로 다시 이으십시오.

</details>

<details>

print(" ".join(input().split()[::-1]))

`split()`과 `join()`은 서로 반대되는 연산입니다. 쪼개고, 가공하고, 다시 잇는 이 세 단계는 문자열 처리에서 가장 흔한 흐름입니다. `reversed()`를 써서 `" ".join(reversed(words))`라고 해도 됩니다. 문자열 전체를 뒤집는 `s[::-1]`과는 결과가 다르다는 점에 주의하십시오.

## 048. 가지런한 영수증

숫자가 섞인 표는 오른쪽 정렬을 해야 자릿수가 세로로 맞아 한눈에 읽힙니다. 회계 장부가 수백 년 동안 지켜 온 원칙입니다.

**문제** 첫째 줄에 품목 수 N, 이어서 N줄에 `품목명 단가 수량`이 주어집니다. 품목마다 `품목명`을 폭 10으로 왼쪽 정렬하고, `단가×수량`을 폭 10으로 오른쪽 정렬하되 세 자리마다 쉼표를 넣어 출력하십시오. 그 뒤에 `-`를 20개 출력하고, 마지막 줄에 `TOTAL`과 합계를 같은 형식으로 출력하십시오.

**제한** 1 ≤ N ≤ 20, 품목명은 10자 이하의 영어, 1 ≤ 단가 ≤ 10⁶, 1 ≤ 수량 ≤ 100

**예제 입력**

```
3
apple 1200 3
milk 2500 1
bread 4800 2
```

**예제 출력**

```
apple          3,600
milk           2,500
bread          9,600
--------------------
TOTAL         15,700
```

<details>
<summary>💡 힌트 보기</summary>

서식 지정자 `:<10`은 왼쪽 정렬, `:>10,`은 오른쪽 정렬과 천 단위 쉼표입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
total = 0
for _ in range(n):
    name, price, qty = input().split()
    amount = int(price) * int(qty)
    total += amount
    print(f"{name:<10}{amount:>10,}")
print("-" * 20)
print(f"{'TOTAL':<10}{total:>10,}")
```

서식 지정은 `[채움][정렬][폭][,][.정밀도][형식]` 순서로 씁니다. 예를 들어 `f"{x:*^12,.2f}"`는 별표로 채우고, 가운데 정렬하고, 폭 12에 쉼표를 넣고, 소수 둘째 자리까지 나타냅니다. f-string 안에 따옴표가 필요하면 바깥 따옴표와 다른 종류를 쓰십시오(파이썬 3.12부터는 같은 종류도 허용됩니다).

</details>

## 049. 런 길이 부호화

팩스는 문서를 흑백 점으로 읽어 보냅니다. 흰 점이 수백 개씩 이어지는 일이 흔하기 때문에 '흰 점 300개'처럼 **같은 것이 몇 번 이어지는지**만 적어 보내면 훨씬 짧아집니다. 이 압축법을 런 길이 부호화(RLE)라 합니다.

**문제** 영어 소문자로 된 문자열이 주어질 때, 같은 글자가 이어지는 구간마다 `글자+개수`로 바꾸어 출력하십시오.

**제한** 1 ≤ 길이 ≤ 10⁵

**예제 입력 1**

```
aaabccdddd
```

**예제 출력 1**

```
a3b1c2d4
```

**예제 입력 2**

```
abc
```

**예제 출력 2**

```
a1b1c1
```

<details>
<summary>💡 힌트 보기</summary>

지금 보고 있는 글자와 그 개수를 기억해 두십시오. 다른 글자가 나오면 그때까지의 결과를 기록하고 새로 시작합니다. 마지막 구간을 기록하는 것을 잊지 마십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
s = input()
result = []
cur, cnt = s[0], 0
for ch in s:
    if ch == cur:
        cnt += 1
    else:
        result.append(f"{cur}{cnt}")
        cur, cnt = ch, 1
result.append(f"{cur}{cnt}")
print("".join(result))
```

반복이 끝난 뒤에 남은 마지막 구간을 처리하는 줄이 이 문제의 함정입니다. 빠뜨리면 마지막 글자 묶음이 사라집니다. 표준 라이브러리 `itertools.groupby`를 쓰면 `"".join(f"{k}{len(list(g))}" for k, g in groupby(s))`로 끝납니다. 'abc'처럼 반복이 없으면 오히려 길이가 두 배가 된다는 점도 생각해 보십시오. 모든 데이터를 줄이는 압축법은 존재하지 않습니다.

</details>

## 050. 비밀번호 검사기

좋은 비밀번호는 길고, 여러 종류의 글자를 섞어 써야 합니다. 그래야 가능한 조합의 수가 기하급수적으로 늘어나 무차별 대입 공격을 버틸 수 있습니다.

**문제** 공백 없는 비밀번호(영문, 숫자, 특수문자로만 구성)가 주어집니다. 아래 다섯 조건을 **모두** 만족하면 `안전`, 하나라도 어기면 `취약`을 출력하십시오.

1. 길이 8 이상  2. 대문자 포함  3. 소문자 포함  4. 숫자 포함  5. 특수문자(영문자와 숫자가 아닌 글자) 포함

**예제 입력 1**

```
Py+thon2026
```

**예제 출력 1**

```
안전
```

**예제 입력 2**

```
python2026!
```

**예제 출력 2**

```
취약
```

<details>
<summary>💡 힌트 보기</summary>

`any(ch.isupper() for ch in pw)`는 대문자가 하나라도 있으면 `True`입니다. 다섯 조건을 각각 변수에 담은 뒤 `and`로 묶으십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
pw = input()
ok = (len(pw) >= 8
      and any(ch.isupper() for ch in pw)
      and any(ch.islower() for ch in pw)
      and any(ch.isdigit() for ch in pw)
      and any(not ch.isalnum() for ch in pw))
print("안전" if ok else "취약")
```

`isupper()`, `islower()`, `isdigit()`, `isalnum()`은 글자의 종류를 알려 주는 문자열 메서드입니다. `any()`는 하나라도 참이면 참이고, 짝이 되는 `all()`은 모두 참이어야 참입니다. 괄호로 감싸면 긴 조건식을 여러 줄로 나누어 쓸 수 있습니다. 주의할 점: `isalnum()`은 한글도 '문자'로 봅니다. 그래서 한글이 섞일 수 있는 실제 서비스라면 특수문자 판정을 `string.punctuation`으로 하는 편이 정확합니다.

</details>
