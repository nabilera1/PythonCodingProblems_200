## 051. 봉우리 XV

19세기 중반 인도 측량국은 히말라야의 봉우리들에 번호만 붙여 두고 높이를 계산했습니다. 1852년 무렵, 계산 결과 '봉우리 XV'가 세계에서 가장 높다는 사실이 드러났습니다. 오늘날 에베레스트라 부르는 산입니다.

**문제** 첫째 줄에 봉우리의 수 N, 둘째 줄에 N개의 높이가 주어집니다. 가장 높은 높이와, 그 높이가 **처음** 나타나는 위치(1부터 셈)를 공백으로 구분해 출력하십시오.

**제한** 1 ≤ N ≤ 1000, 각 높이는 1 이상 10000 이하의 정수

**예제 입력**

```
5
8586 8848 8516 8848 8485
```

**예제 출력**

```
8848 2
```

<details>
<summary>💡 힌트 보기</summary>

`max(리스트)`로 최댓값을, `리스트.index(값)`으로 그 값이 처음 나오는 위치를 얻을 수 있습니다. 위치는 0부터 세므로 1을 더하십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
heights = list(map(int, input().split()))
best = max(heights)
print(best, heights.index(best) + 1)
```

`index()`는 앞에서부터 찾아 처음 일치하는 위치를 돌려주므로 '처음 나타나는 위치'라는 조건이 저절로 만족됩니다. 리스트를 두 번 훑는 풀이이지만 충분히 빠릅니다. 한 번만 훑고 싶다면 21번처럼 '지금까지의 최댓값과 그 위치'를 들고 다니면 됩니다. 이때 같은 값이 나와도 기록을 바꾸지 않도록 `>`를 써야 합니다.

</details>

## 052. 평균보다 높은 학생

'평균 이상'이라는 말은 흔히 쓰이지만, 실제로 평균보다 높은 사람이 몇 명인지는 자료의 모양에 따라 크게 달라집니다. 한 명이 아주 높은 점수를 받으면 나머지 대부분이 평균 아래에 놓이기도 합니다.

**문제** 첫째 줄에 학생 수 N, 둘째 줄에 N개의 점수(정수)가 주어집니다. 점수가 평균보다 **엄격하게 큰** 학생 수를 출력하십시오.

**제한** 1 ≤ N ≤ 1000, 0 ≤ 점수 ≤ 100

**예제 입력 1**

```
5
50 50 70 80 90
```

**예제 출력 1**

```
3
```

**예제 입력 2**

```
4
10 10 10 100
```

**예제 출력 2**

```
1
```

<details>
<summary>💡 힌트 보기</summary>

평균을 먼저 구한 뒤 리스트를 다시 훑으며 세십시오. 실수 비교가 걱정된다면 `점수 × N > 총합`으로 정수끼리 비교할 수 있습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
scores = list(map(int, input().split()))
total = sum(scores)
print(sum(1 for s in scores if s * n > total))
```

`s > total / n` 대신 양변에 n을 곱한 `s * n > total`을 쓰면 실수 오차가 끼어들 틈이 없습니다. 나눗셈을 곱셈으로 바꾸는 이 요령은 경시 문제에서 자주 쓰입니다. `sum(1 for ... if ...)`는 조건을 만족하는 원소의 개수를 셉니다. 반복문과 카운터 변수로 풀어도 물론 좋습니다.

</details>

## 053. 회전 초밥

회전 초밥집의 레일은 원형이라 끝과 처음이 이어져 있습니다. 리스트를 오른쪽으로 한 칸 돌리면 마지막 원소가 맨 앞으로 옵니다. 원소가 N개라면 N칸을 돌렸을 때 제자리로 돌아옵니다.

**문제** 첫째 줄에 N과 k, 둘째 줄에 N개의 정수가 주어집니다. 리스트를 오른쪽으로 k칸 회전한 결과를 출력하십시오.

**제한** 1 ≤ N ≤ 1000, 0 ≤ k ≤ 10⁹

**예제 입력 1**

```
5 2
1 2 3 4 5
```

**예제 출력 1**

```
4 5 1 2 3
```

**예제 입력 2**

```
3 7
10 20 30
```

**예제 출력 2**

```
30 10 20
```

<details>
<summary>💡 힌트 보기</summary>

k칸 회전은 `k % N`칸 회전과 같습니다. 오른쪽으로 k칸 돌리면 뒤쪽 k개가 앞으로 옵니다. 슬라이싱 두 개를 이어 붙이십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n, k = map(int, input().split())
a = input().split()
k %= n
print(*(a[n - k:] + a[:n - k]))
```

10억 칸을 실제로 한 칸씩 돌리면 시간이 한참 걸리지만, `k % N`을 쓰면 회전은 언제나 N칸 미만으로 줄어듭니다. `a[-k:] + a[:-k]`로 써도 되지만 k가 0일 때 함정이 있습니다. `a[-0:]`은 리스트 전체이고 `a[:-0]`은 빈 리스트가 되기 때문입니다. 이 경우는 우연히 결과가 맞지만, 위처럼 `n - k`로 쓰면 그런 고민이 필요 없습니다. `collections.deque`의 `rotate(k)`도 같은 일을 합니다.

</details>

## 054. 통장의 잔액

복식부기 장부에는 거래 하나하나와 함께 그 시점의 잔액이 적힙니다. 잔액은 처음부터 그때까지의 거래를 모두 더한 값, 곧 **누적합**입니다. 누적합은 제3부에서 가장 먼저 만나는 기법이기도 합니다.

**문제** 첫째 줄에 거래 수 N, 둘째 줄에 N개의 거래 금액(입금은 양수, 출금은 음수)이 주어집니다. 잔액은 0원에서 시작합니다. 첫째 줄에 각 거래 직후의 잔액을 차례로, 둘째 줄에 그 가운데 **가장 낮았던 잔액**을 출력하십시오.

**제한** 1 ≤ N ≤ 1000, |금액| ≤ 10⁶

**예제 입력**

```
4
1000 -300 -900 500
```

**예제 출력**

```
1000 700 -200 300
-200
```

<details>
<summary>💡 힌트 보기</summary>

`balance` 변수에 거래를 하나씩 더하면서 그때마다 결과 리스트에 `append()` 하십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
balance = 0
history = []
for x in map(int, input().split()):
    balance += x
    history.append(balance)
print(*history)
print(min(history))
```

리스트를 빈 상태로 만들고 `append()`로 하나씩 채워 가는 것은 가장 기본적인 리스트 사용법입니다. 표준 라이브러리 `itertools.accumulate(거래들)`가 정확히 이 누적합을 만들어 줍니다. 누적합 리스트가 있으면 'i번째부터 j번째 거래까지의 합'을 뺄셈 한 번으로 구할 수 있습니다. 이 사실은 151번 문제에서 큰 힘을 발휘합니다.

</details>

## 055. 은메달

올림픽에서 공동 1위가 나오면 은메달 없이 곧바로 동메달로 넘어가기도 합니다. '두 번째로 큰 값'을 물을 때는 같은 값을 어떻게 다룰지부터 정해야 합니다.

**문제** 첫째 줄에 N, 둘째 줄에 N개의 정수가 주어집니다. **서로 다른 값들 가운데** 두 번째로 큰 값을 출력하십시오. 서로 다른 값이 하나뿐이면 `없음`을 출력합니다.

**제한** 1 ≤ N ≤ 1000, |각 수| ≤ 10⁹

**예제 입력 1**

```
5
3 9 9 4 1
```

**예제 출력 1**

```
4
```

**예제 입력 2**

```
3
7 7 7
```

**예제 출력 2**

```
없음
```

<details>
<summary>💡 힌트 보기</summary>

중복을 없앤 뒤 정렬하면 뒤에서 두 번째 원소가 답입니다. `set()`으로 중복을 없앨 수 있습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
values = sorted(set(map(int, input().split())))
print(values[-2] if len(values) >= 2 else "없음")
```

`set`은 중복을 허락하지 않는 자료형입니다(제13단원에서 자세히 다룹니다). 정렬하지 않고 한 번만 훑는 방법도 있습니다. `first`와 `second` 두 변수를 두고, 새 값이 first보다 크면 first를 second로 내리면 됩니다. 이 방법은 N이 아주 클 때 유리합니다. 직접 구현해 보고 `3 9 9 4 1`에서 9가 두 번 나올 때 어떻게 처리해야 하는지 확인해 보십시오.

</details>
