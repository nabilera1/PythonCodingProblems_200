## 101. 에라토스테네스의 체

기원전 3세기 알렉산드리아 도서관장 에라토스테네스는 지구 둘레를 처음으로 꽤 정확히 잰 사람으로 유명합니다. 그는 소수를 걸러 내는 아름다운 방법도 남겼습니다. 2의 배수를 지우고, 남은 3의 배수를 지우고, … 끝까지 남은 수가 소수입니다.

**문제** 정수 n이 주어질 때 n 이하의 소수의 개수와 가장 큰 소수를 공백으로 구분해 출력하십시오.

**제한** 2 ≤ n ≤ 10⁶

**예제 입력 1**

```
10
```

**예제 출력 1**

```
4 7
```

**예제 입력 2**

```
100
```

**예제 출력 2**

```
25 97
```

<details>
<summary>💡 힌트 보기</summary>

길이 n+1의 참/거짓 표를 만들고, i가 소수이면 i×i부터 i씩 건너뛰며 지우십시오. i는 √n까지만 보면 됩니다. 슬라이스 대입 `sieve[i*i::i] = ...`를 쓰면 빠릅니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import math
n = int(input())
sieve = bytearray([1]) * (n + 1)
sieve[0] = sieve[1] = 0
for i in range(2, math.isqrt(n) + 1):
    if sieve[i]:
        sieve[i * i::i] = bytes(len(range(i * i, n + 1, i)))
largest = n
while not sieve[largest]:
    largest -= 1
print(sum(sieve), largest)
```

i의 배수 가운데 i×i보다 작은 것들은 이미 더 작은 소인수에서 지워졌으므로 i×i부터 시작해도 됩니다. 체의 시간 복잡도는 O(n log log n)으로, 사실상 선형입니다. 71번처럼 수마다 √n까지 나누어 보면 n = 10⁶에서 수억 번의 나눗셈이 필요하지만, 체는 수백만 번이면 끝납니다. `bytearray`는 원소마다 1바이트만 쓰는 가변 배열이고, 슬라이스 대입은 파이썬 반복문 없이 C 속도로 한꺼번에 지웁니다.

</details>

## 102. 소인수분해

산술의 기본 정리에 따르면 1보다 큰 모든 자연수는 소수들의 곱으로 단 한 가지 방법으로만 나타납니다. 이 정리는 유클리드 『원론』에 그 뿌리가 있고, 1801년 가우스의 『산술 연구』에서 완전한 형태로 증명되었습니다.

**문제** 자연수 n을 소인수분해하여 작은 소인수부터 `p^e` 꼴로 ` * `로 이어 출력하십시오. 지수가 1이면 `^1`은 생략합니다.

**제한** 2 ≤ n ≤ 10¹²

**예제 입력 1**

```
360
```

**예제 출력 1**

```
2^3 * 3^2 * 5
```

**예제 입력 2**

```
97
```

**예제 출력 2**

```
97
```

<details>
<summary>💡 힌트 보기</summary>

2부터 시작해 나누어떨어지는 동안 계속 나누고 지수를 세십시오. d × d > n이 되면 멈춥니다. 그때 n이 1보다 크면 남은 n 자신이 소수입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
parts = []
d = 2
while d * d <= n:
    e = 0
    while n % d == 0:
        n //= d
        e += 1
    if e:
        parts.append(f"{d}^{e}" if e > 1 else str(d))
    d += 1
if n > 1:
    parts.append(str(n))
print(" * ".join(parts))
```

d가 합성수일 때는 나누어떨어지지 않습니다. 그 소인수들이 앞에서 이미 모두 나누어져 나갔기 때문입니다. 그래서 소수 판별 없이도 소인수만 걸러집니다. 최악의 경우는 n이 10¹²에 가까운 소수일 때로, 약 백만 번 반복합니다. 숨은 테스트의 999966000289 = 999983²은 큰 소수의 제곱이라 마지막까지 소인수가 나오지 않는 까다로운 경우입니다. 600851475143은 유명한 수학 문제 사이트 Project Euler 3번 문제에 나오는 수입니다.

</details>

## 103. 약수의 개수와 합

소인수분해를 알면 약수를 하나하나 세지 않고도 개수와 합을 곧바로 계산할 수 있습니다. n = p^a × q^b이면 약수는 p^i × q^j (0 ≤ i ≤ a, 0 ≤ j ≤ b)의 꼴이기 때문입니다.

**문제** 자연수 n의 약수의 개수와 약수의 합을 공백으로 구분해 출력하십시오.

**제한** 1 ≤ n ≤ 10¹²

**예제 입력 1**

```
28
```

**예제 출력 1**

```
6 56
```

**예제 입력 2**

```
1
```

**예제 출력 2**

```
1 1
```

<details>
<summary>💡 힌트 보기</summary>

n = ∏ p^e이면 약수의 개수는 ∏(e + 1), 약수의 합은 ∏(1 + p + p² + … + p^e)입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
count, total = 1, 1
d = 2
while d * d <= n:
    if n % d == 0:
        e, s, pw = 0, 1, 1
        while n % d == 0:
            n //= d
            e += 1
            pw *= d
            s += pw
        count *= e + 1
        total *= s
    d += 1
if n > 1:
    count *= 2
    total *= 1 + n
print(count, total)
```

약수의 합이 2n이면 완전수입니다. 28의 약수의 합 56 = 2 × 28이 그 예입니다. 숨은 테스트의 496과 8128도 완전수이며, 고대 그리스인이 알던 완전수는 이 넷(6, 28, 496, 8128)이 전부였습니다. 963761198400은 10¹² 이하에서 약수가 가장 많은 수로, 약수가 6720개입니다. 30번처럼 하나씩 나누어 보았다면 1조 번이 걸렸을 것입니다. 구조를 알면 계산이 사라집니다.

</details>

## 104. 오일러의 피 함수

1763년 오일러는 n 이하의 자연수 가운데 n과 서로소인 수의 개수를 세는 함수 φ(n)을 도입했습니다. 이백 년 뒤 이 함수는 인터넷 보안을 떠받치는 RSA 암호의 핵심 부품이 됩니다.

**문제** 자연수 n에 대해 φ(n)을 출력하십시오.

**제한** 1 ≤ n ≤ 10¹²

**예제 입력 1**

```
36
```

**예제 출력 1**

```
12
```

**예제 입력 2**

```
1
```

**예제 출력 2**

```
1
```

<details>
<summary>💡 힌트 보기</summary>

φ(n) = n × ∏(1 − 1/p) (p는 n의 서로 다른 소인수)입니다. 실수를 피하려면 소인수 p를 찾을 때마다 `result = result // p * (p - 1)`로 계산하십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
result = n
d = 2
while d * d <= n:
    if n % d == 0:
        while n % d == 0:
            n //= d
        result = result // d * (d - 1)
    d += 1
if n > 1:
    result = result // n * (n - 1)
print(result)
```

36 = 2² × 3²이므로 φ(36) = 36 × (1/2) × (2/3) = 12입니다. 1, 5, 7, 11, 13, 17, 19, 23, 25, 29, 31, 35의 열두 개입니다. `result // d * (d - 1)`의 나눗셈은 언제나 나누어떨어집니다. d가 result의 소인수이기 때문입니다. 실수 계산을 하지 않으므로 오차가 없습니다. 소수 p에 대해 φ(p) = p − 1입니다. 그래서 1000000007의 답은 1000000006입니다.

</details>

## 105. 빠른 거듭제곱

1640년 페르마는 '소수 p와 서로소인 a에 대해 a^(p−1)을 p로 나눈 나머지는 1'이라는 정리를 편지에 적었습니다. 이 정리를 확인하려면 거대한 거듭제곱의 나머지를 구해야 합니다. 지수가 10¹⁸이라도 60번 남짓의 곱셈이면 충분합니다.

**문제** a, b, m이 주어질 때 aᵇ을 m으로 나눈 나머지를 출력하십시오. 내장 함수 `pow(a, b, m)`을 쓰지 말고 **분할 정복**으로 직접 구현하십시오.

**제한** 0 ≤ a, b ≤ 10¹⁸, 1 ≤ m ≤ 10⁹ (0⁰ = 1로 약속)

**예제 입력 1**

```
2 10 1000
```

**예제 출력 1**

```
24
```

**예제 입력 2**

```
3 200 13
```

**예제 출력 2**

```
9
```

<details>
<summary>💡 힌트 보기</summary>

b가 짝수이면 aᵇ = (a^(b/2))², 홀수이면 aᵇ = a × a^(b−1)입니다. 반복문으로 쓰려면 b를 2진수로 보고 한 비트씩 처리하십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
a, b, m = map(int, input().split())
result = 1 % m
a %= m
while b > 0:
    if b & 1:
        result = result * a % m
    a = a * a % m
    b >>= 1
print(result)
```

b를 2진수로 쓰면 aᵇ은 a, a², a⁴, a⁸, … 가운데 일부의 곱입니다. 매 단계 a를 제곱하고, b의 해당 비트가 1이면 결과에 곱합니다. 곱셈 횟수는 b의 비트 수, 곧 log₂b에 비례합니다. `result = 1 % m`은 m = 1일 때 답을 0으로 만들기 위한 작은 배려입니다. 마지막 숨은 테스트는 페르마의 소정리에 따라 1이 나와야 합니다. 실전에서는 `pow(a, b, m)`을 쓰면 되고, 파이썬 3.8부터는 `pow(a, -1, m)`으로 모듈러 역원도 구할 수 있습니다.

</details>
