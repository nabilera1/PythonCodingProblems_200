## 186. 합치고 묻기

'두 사람이 같은 모임에 속하는가?'라는 질문에 모임이 계속 합쳐지는 상황에서도 거의 즉시 답하는 자료구조가 **유니온 파인드**입니다. 각 원소가 자기 모임의 대표를 가리키는 나무를 이루고, 찾는 길에 경로를 줄여 나무를 납작하게 유지합니다.

**문제** 1번부터 N번까지의 원소가 처음에는 각자 다른 집합에 있습니다. Q개의 명령을 처리하십시오. `0 a b`는 a가 속한 집합과 b가 속한 집합을 합치고, `1 a b`는 a와 b가 같은 집합이면 `YES`, 아니면 `NO`를 출력합니다.

**입력** 첫째 줄에 N과 Q, 이어서 Q줄에 명령이 주어집니다.

**출력** `1` 명령마다 한 줄에 답을 출력합니다.

**제한** 1 ≤ N ≤ 2×10⁵, 1 ≤ Q ≤ 2×10⁵, 시간 제한 3초

**예제 입력**

```
5 6
0 1 2
1 1 2
1 2 3
0 3 2
1 1 3
1 4 5
```

**예제 출력**

```
YES
NO
YES
NO
```

<details>
<summary>💡 힌트 보기</summary>

`parent[x]`가 x의 부모를 가리키게 하고, `find(x)`는 대표에 이를 때까지 따라 올라가면서 지나는 원소를 할아버지에 연결해 경로를 줄이십시오(경로 절반화). 합칠 때는 한 대표를 다른 대표 밑에 붙입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
data = sys.stdin.buffer.read().split()
n, q = int(data[0]), int(data[1])
parent = list(range(n + 1))
size = [1] * (n + 1)

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

out = []
idx = 2
for _ in range(q):
    op, a, b = data[idx], int(data[idx + 1]), int(data[idx + 2])
    idx += 3
    ra, rb = find(a), find(b)
    if op == b'0':
        if ra != rb:
            if size[ra] < size[rb]:
                ra, rb = rb, ra
            parent[rb] = ra
            size[ra] += size[rb]
    else:
        out.append('YES' if ra == rb else 'NO')
print('\n'.join(out))
```

경로 압축과 '크기가 작은 쪽을 큰 쪽 밑에 붙이기'(union by size)를 함께 쓰면 연산 하나의 평균 비용이 아커만 함수의 역함수 α(N) 수준이 됩니다. 1975년 타잔이 증명한 결과로, 우주에 있는 원자의 수만큼 원소가 있어도 α(N)은 5를 넘지 않습니다. 사실상 상수 시간입니다. 재귀로 `find`를 쓰면 경로가 긴 경우 재귀 깊이 초과가 날 수 있습니다. 숨은 테스트에는 10만 개가 한 줄로 이어지는 경우가 있습니다. 위처럼 반복문으로 쓰는 것이 안전합니다.

</details>

## 187. 크루스칼의 다리

모든 섬을 최소 비용의 다리로 잇는 문제, 곧 **최소 신장 트리**는 1956년 조지프 크루스칼이 간결한 답을 내놓았습니다. 싼 다리부터 차례로 보며, 이미 이어진 두 섬을 잇는 다리(사이클을 만드는 다리)만 건너뛰는 것입니다. 이어졌는지의 판정은 유니온 파인드가 맡습니다.

**문제** N개의 섬과 M개의 다리 후보(양방향, 비용)가 주어집니다. 모든 섬이 이어지도록 다리를 고를 때 비용 합의 최솟값을 구하십시오. 모든 섬을 이을 수 없으면 −1을 출력합니다.

**입력** 첫째 줄에 N과 M, 이어서 M줄에 a b w가 주어집니다.

**출력** 최소 비용 또는 −1을 출력합니다.

**제한** 1 ≤ N ≤ 10⁵, 0 ≤ M ≤ 2×10⁵, 1 ≤ w ≤ 10⁶, 시간 제한 3초

**예제 입력 1**

```
4 5
1 2 3
2 3 1
1 3 2
3 4 5
2 4 4
```

**예제 출력 1**

```
7
```

**예제 입력 2**

```
3 1
1 2 1
```

**예제 출력 2**

```
-1
```

<details>
<summary>💡 힌트 보기</summary>

간선을 비용 순으로 정렬하고, 두 끝점의 대표가 다를 때만 그 간선을 고르고 합치십시오. 고른 간선이 N−1개가 되면 끝입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
data = sys.stdin.buffer.read().split()
n, m = int(data[0]), int(data[1])
edges = sorted(zip(map(int, data[4::3]), map(int, data[2::3]), map(int, data[3::3])))
parent = list(range(n + 1))

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

total = used = 0
for w, a, b in edges:
    ra, rb = find(a), find(b)
    if ra != rb:
        parent[ra] = rb
        total += w
        used += 1
        if used == n - 1:
            break
print(total if used == n - 1 else -1)
```

크루스칼의 정당성은 **절단 성질**에서 나옵니다. 그래프를 두 무리로 나누었을 때 두 무리를 잇는 간선 가운데 가장 싼 것은 어떤 최소 신장 트리에 반드시 들어갈 수 있습니다. 검증용 풀이는 같은 문제를 프림 알고리즘(1957)으로 풉니다. 하나의 정점에서 트리를 키워 가며 가장 싼 바깥 간선을 붙이는 방식입니다. 출발점이 다른 두 알고리즘이 같은 답을 낸다는 것이 이 문제의 정답을 뒷받침합니다. 자기 자신으로 가는 다리(a = b)가 입력에 있어도 크루스칼은 자연스럽게 건너뜁니다. 두 끝점의 대표가 같기 때문입니다.

</details>

## 188. 친구의 친구

사회관계망 서비스는 '친구의 친구'까지 연결된 무리의 크기를 실시간으로 계산합니다. 유니온 파인드의 대표마다 무리의 크기를 함께 기록해 두면, 합칠 때마다 크기를 더하는 것만으로 이 질문에 즉시 답할 수 있습니다.

**문제** 친구 관계가 하나씩 F개 주어집니다. 관계 `a b`가 맺어질 때마다 a가 속한 친구 무리(친구의 친구… 로 이어진 모든 사람)의 크기를 출력하십시오. 이름은 영어 소문자입니다.

**입력** 첫째 줄에 F, 이어서 F줄에 두 사람의 이름이 주어집니다.

**출력** 관계마다 한 줄에 무리의 크기를 출력합니다.

**제한** 1 ≤ F ≤ 10⁵, 이름 길이 ≤ 20, 시간 제한 3초

**예제 입력**

```
4
kim lee
lee park
choi han
park kim
```

**예제 출력**

```
2
3
2
3
```

<details>
<summary>💡 힌트 보기</summary>

이름 → 번호 딕셔너리로 처음 보는 이름에 새 번호를 붙이고, `size` 배열을 유니온 파인드와 함께 관리하십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
data = sys.stdin.buffer.read().split()
f = int(data[0])
id_of = {}
parent, size = [], []

def get(name):
    if name not in id_of:
        id_of[name] = len(parent)
        parent.append(len(parent))
        size.append(1)
    return id_of[name]

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

out = []
for i in range(f):
    a, b = find(get(data[1 + 2 * i])), find(get(data[2 + 2 * i]))
    if a != b:
        if size[a] < size[b]:
            a, b = b, a
        parent[b] = a
        size[a] += size[b]
    out.append(size[a])
print('\n'.join(map(str, out)))
```

크기는 대표에만 정확히 기록되어 있습니다. 대표가 아닌 원소의 `size` 값은 합쳐지기 전의 낡은 값이므로 읽으면 안 됩니다. 반드시 `find`로 대표를 구한 뒤 읽으십시오. `a a`처럼 자기 자신과 친구를 맺는 입력도 이상 없이 1을 출력합니다. 이름을 바이트 문자열 그대로 딕셔너리 키로 쓴 것은 대용량 입력에서 디코딩 비용을 아끼기 위해서입니다.

</details>

## 189. 처음 생긴 순환

간선을 하나씩 추가하는 그래프에서 '이 간선이 순환을 만드는가?'는 '두 끝점이 이미 이어져 있는가?'와 같은 질문입니다. 유니온 파인드로 매번 답하면, 처음 순환이 생기는 순간을 정확히 잡아낼 수 있습니다.

**문제** N개의 정점에 무방향 간선 M개가 차례로 추가됩니다. 처음으로 순환이 생기는 것은 몇 번째 간선을 추가했을 때인지 출력하십시오. 끝까지 순환이 생기지 않으면 0을 출력합니다.

**입력** 첫째 줄에 N과 M, 이어서 M줄에 간선의 두 끝점이 주어집니다(0부터 N−1).

**출력** 처음 순환을 만든 간선의 번호(1부터) 또는 0을 출력합니다.

**제한** 3 ≤ N ≤ 5×10⁵, 1 ≤ M ≤ 10⁶, 자기 자신으로 가는 간선은 없음, 시간 제한 4초

**예제 입력 1**

```
6 5
0 1
1 2
2 3
5 4
0 4
```

**예제 출력 1**

```
0
```

**예제 입력 2**

```
6 5
0 1
1 2
1 3
0 3
4 5
```

**예제 출력 2**

```
4
```

<details>
<summary>💡 힌트 보기</summary>

간선을 순서대로 보며 두 끝점의 대표가 같으면 그 번호를 출력하고 멈추십시오. 다르면 합칩니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
data = sys.stdin.buffer.read().split()
n, m = int(data[0]), int(data[1])
parent = list(range(n))

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

answer = 0
for i in range(m):
    a, b = find(int(data[2 + 2 * i])), find(int(data[3 + 2 * i]))
    if a == b:
        answer = i + 1
        break
    parent[a] = b
print(answer)
```

같은 두 정점 사이의 두 번째 간선(숨은 테스트 `0 1`, `0 1`)도 길이 2의 순환입니다. 유니온 파인드는 이 경우도 자연스럽게 처리합니다. 답을 찾으면 바로 멈추므로 나머지 입력은 읽기만 하고 버립니다. 입력을 한꺼번에 읽어 두었기 때문에 남은 줄을 따로 처리할 필요가 없습니다(99번에서 말한 '남은 입력' 문제를 이렇게 피합니다). 검증용 풀이는 간선을 추가하기 전마다 DFS로 '이미 이어져 있는가'를 직접 확인합니다.

## 190. 우주 정거장 연결

정거장이 10만 개면 정거장 쌍은 50억 개입니다. 모든 쌍을 간선으로 만들 수는 없습니다. 비용이 '세 좌표 차이 중 최솟값'이라는 특별한 구조를 이용하면, **각 축으로 정렬했을 때 이웃한 쌍**만 후보로 두어도 충분하다는 것을 증명할 수 있습니다.

**문제** 3차원 공간에 N개의 정거장이 있습니다. 두 정거장 (x₁, y₁, z₁), (x₂, y₂, z₂)를 터널로 잇는 비용은 min(|x₁−x₂|, |y₁−y₂|, |z₁−z₂|)입니다. 모든 정거장을 잇는 최소 비용을 구하십시오.

**입력** 첫째 줄에 N, 이어서 N줄에 정거장의 좌표가 주어집니다.

**출력** 최소 비용을 출력합니다.

**제한** 1 ≤ N ≤ 10⁵, |좌표| ≤ 10⁹, 시간 제한 4초

**예제 입력**

```
5
11 -15 -15
14 -5 -15
-1 -1 -5
10 -4 -1
19 -4 19
```

**예제 출력**

```
4
```

<details>
<summary>💡 힌트 보기</summary>

x로 정렬해 이웃한 쌍의 x 차이를 간선으로, y와 z도 마찬가지로 만들면 간선이 3(N−1)개뿐입니다. 이 간선들로 크루스칼을 돌리십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
data = sys.stdin.buffer.read().split()
n = int(data[0])
pts = [(int(data[1 + 3 * i]), int(data[2 + 3 * i]), int(data[3 + 3 * i])) for i in range(n)]
edges = []
for axis in range(3):
    order = sorted(range(n), key=lambda i: pts[i][axis])
    for a, b in zip(order, order[1:]):
        edges.append((pts[b][axis] - pts[a][axis], a, b))
edges.sort()
parent = list(range(n))

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

total = used = 0
for w, a, b in edges:
    ra, rb = find(a), find(b)
    if ra != rb:
        parent[ra] = rb
        total += w
        used += 1
        if used == n - 1:
            break
print(total)
```

왜 이웃한 쌍만으로 충분할까요? 비용은 세 축의 거리 가운데 최솟값입니다. 그래서 어떤 터널 (p, q)의 비용이 x축 거리라면, x로 정렬했을 때 p와 q 사이에 놓인 정거장들을 이웃끼리 잇는 x 간선들은 모두 그보다 싸거나 같습니다. 이 간선들만으로 p와 q를 같은 비용 이하로 이을 수 있으므로, (p, q) 대신 이웃 간선들을 써도 손해가 없습니다. 이처럼 문제의 구조를 이용해 **후보 간선을 줄이는** 것은 고급 문제의 전형적인 첫 관문입니다. 검증용 풀이는 모든 쌍을 고려하는 프림 알고리즘입니다.

</details>
