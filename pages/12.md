## 056. 중앙값의 힘

어느 마을 주민 아홉 명의 평균 재산이 어느 날 갑자기 열 배로 뛰었습니다. 억만장자 한 명이 이사 왔기 때문입니다. 이럴 때도 줄을 세워 한가운데 사람을 보는 **중앙값**은 거의 변하지 않습니다. 극단값에 흔들리지 않는 대푯값입니다.

**문제** 첫째 줄에 홀수 N, 둘째 줄에 N개의 정수가 주어집니다. 중앙값을 출력하십시오.

**제한** 1 ≤ N ≤ 10⁵ (N은 홀수), |각 수| ≤ 10⁹

**예제 입력**

```
5
7 1 3 1000000000 2
```

**예제 출력**

```
3
```

<details>
<summary>💡 힌트 보기</summary>

정렬한 뒤 가운데 인덱스 `N // 2`의 원소를 고르십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
a = sorted(map(int, input().split()))
print(a[n // 2])
```

`sorted()`는 새 리스트를 돌려주고, `리스트.sort()`는 원래 리스트를 제자리에서 정렬합니다. 원본을 보존해야 하는지에 따라 골라 쓰십시오. 파이썬의 정렬은 2002년 팀 피터스가 만든 **Timsort**로, 10만 개를 정렬하는 데 0.1초도 걸리지 않습니다. 표준 라이브러리 `statistics.median()`도 있습니다.

</details>

## 057. 안정 정렬

파이썬의 정렬은 **안정적(stable)** 입니다. 기준값이 같은 원소들은 정렬 전의 순서를 그대로 지킵니다. 이 성질을 이용하면, 덜 중요한 기준으로 먼저 정렬한 뒤 더 중요한 기준으로 다시 정렬하는 방식으로 여러 기준을 한꺼번에 처리할 수 있습니다.

**문제** 영어 단어들이 한 줄에 공백으로 구분되어 주어집니다. 단어를 **길이가 짧은 순서**로, 길이가 같으면 **사전 순서**로 정렬해 출력하십시오.

**제한** 단어는 1개 이상 1000개 이하, 영어 소문자

**예제 입력**

```
banana kiwi apple fig cherry date
```

**예제 출력**

```
fig date kiwi apple banana cherry
```

<details>
<summary>💡 힌트 보기</summary>

먼저 `sort()`로 사전 순 정렬을 한 뒤, `sort(key=len)`으로 길이 순 정렬을 하십시오. 두 번째 정렬이 첫 번째 정렬의 순서를 망가뜨리지 않는 이유를 생각해 보십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
words = input().split()
words.sort()
words.sort(key=len)
print(*words)
```

두 번째 정렬에서 길이가 같은 단어들은 안정성 덕분에 첫 번째 정렬이 만든 사전 순서를 그대로 유지합니다. `key=len`은 '각 원소에 `len`을 적용한 값으로 비교하라'는 뜻입니다. 제16단원에서 람다를 배우면 `words.sort(key=lambda w: (len(w), w))` 한 번으로 끝낼 수 있습니다.

</details>

## 058. 시상대

시상대에는 세 사람만 오릅니다. 점수가 같을 때 누구를 먼저 부를지 정해 두지 않으면 순위가 매번 달라질 수 있습니다. 좋은 문제는 이런 모호함을 남기지 않습니다.

**문제** 첫째 줄에 참가자 수 N, 이어서 N줄에 `이름 점수`가 주어집니다. 점수가 높은 순서로, 점수가 같으면 이름의 사전 순서로 상위 3명을 한 줄에 하나씩 `이름 점수` 형식으로 출력하십시오.

**제한** 3 ≤ N ≤ 1000, 이름은 서로 다른 영어 소문자, 0 ≤ 점수 ≤ 100

**예제 입력**

```
5
kim 90
lee 95
park 90
choi 80
han 95
```

**예제 출력**

```
han 95
lee 95
kim 90
```

<details>
<summary>💡 힌트 보기</summary>

`(-점수, 이름)` 쌍을 리스트에 담아 정렬하십시오. 점수에 마이너스를 붙이면 높은 점수가 앞으로 옵니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
records = []
for _ in range(n):
    name, score = input().split()
    records.append((-int(score), name))
records.sort()
for neg, name in records[:3]:
    print(name, -neg)
```

튜플은 앞 원소부터 차례로 비교되므로(18번 참고), `(-점수, 이름)`으로 정렬하면 '점수 내림차순, 이름 오름차순'이 한 번에 됩니다. 부호를 뒤집는 요령은 숫자에만 쓸 수 있습니다. 문자열을 내림차순으로 정렬해야 한다면 57번처럼 안정 정렬을 두 번 하거나, `reverse=True`를 섞어 써야 합니다.

</details>

## 059. 슬라이싱 연습장

슬라이싱 `[시작:끝:보폭]`은 파이썬이 가장 자랑하는 문법 가운데 하나입니다. 세 수만으로 앞부분, 뒷부분, 띄엄띄엄, 거꾸로를 모두 표현합니다.

**문제** 첫째 줄에 N, 둘째 줄에 N개의 정수가 주어집니다. 다음 네 줄을 출력하십시오.

1. 앞의 3개  2. 뒤의 3개  3. 짝수 번째 인덱스(0, 2, 4, …)의 원소  4. 전체를 거꾸로

**제한** 3 ≤ N ≤ 100

**예제 입력**

```
6
10 20 30 40 50 60
```

**예제 출력**

```
10 20 30
40 50 60
10 30 50
60 50 40 30 20 10
```

<details>
<summary>💡 힌트 보기</summary>

`a[:3]`, `a[-3:]`, `a[::2]`, `a[::-1]`.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
a = input().split()
print(*a[:3])
print(*a[-3:])
print(*a[::2])
print(*a[::-1])
```

슬라이싱은 범위를 벗어나도 오류를 내지 않습니다. 리스트가 2개뿐이어도 `a[:3]`은 오류 없이 2개만 돌려줍니다. 반면 `a[5]`처럼 인덱스로 하나를 꺼낼 때는 `IndexError`가 납니다. 또 슬라이싱 결과는 **새 리스트**입니다. 그래서 `b = a[:]`는 리스트를 복사하는 관용구로 쓰입니다.

</details>

## 060. 폰 노이만의 병합

1945년 존 폰 노이만은 정렬된 두 묶음을 하나로 합치는 **병합(merge)** 을 바탕으로 한 정렬법을 고안했습니다. 두 줄의 맨 앞만 비교해 더 작은 쪽을 하나씩 꺼내는 것, 그것이 전부입니다.

**문제** 첫째 줄에 N과 M, 둘째 줄에 오름차순으로 정렬된 N개의 정수, 셋째 줄에 오름차순으로 정렬된 M개의 정수가 주어집니다. 두 리스트를 합쳐 오름차순으로 출력하십시오. **`sort()`나 `sorted()`를 쓰지 말고** 직접 병합하십시오.

**제한** 1 ≤ N, M ≤ 10⁵, |각 수| ≤ 10⁹

**예제 입력**

```
3 4
1 4 9
2 3 4 10
```

**예제 출력**

```
1 2 3 4 4 9 10
```

<details>
<summary>💡 힌트 보기</summary>

두 리스트에 각각 손가락(인덱스 i, j)을 하나씩 얹으십시오. 더 작은 쪽을 결과에 넣고 그 손가락을 한 칸 옮깁니다. 한쪽이 바닥나면 남은 쪽을 통째로 붙이면 됩니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n, m = map(int, input().split())
a = list(map(int, input().split()))
b = list(map(int, input().split()))
i = j = 0
result = []
while i < n and j < m:
    if a[i] <= b[j]:
        result.append(a[i]); i += 1
    else:
        result.append(b[j]); j += 1
result += a[i:]
result += b[j:]
print(*result)
```

손가락이 한 번 지나간 원소는 다시 보지 않으므로 N + M번 만에 끝납니다. 정렬된 두 리스트를 합치는 최적의 방법입니다. 이 '두 손가락' 사고법은 제3부 '투 포인터'의 출발점입니다. `a[i] <= b[j]`에서 `<`가 아니라 `<=`를 쓰면 같은 값일 때 a 쪽이 먼저 나와 병합이 안정적이 됩니다. 표준 라이브러리에는 `heapq.merge`가 있습니다.

</details>
