## 001. 첫 인사

1978년 브라이언 커니핸과 데니스 리치가 펴낸 『C 프로그래밍 언어』는 첫 예제로 화면에 짧은 인사말을 띄웠습니다. 이 책이 관례를 널리 퍼뜨린 뒤로 반세기 가까이, 새 언어를 배우는 이들은 누구나 같은 의식으로 첫걸음을 뗍니다.

**문제** 화면에 `Hello, World!`를 출력하십시오.

**예제 출력**

```
Hello, World!
```

<details>
<summary>💡 힌트 보기</summary>

대문자, 쉼표, 공백, 느낌표까지 글자 하나하나가 정확해야 합니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
print("Hello, World!")
```

채점기는 출력된 글자를 하나씩 비교합니다. `hello world`처럼 한 글자만 달라도 오답이 됩니다. 프로그래밍에서 '거의 맞음'은 '틀림'과 같다는 사실을 처음부터 기억해 두면 좋습니다.

</details>

## 002. ISO 8601의 날짜

국제 표준 ISO 8601은 날짜를 `연-월-일` 순서로, 하이픈으로 이어 적도록 권합니다. 큰 단위에서 작은 단위로 내려가는 이 표기는 문자열로 정렬해도 시간 순서가 흐트러지지 않는다는 장점이 있습니다.

**문제** 세 정수 `2026`, `11`, `22`를 `print()`에 **쉼표로 구분한 세 개의 인자**로 넘겨서 `2026-11-22`를 출력하십시오.

**예제 출력**

```
2026-11-22
```

<details>
<summary>💡 힌트 보기</summary>

`print()`는 인자 사이에 기본으로 공백을 넣습니다. 그 구분자를 바꾸는 매개변수가 있습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
print(2026, 11, 22, sep="-")
```

`print()`의 `sep` 매개변수는 인자 사이에 넣을 문자열을 정하고, `end`는 출력 끝에 붙일 문자열을 정합니다(기본값은 줄바꿈 `\n`). `print("2026-11-22")`라고 써도 같은 결과가 나오지만, 이 문제의 목적은 `sep`을 익히는 것입니다.

</details>

## 003. 역슬래시의 함정

문자열 안의 역슬래시(`\`)는 뒤에 오는 글자와 짝을 지어 특별한 뜻을 갖습니다. `\n`은 줄바꿈이고 `\t`는 탭입니다. 그래서 윈도우의 파일 경로를 그대로 적으면 뜻밖의 일이 벌어지곤 합니다.

**문제** 아래 두 줄을 정확히 출력하십시오.

```
그는 "파이썬은 아름답다"라고 말했다.
경로: C:\Users\guest\new
```

**예제 출력**

```
그는 "파이썬은 아름답다"라고 말했다.
경로: C:\Users\guest\new
```

<details>
<summary>💡 힌트 보기</summary>

큰따옴표가 들어간 문자열은 작은따옴표로 감싸면 편합니다. 경로 쪽은 `"C:\Users..."`를 그대로 실행해 보고 무슨 일이 일어나는지 살펴보십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
print('그는 "파이썬은 아름답다"라고 말했다.')
print(r"경로: C:\Users\guest\new")
```

`"C:\Users"`를 그대로 쓰면 `\U`가 유니코드 이스케이프의 시작으로 해석되어 `SyntaxError`가 납니다. 오류를 피하더라도 `\n`은 줄바꿈으로 바뀝니다. 문자열 앞에 `r`을 붙인 **raw 문자열**은 역슬래시를 글자 그대로 둡니다. `\\`처럼 역슬래시를 두 번 써도 됩니다.

</details>

## 004. 가운데 정렬된 표제

옛 타자기 시절부터 문서의 표제는 위아래에 줄을 긋고 가운데에 놓았습니다. 파이썬 문자열은 곱셈 연산자로 반복할 수 있고, 가운데 정렬을 해 주는 메서드도 갖추고 있습니다.

**문제** 폭이 20칸인 다음 표제를 출력하십시오. 둘째 줄은 `PYTHON 200`을 20칸 가운데에 놓은 것입니다.

```
====================
     PYTHON 200
====================
```

**예제 출력**

```
====================
     PYTHON 200     
====================
```

<details>
<summary>💡 힌트 보기</summary>

`"=" * 20`과 `str.center()`를 써 보십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
line = "=" * 20
print(line)
print("PYTHON 200".center(20))
print(line)
```

`"PYTHON 200"`은 10글자이므로 남는 10칸이 양쪽에 5칸씩 나뉩니다. 오른쪽 정렬은 `rjust()`, 왼쪽 정렬은 `ljust()`입니다. f-string으로 `f"{'PYTHON 200':^20}"`이라고 써도 같습니다. (채점기는 줄 끝의 공백을 무시합니다.)

</details>

## 005. 아르키메데스의 원주율

기원전 3세기, 아르키메데스는 원에 안팎으로 정96각형을 그려 원주율이 223/71보다 크고 22/7보다 작다는 것을 보였습니다. 이천 년 남짓 뒤의 우리는 `math` 모듈 한 줄로 그 값을 불러옵니다.

**문제** `math.pi`를 소수점 아래 **다섯째 자리까지** 출력하십시오.

**예제 출력**

```
3.14159
```

<details>
<summary>💡 힌트 보기</summary>

f-string의 서식 지정자 `:.5f`를 떠올려 보십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import math
print(f"{math.pi:.5f}")
```

`:.5f`는 '고정 소수점 형식으로 소수 다섯째 자리까지(여섯째 자리에서 반올림)'라는 뜻입니다. 덤으로 `print(223/71 < math.pi < 22/7)`을 실행해 아르키메데스의 부등식을 확인해 보십시오. 파이썬은 이런 **연쇄 비교**를 허용합니다.

</details>
