## 096. 숫자 야구

서로 다른 세 숫자를 맞히는 '숫자 야구'는 연필과 종이만으로 즐기던 추리 놀이입니다. 숫자와 자리가 모두 맞으면 스트라이크, 숫자만 맞고 자리가 다르면 볼입니다.

**문제** 첫째 줄에 정답, 둘째 줄에 추측이 주어집니다. 둘 다 1~9의 서로 다른 숫자 세 개로 된 문자열입니다. 스트라이크도 볼도 없으면 `OUT`, 그렇지 않으면 `xS yB`를 출력하십시오.

**예제 입력 1**

```
123
132
```

**예제 출력 1**

```
1S 2B
```

**예제 입력 2**

```
123
456
```

**예제 출력 2**

```
OUT
```

<details>
<summary>💡 힌트 보기</summary>

스트라이크는 같은 자리의 글자가 같은 경우입니다. 볼은 '공통 숫자의 개수 − 스트라이크'로 구할 수 있습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
answer, guess = input(), input()
strike = sum(a == g for a, g in zip(answer, guess))
ball = len(set(answer) & set(guess)) - strike
print("OUT" if strike == ball == 0 else f"{strike}S {ball}B")
```

`zip`으로 같은 자리끼리 짝지어 비교하고(82번), 집합의 교집합으로 공통 숫자를 셉니다(61번). 그동안 배운 도구 세 가지가 세 줄에 모였습니다. 볼을 자리마다 따로 세지 않고 **전체에서 스트라이크를 빼는** 발상이 핵심입니다. `strike == ball == 0` 같은 연쇄 비교는 5번에서 본 것과 같습니다.

</details>

## 097. 로마 숫자 만들기

로마 숫자에는 0이 없고 자릿값도 없습니다. I(1), V(5), X(10), L(50), C(100), D(500), M(1000)을 늘어놓되, 4는 IIII 대신 IV(5 − 1)처럼 작은 기호를 앞에 두어 빼는 규칙을 씁니다.

**문제** 1 이상 3999 이하의 정수를 로마 숫자로 바꾸어 출력하십시오.

**예제 입력 1**

```
1994
```

**예제 출력 1**

```
MCMXCIV
```

**예제 입력 2**

```
4
```

**예제 출력 2**

```
IV
```

<details>
<summary>💡 힌트 보기</summary>

`1000 M, 900 CM, 500 D, 400 CD, 100 C, 90 XC, 50 L, 40 XL, 10 X, 9 IX, 5 V, 4 IV, 1 I` 열세 쌍의 표를 만들고, 큰 것부터 뺄 수 있는 만큼 빼십시오. 12번의 거스름돈과 같은 탐욕 방식입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
TABLE = [(1000, "M"), (900, "CM"), (500, "D"), (400, "CD"), (100, "C"), (90, "XC"),
         (50, "L"), (40, "XL"), (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I")]
n = int(input())
out = []
for value, symbol in TABLE:
    q, n = divmod(n, value)
    out.append(symbol * q)
print("".join(out))
```

뺄셈 표기(CM, CD, XC, XL, IX, IV)를 처음부터 표에 넣어 두면 예외 처리 없이 거스름돈 문제와 똑같아집니다. **규칙의 예외를 데이터로 바꾸는** 좋은 예입니다. 로마 숫자로 쓸 수 있는 가장 큰 수가 3999(MMMCMXCIX)인 것은 같은 기호를 세 번까지만 쓰는 관례 때문입니다.

</details>

## 098. 로마 숫자 읽기

로마 숫자를 읽는 규칙은 의외로 간단합니다. 왼쪽에서 오른쪽으로 읽되, 어떤 기호가 **바로 오른쪽 기호보다 작으면** 그 값을 빼고, 그렇지 않으면 더합니다.

**문제** 올바른 로마 숫자(1~3999)가 주어질 때 그 값을 출력하십시오.

**예제 입력 1**

```
MCMXCIV
```

**예제 출력 1**

```
1994
```

**예제 입력 2**

```
III
```

**예제 출력 2**

```
3
```

<details>
<summary>💡 힌트 보기</summary>

기호의 값을 딕셔너리로 만들고, 각 위치에서 다음 기호의 값과 비교하십시오. 마지막 기호는 언제나 더합니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
VALUE = {"I": 1, "V": 5, "X": 10, "L": 50, "C": 100, "D": 500, "M": 1000}
s = input()
total = 0
for i, ch in enumerate(s):
    v = VALUE[ch]
    if i + 1 < len(s) and v < VALUE[s[i + 1]]:
        total -= v
    else:
        total += v
print(total)
```

97번과 98번을 함께 풀면, 정수 → 로마 숫자 → 정수로 돌아왔을 때 원래 수가 나오는지 1부터 3999까지 모두 시험해 볼 수 있습니다. 서로 반대인 두 함수로 **서로를 검증하는** 방법은 실무에서도 자주 쓰입니다. `i + 1 < len(s)` 검사를 먼저 둔 것은 25번에서 배운 단락 평가 덕분에 범위를 벗어난 인덱스를 건드리지 않기 위해서입니다.

</details>

## 099. 끝말잇기 심판

끝말잇기의 규칙은 두 가지입니다. 앞 단어의 마지막 글자로 시작할 것, 그리고 이미 나온 단어를 다시 쓰지 말 것. 심판 프로그램은 규칙을 처음 어긴 순간을 정확히 짚어 내야 합니다.

**문제** 첫째 줄에 N, 이어서 N줄에 단어가 하나씩 주어집니다. 끝까지 규칙을 지켰으면 `성공`을, 그렇지 않으면 규칙을 처음 어긴 단어의 순서를 `k번째 단어에서 실패` 형식으로 출력하십시오. (두음 법칙은 적용하지 않습니다.)

**제한** 1 ≤ N ≤ 1000, 단어 길이 2 이상 10 이하

**예제 입력 1**

```
4
기차
차표
표범
범인
```

**예제 출력 1**

```
성공
```

**예제 입력 2**

```
4
우유
유리
리우
우유
```

**예제 출력 2**

```
4번째 단어에서 실패
```

<details>
<summary>💡 힌트 보기</summary>

이미 나온 단어는 집합에 넣어 두고, 각 단어마다 '앞 단어의 끝 글자와 첫 글자 비교'와 '집합에 있는지'를 검사하십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
used = set()
prev = None
result = "성공"
for k in range(1, n + 1):
    w = input()
    if (prev is not None and prev[-1] != w[0]) or w in used:
        result = f"{k}번째 단어에서 실패"
        break
    used.add(w)
    prev = w
print(result)
```

첫 단어에는 앞 단어가 없으므로 `prev is not None` 검사가 필요합니다. 처음과 끝을 따로 생각하는 습관이 버그를 막습니다. 주의할 점이 있습니다. 실패한 뒤에 `break`하면 남은 입력을 읽지 않게 됩니다. 이 문제는 출력이 하나뿐이라 괜찮지만, 여러 사례를 연달아 처리하는 문제에서는 남은 줄을 마저 읽어야 다음 사례가 어긋나지 않습니다.

</details>

## 100. 가계부 결산

기초편의 마지막 문제입니다. 입력을 쪼개고, 딕셔너리에 모으고, 정렬하고, 서식에 맞춰 출력하는, 지금까지 익힌 모든 기술을 하나의 작은 프로그램에 담아 봅니다.

**문제** 첫째 줄에 N, 이어서 N줄에 `MM-DD 항목 금액`이 주어집니다(수입은 양수, 지출은 음수). 다음을 차례로 출력하십시오.

1. 항목 이름의 사전 순서로, 항목마다 `항목 합계`
2. `잔액 전체합계`
3. 지출(음수 금액)의 합이 가장 큰 날을 `최대 지출일 MM-DD (지출액)`. 같은 날이 여럿이면 이른 날짜, 지출이 전혀 없으면 `최대 지출일 없음`

모든 금액은 세 자리마다 쉼표를 넣고, 지출액은 양수로 나타냅니다.

**제한** 1 ≤ N ≤ 1000, 날짜는 같은 해, |금액| ≤ 10⁸

**예제 입력**

```
6
11-01 월급 2500000
11-02 식비 -12000
11-02 교통 -1450
11-05 식비 -30000
11-05 도서 -18000
11-07 식비 -9000
```

**예제 출력**

```
교통 -1,450
도서 -18,000
식비 -51,000
월급 2,500,000
잔액 2,429,550
최대 지출일 11-05 (48,000)
```

<details>
<summary>💡 힌트 보기</summary>

딕셔너리 두 개를 쓰십시오. 하나는 항목별 합계, 다른 하나는 날짜별 지출 합계입니다. 최대 지출일은 `(-지출액, 날짜)`가 가장 작은 것을 고르면 동점 처리까지 한 번에 됩니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
by_item, spent = {}, {}
for _ in range(n):
    day, item, amount = input().split()
    amount = int(amount)
    by_item[item] = by_item.get(item, 0) + amount
    if amount < 0:
        spent[day] = spent.get(day, 0) - amount
for item in sorted(by_item):
    print(f"{item} {by_item[item]:,}")
print(f"잔액 {sum(by_item.values()):,}")
if spent:
    day = min(spent, key=lambda d: (-spent[d], d))
    print(f"최대 지출일 {day} ({spent[day]:,})")
else:
    print("최대 지출일 없음")
```

`MM-DD` 형식은 자릿수가 고정되어 있어 문자열 비교만으로 날짜 순서가 맞습니다. 2번 문제에서 본 ISO 8601의 장점이 여기서 쓰입니다. `min(딕셔너리, key=…)`는 키들 가운데 기준값이 가장 작은 키를 돌려줍니다. 한글 항목 이름은 유니코드 순서로 정렬되며, 이것은 가나다순과 같습니다. 기초편을 마친 것을 축하합니다. 이제 제2부에서 이 도구들로 **알고리즘**을 만들어 봅니다.

</details>
