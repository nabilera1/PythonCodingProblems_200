## 031. 유클리드 호제법

유클리드 『원론』 제7권에는 두 수의 최대공약수를 구하는 방법이 실려 있습니다. 큰 수를 작은 수로 나눈 나머지로 바꾸는 일을 나머지가 0이 될 때까지 되풀이하는 것입니다. 2천 년이 넘도록 쓰이는, 기록에 남은 가장 오래된 알고리즘 가운데 하나입니다.

**문제** 두 자연수 a, b의 최대공약수를 **`while` 문으로** 구해 출력하십시오.

**제한** 1 ≤ a, b ≤ 10¹⁸

**예제 입력 1**

```
1071 1029
```

**예제 출력 1**

```
21
```

**예제 입력 2**

```
12 18
```

**예제 출력 2**

```
6
```

<details>
<summary>💡 힌트 보기</summary>

gcd(a, b) = gcd(b, a % b)이고, gcd(a, 0) = a입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
a, b = map(int, input().split())
while b:
    a, b = b, a % b
print(a)
```

`a, b = b, a % b`는 오른쪽을 모두 계산한 뒤에 한꺼번에 대입하므로 임시 변수가 필요 없습니다. `while b:`는 b가 0이 아닌 동안 반복한다는 뜻입니다. 마지막 숨은 테스트의 832040과 514229는 이웃한 피보나치 수입니다. 호제법이 가장 오래 걸리는 최악의 입력으로, 1844년 라메가 이를 증명했습니다. 그래도 수십 번이면 끝납니다. 표준 라이브러리에는 `math.gcd`가 있습니다.

</details>

## 032. 196의 수수께끼

어떤 수에 그 수를 뒤집은 수를 더하는 일을 되풀이하면 대개 금방 회문수가 됩니다(예: 57 + 75 = 132, 132 + 231 = 363). 그런데 196은 컴퓨터로 수억 번을 되풀이해도 회문수가 되지 않았고, 끝내 되지 않는지는 아직 아무도 증명하지 못했습니다. 그 첫걸음은 수를 뒤집는 일입니다.

**문제** 자연수 n을 뒤집은 수를 출력하십시오. 앞자리의 0은 사라집니다(예: 1200 → 21). 단, **문자열로 바꾸지 말고** `%`와 `//`만 쓰십시오.

**제한** 1 ≤ n ≤ 10¹⁸

**예제 입력 1**

```
12345
```

**예제 출력 1**

```
54321
```

**예제 입력 2**

```
1200
```

**예제 출력 2**

```
21
```

<details>
<summary>💡 힌트 보기</summary>

`n % 10`은 마지막 자리이고 `n // 10`은 마지막 자리를 떼어 낸 수입니다. 뒤집은 수 `r`에는 `r = r * 10 + 마지막 자리`로 한 자리씩 붙여 가십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
r = 0
while n > 0:
    r = r * 10 + n % 10
    n //= 10
print(r)
```

이 반복은 n의 자릿수만큼 돌기 때문에, 반복 횟수를 미리 알 수 없을 때 `while`이 알맞습니다. 문자열로는 `int(str(n)[::-1])` 한 줄이면 되며, 앞자리 0은 `int()`가 알아서 없애 줍니다. 두 방법 모두 알아 두십시오.

</details>

## 033. 72의 법칙

'원금이 두 배가 되는 데 걸리는 햇수는 72를 연이율(%)로 나눈 값과 비슷하다.' 1494년 루카 파치올리의 책에도 실린, 오래된 어림셈입니다. 복리가 얼마나 무서운지를 이 법칙만큼 간결하게 보여 주는 것도 드뭅니다.

**문제** 원금 P, 연이율 r(%, 정수), 목표 금액 T가 주어집니다. 해마다 복리로 이자가 붙을 때 잔액이 **처음으로 T 이상**이 되는 햇수를 출력하십시오. 처음부터 P ≥ T이면 0을 출력합니다.

**제한** 1 ≤ P, T ≤ 10⁹, 1 ≤ r ≤ 100

**예제 입력 1**

```
100 5 200
```

**예제 출력 1**

```
15
```

**예제 입력 2**

```
1000 10 2000
```

**예제 출력 2**

```
8
```

<details>
<summary>💡 힌트 보기</summary>

반복 횟수를 미리 알 수 없으니 `while 잔액 < 목표:` 형태가 알맞습니다. 해마다 잔액에 `(1 + r / 100)`을 곱하십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
p, r, t = map(int, input().split())
money, years = p, 0
while money < t:
    money *= 1 + r / 100
    years += 1
print(years)
```

이율 5%이면 72 ÷ 5 = 14.4, 실제로는 15년째에 두 배를 넘습니다. 72의 법칙이 꽤 정확하다는 것을 확인할 수 있습니다. `while`은 조건을 먼저 검사하므로 처음부터 목표에 이르렀다면 한 번도 돌지 않고 0을 출력합니다. 수학적으로는 log(T/P) / log(1 + r/100)을 올림한 값과 같지만, 실수 오차 때문에 경계에서 어긋날 수 있어 반복이 더 믿을 만합니다.

</details>

## 034. 소수 판별과 while-else

1보다 큰 자연수 중 1과 자기 자신만을 약수로 가지는 수를 소수라 합니다. 1은 소수도 합성수도 아닙니다. 이렇게 약속해야 '모든 자연수는 소수의 곱으로 **단 한 가지 방법으로** 나타낼 수 있다'는 산술의 기본 정리가 깔끔하게 성립하기 때문입니다.

**문제** 자연수 n이 주어질 때 `소수`, `합성수`, `소수도 합성수도 아님` 중 하나를 출력하십시오.

**제한** 1 ≤ n ≤ 2×10⁹

**예제 입력 1**

```
97
```

**예제 출력 1**

```
소수
```

**예제 입력 2**

```
1
```

**예제 출력 2**

```
소수도 합성수도 아님
```

<details>
<summary>💡 힌트 보기</summary>

n이 합성수라면 √n 이하의 약수를 반드시 가집니다. 그러니 `i * i <= n`인 동안만 나누어 보면 됩니다. 약수를 찾으면 `break`로 빠져나오십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
if n < 2:
    print("소수도 합성수도 아님")
else:
    i = 2
    while i * i <= n:
        if n % i == 0:
            print("합성수")
            break
        i += 1
    else:
        print("소수")
```

반복문에 붙은 `else`는 **`break` 없이 끝까지 돌았을 때만** 실행됩니다. 그래서 '끝까지 약수를 찾지 못했다'를 따로 표시하는 변수가 필요 없습니다. 다른 언어에는 드문 파이썬만의 문법입니다. 2부터 n−1까지 나누면 20억 번이 걸리지만, √n까지만 나누면 약 4만 5천 번으로 끝납니다.

</details>

## 035. 0이 나올 때까지

입력이 몇 개인지 미리 알려 주지 않고, 끝에 약속된 값(보초값, sentinel)을 두어 끝을 알리는 방식이 있습니다. 옛 천공 카드 시절부터 쓰인 관례입니다.

**문제** 한 줄에 하나씩 정수가 주어지며, 마지막 줄은 `0`입니다. 0을 제외한 수들의 **개수와 합**을 공백으로 구분해 출력하십시오.

**예제 입력 1**

```
5
3
-2
0
```

**예제 출력 1**

```
3 6
```

**예제 입력 2**

```
0
```

**예제 출력 2**

```
0 0
```

<details>
<summary>💡 힌트 보기</summary>

'읽고, 0인지 검사하고, 처리하고'를 되풀이합니다. 바다코끼리 연산자 `:=`를 쓰면 읽기와 검사를 한 줄로 합칠 수 있습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
count = total = 0
while (x := int(input())) != 0:
    count += 1
    total += x
print(count, total)
```

`:=`는 값을 변수에 담으면서 동시에 그 값을 돌려주는 **대입 표현식**입니다(파이썬 3.8부터). 옆으로 누운 모습이 바다코끼리의 눈과 엄니를 닮아 그런 별명이 붙었습니다. 이 연산자가 없을 때는 `while True:` 안에서 읽은 뒤 `if x == 0: break`로 빠져나가는 방식을 썼습니다. 두 방법 모두 알아 두십시오.

</details>
