## 196. 히스토그램의 가장 큰 직사각형

폭이 1인 막대들이 나란히 선 히스토그램 안에 들어가는 가장 큰 직사각형을 찾는 문제는 단조 스택의 백미입니다. 막대마다 '나보다 낮은 막대를 만날 때까지 양옆으로 얼마나 넓힐 수 있는가'를 134번의 기법으로 한 번에 구합니다.

**문제** N개의 막대 높이가 주어질 때 히스토그램 안에 그릴 수 있는 가장 넓은 직사각형의 넓이를 구하십시오.

**입력** 첫째 줄에 N, 둘째 줄에 N개의 높이가 주어집니다.

**출력** 최대 넓이를 출력합니다.

**제한** 1 ≤ N ≤ 2×10⁵, 0 ≤ 높이 ≤ 10⁹, 시간 제한 3초

**예제 입력 1**

```
7
2 1 4 5 1 3 3
```

**예제 출력 1**

```
8
```

**예제 입력 2**

```
4
1000 1000 1000 1000
```

**예제 출력 2**

```
4000
```

<details>
<summary>💡 힌트 보기</summary>

높이가 증가하는 막대들의 인덱스를 스택에 쌓습니다. 더 낮은 막대가 오면 스택에서 꺼내는 막대의 높이로 직사각형을 계산하는데, 폭은 '지금 위치'와 '꺼낸 뒤 스택 맨 위 위치' 사이입니다. 끝에 높이 0인 막대를 하나 덧붙이면 남은 막대도 모두 처리됩니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
input = sys.stdin.readline
n = int(input())
h = list(map(int, input().split())) + [0]
stack = [-1]
best = 0
for i, x in enumerate(h):
    while len(stack) > 1 and h[stack[-1]] >= x:
        top = h[stack.pop()]
        width = i - stack[-1] - 1
        if top * width > best:
            best = top * width
    stack.append(i)
print(best)
```

스택 바닥에 −1을 '보초'로 두면 스택이 빌 때의 폭 계산(i − (−1) − 1 = i)을 따로 처리하지 않아도 됩니다. 끝에 덧붙인 높이 0의 막대도 같은 역할을 하는 보초입니다. **보초값**은 경계 처리를 없애는 강력한 기법입니다. 예제 1의 답 8은 높이 4, 5인 막대 위의 4 × 2입니다. 각 인덱스가 스택에 한 번 들어가고 한 번 나오므로 O(N)입니다. 이 문제는 2차원 격자에서 '1로만 된 가장 큰 직사각형' 문제의 부품으로도 쓰입니다. 행마다 위로 이어진 1의 높이로 히스토그램을 만들면 됩니다.

</details>

## 197. 벽을 K번 부술 수 있다면

BFS의 상태가 '위치'만이 아니라 '위치와 지금까지 부순 벽의 수'라면 어떨까요? 상태를 늘린 그래프에서 BFS를 하면 됩니다. 상태 공간을 설계하는 능력은 고급 탐색 문제의 핵심입니다.

**문제** R×C 격자에서 `0`은 빈칸, `1`은 벽입니다. 왼쪽 위에서 오른쪽 아래까지 상하좌우로 한 칸씩 움직이는데, 이동 중에 벽을 최대 K개까지 부수고 지나갈 수 있습니다. 최소 이동 횟수를 구하고, 불가능하면 −1을 출력하십시오.

**입력** 첫째 줄에 R, C, K, 이어서 R줄에 격자가 주어집니다.

**출력** 최소 이동 횟수 또는 −1을 출력합니다.

**제한** 1 ≤ R, C ≤ 300, 0 ≤ K ≤ 5, 시작 칸과 도착 칸은 `0`, 시간 제한 4초

**예제 입력 1**

```
4 4 1
0100
1110
1000
0110
```

**예제 출력 1**

```
6
```

**예제 입력 2**

```
3 3 0
010
111
010
```

**예제 출력 2**

```
-1
```

<details>
<summary>💡 힌트 보기</summary>

dist[k][x][y] = 벽을 k개 부수고 (x, y)에 도착한 최소 이동 횟수. 빈칸으로는 같은 k로, 벽으로는 k+1로 이동합니다(k < K일 때만). BFS이므로 처음 도착했을 때가 최소입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
from collections import deque
input = sys.stdin.readline
r, c, K = map(int, input().split())
wall = [[ch == '1' for ch in input().rstrip()] for _ in range(r)]
seen = [[[False] * c for _ in range(r)] for _ in range(K + 1)]
seen[0][0][0] = True
q = deque([(0, 0, 0)])
steps = 0
answer = -1
while q and answer < 0:
    for _ in range(len(q)):
        x, y, k = q.popleft()
        if x == r - 1 and y == c - 1:
            answer = steps
            break
        for nx, ny in ((x + 1, y), (x - 1, y), (x, y + 1), (x, y - 1)):
            if 0 <= nx < r and 0 <= ny < c:
                nk = k + wall[nx][ny]
                if nk <= K and not seen[nk][nx][ny]:
                    seen[nk][nx][ny] = True
                    q.append((nx, ny, nk))
    steps += 1
print(answer)
```

상태는 R × C × (K+1)개로 최대 54만 개입니다. 같은 칸이라도 부순 벽의 수가 다르면 다른 상태이므로 방문 표시도 따로 해야 합니다. 이것을 하나로 합치면 '벽을 덜 부수고 늦게 온' 더 유망한 경로를 놓칩니다. 큐를 '이동 횟수'별 층으로 나누어 처리하면 거리 배열 없이도 몇 번째 층인지가 곧 이동 횟수입니다. 182번(벽을 몇 개나 부숴야 하는가)과 이 문제(정해진 개수 안에서 가장 빨리)는 같은 격자에 대한 서로 다른 질문입니다. 질문에 따라 최적화 대상이 무엇이고 제약이 무엇인지 구분하는 것이 중요합니다.

</details>

## 198. 트리의 지름

트리에서 가장 멀리 떨어진 두 정점 사이의 거리를 지름이라 합니다. 놀랍게도 두 번의 탐색이면 충분합니다. 아무 정점에서나 가장 먼 정점 u를 찾고, u에서 다시 가장 먼 정점까지의 거리를 재면 그것이 지름입니다.

**문제** N개의 정점과 가중치가 있는 N−1개의 간선으로 된 트리가 주어질 때, 지름(가장 먼 두 정점 사이의 거리)을 구하십시오.

**입력** 첫째 줄에 N, 이어서 N−1줄에 간선 a b w가 주어집니다.

**출력** 트리의 지름을 출력합니다.

**제한** 1 ≤ N ≤ 2×10⁵, 1 ≤ w ≤ 10⁴, 시간 제한 4초

**예제 입력**

```
5
1 3 2
3 4 3
4 2 4
4 5 6
```

**예제 출력**

```
11
```

<details>
<summary>💡 힌트 보기</summary>

'시작 정점에서 모든 정점까지의 거리'를 반복문으로 구하는 함수를 만드십시오. 트리에서는 경로가 하나뿐이므로 BFS 순서로 거리를 더해 가면 됩니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
data = sys.stdin.buffer.read().split()
n = int(data[0])
adj = [[] for _ in range(n + 1)]
for i in range(n - 1):
    a, b, w = int(data[1 + 3 * i]), int(data[2 + 3 * i]), int(data[3 + 3 * i])
    adj[a].append((b, w))
    adj[b].append((a, w))

def farthest(s):
    dist = [-1] * (n + 1)
    dist[s] = 0
    order = [s]
    for u in order:
        for v, w in adj[u]:
            if dist[v] < 0:
                dist[v] = dist[u] + w
                order.append(v)
    far = max(range(1, n + 1), key=dist.__getitem__)
    return far, dist[far]

u, _ = farthest(1)
print(farthest(u)[1])
```

왜 두 번이면 될까요? 아무 정점에서 가장 먼 정점 u는 반드시 어떤 지름의 한쪽 끝입니다. 그렇지 않다고 가정하면 경로를 바꿔 붙여 더 먼 정점을 만들 수 있어 모순이 생깁니다. 이 증명은 가중치가 **음수가 아닐 때만** 성립합니다. 예제의 지름은 1 → 3 → 4 → 5로 2 + 3 + 6 = 11입니다. 트리 동적 계획법(180번)으로도 풀 수 있습니다. 정점마다 '아래로 내려가는 가장 긴 두 경로의 합'을 구하면 됩니다. 한 문제를 두 가지 방법으로 풀어 보는 것은 좋은 공부입니다.

</details>

## 199. 공통 조상

가계도에서 두 사람의 가장 가까운 공통 조상(LCA)을 찾는 문제입니다. 한 칸씩 올라가면 최악의 경우 O(N)이지만, 2ᵏ칸 위의 조상을 미리 표로 만들어 두면(이진 리프팅) 큰 걸음부터 뛰어 O(log N)에 찾을 수 있습니다. 105번 빠른 거듭제곱과 같은 '2의 거듭제곱으로 쪼개기' 발상입니다.

**문제** 1번 정점을 뿌리로 하는 가중치 트리와 Q개의 질의 `u v`가 주어집니다. 각 질의마다 u와 v 사이의 거리를 출력하십시오.

**입력** 첫째 줄에 N, 이어서 N−1줄에 간선 a b w, 다음 줄에 Q, 이어서 Q줄에 u와 v가 주어집니다.

**출력** 질의마다 한 줄에 거리를 출력합니다.

**제한** 1 ≤ N, Q ≤ 5×10⁴, 1 ≤ w ≤ 10⁴, 시간 제한 4초

**예제 입력**

```
6
1 2 3
1 3 1
2 4 2
2 5 4
3 6 5
4
4 5
4 6
1 1
5 3
```

**예제 출력**

```
6
11
0
8
```

<details>
<summary>💡 힌트 보기</summary>

BFS로 깊이 depth, 부모 up[0], 뿌리로부터의 거리 dist를 구합니다. up[k][v] = up[k−1][up[k−1][v]]로 표를 채우십시오. 거리는 dist[u] + dist[v] − 2·dist[LCA]입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
data = sys.stdin.buffer.read().split()
n = int(data[0])
adj = [[] for _ in range(n + 1)]
idx = 1
for _ in range(n - 1):
    a, b, w = int(data[idx]), int(data[idx + 1]), int(data[idx + 2])
    idx += 3
    adj[a].append((b, w))
    adj[b].append((a, w))
LOG = max(1, n.bit_length())
depth = [0] * (n + 1)
dist = [0] * (n + 1)
parent = [0] * (n + 1)
parent[1] = 1
seen = [False] * (n + 1)
seen[1] = True
order = [1]
for u in order:
    for v, w in adj[u]:
        if not seen[v]:
            seen[v] = True
            parent[v] = u
            depth[v] = depth[u] + 1
            dist[v] = dist[u] + w
            order.append(v)
up = [parent]
for k in range(1, LOG):
    prev = up[-1]
    up.append([prev[prev[v]] for v in range(n + 1)])

def lca(a, b):
    if depth[a] < depth[b]:
        a, b = b, a
    diff = depth[a] - depth[b]
    k = 0
    while diff:
        if diff & 1:
            a = up[k][a]
        diff >>= 1
        k += 1
    if a == b:
        return a
    for k in range(LOG - 1, -1, -1):
        if up[k][a] != up[k][b]:
            a, b = up[k][a], up[k][b]
    return parent[a]

q = int(data[idx])
idx += 1
out = []
for _ in range(q):
    u, v = int(data[idx]), int(data[idx + 1])
    idx += 2
    out.append(dist[u] + dist[v] - 2 * dist[lca(u, v)])
print('\n'.join(map(str, out)))
```

LCA를 찾는 과정은 두 단계입니다. 먼저 더 깊은 쪽을 깊이 차이만큼 끌어올려 높이를 맞춥니다(차이를 2진수로 쪼개 뜁니다). 그다음 두 정점의 2ᵏ번째 조상이 **다를 때만** 함께 올라가면, 마지막에 둘은 LCA의 바로 아래 자식에 멈춥니다. 뿌리의 부모를 자기 자신으로 두면 표가 뿌리 위로 넘어가지 않아 경계 처리가 필요 없습니다. 거리 공식 dist[u] + dist[v] − 2·dist[LCA]는, 뿌리에서 u와 v로 가는 두 경로가 LCA까지 겹치기 때문에 그 부분을 두 번 빼는 것입니다. 숨은 테스트에는 깊이가 5만인 일자 트리도 있습니다.

</details>

## 200. 마지막 무대

이 책의 마지막 문제는 정렬(25단원), 이분 탐색(26단원), 동적 계획법(35·36단원)이 한 무대에 모두 오르는 문제입니다. 회의실 하나에 보상이 다른 공연들을 배정합니다. 156번처럼 개수가 아니라 **보상의 합**을 최대로 하려면 그리디는 통하지 않습니다.

**문제** N개의 공연이 [시작, 끝)과 보상으로 주어집니다. 한 공연이 끝나는 시각에 다음 공연이 시작할 수 있습니다. 서로 겹치지 않게 고른 공연들의 보상 합의 최댓값을 구하십시오.

**입력** 첫째 줄에 N, 이어서 N줄에 시작 시각, 끝 시각, 보상이 주어집니다.

**출력** 최대 보상 합을 출력합니다.

**제한** 1 ≤ N ≤ 2×10⁵, 0 ≤ 시작 < 끝 ≤ 10⁹, 1 ≤ 보상 ≤ 10⁹, 시간 제한 3초

**예제 입력 1**

```
4
1 3 5
2 5 6
4 6 5
6 7 4
```

**예제 출력 1**

```
14
```

**예제 입력 2**

```
3
0 10 100
0 5 60
5 10 60
```

**예제 출력 2**

```
120
```

<details>
<summary>💡 힌트 보기</summary>

공연을 끝 시각 순으로 정렬하고 D[i] = 앞의 i개 공연만 볼 때의 최대 보상이라 하십시오. i번째 공연을 고르면, 그 시작 시각 이하에 끝나는 공연들의 개수 j를 이분 탐색으로 찾아 D[j] + 보상입니다. 고르지 않으면 D[i−1]입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
from bisect import bisect_right
data = sys.stdin.buffer.read().split()
n = int(data[0])
shows = sorted(zip(map(int, data[2::3]), map(int, data[1::3]), map(int, data[3::3])))
ends = [e for e, _, _ in shows]
D = [0] * (n + 1)
for i, (e, s, w) in enumerate(shows, 1):
    j = bisect_right(ends, s, 0, i - 1)
    take = D[j] + w
    D[i] = take if take > D[i - 1] else D[i - 1]
print(D[n])
```

예제 1은 [1,3) + [4,6) + [6,7)로 5 + 5 + 4 = 14이고, 예제 2는 긴 공연 하나(100)보다 짧은 공연 둘(60 + 60)이 낫다는 것을 보여 줍니다. 156번의 '일찍 끝나는 것부터' 그리디는 보상이 다를 때 통하지 않습니다. `bisect_right(ends, s, 0, i - 1)`은 앞의 i−1개 공연 가운데 끝 시각이 s 이하인 것의 개수입니다. 끝 시각 순으로 정렬했으므로 그 공연들이 정확히 앞의 j개입니다. 정렬과 이분 탐색이 동적 계획법의 '어디서 이어 받을까'를 O(log N)에 해결해 줍니다. 전체 O(N log N)입니다. 200문제를 모두 마친 것을 진심으로 축하합니다. 여기서 익힌 도구들은 정보올림피아드뿐 아니라, 앞으로 만날 모든 문제를 푸는 든든한 밑천이 될 것입니다.

</details>
