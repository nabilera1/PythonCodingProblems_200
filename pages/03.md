## 011. 바빌로니아의 60진법

한 시간이 60분, 1분이 60초인 것은 4천 년 전 바빌로니아의 60진법이 남긴 흔적입니다. 60은 약수가 열두 개나 되어 나누어 쓰기 좋은 수였습니다.

**문제** 0 이상 86400 미만의 정수 초가 주어집니다. 이를 `HH:MM:SS` 형식으로 출력하십시오. 각 자리는 두 자리로 맞춥니다.

**예제 입력 1**

```
3725
```

**예제 출력 1**

```
01:02:05
```

**예제 입력 2**

```
86399
```

**예제 출력 2**

```
23:59:59
```

<details>
<summary>💡 힌트 보기</summary>

`divmod(a, b)`는 몫과 나머지를 한꺼번에 돌려줍니다. 두 자리를 맞추는 서식은 `:02d`입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
s = int(input())
m, s = divmod(s, 60)
h, m = divmod(m, 60)
print(f"{h:02d}:{m:02d}:{s:02d}")
```

작은 단위부터 차례로 몫과 나머지를 떼어 내는 것이 진법 변환의 핵심입니다. 같은 원리로 10진수를 2진수로 바꿀 수도 있습니다. `:02d`는 '정수를 폭 2로, 빈자리는 0으로 채워서'라는 뜻입니다.

</details>

## 012. 거스름돈의 동전

가게 주인은 거스름돈을 줄 때 큰 동전부터 집습니다. 이처럼 매 순간 가장 커 보이는 것을 고르는 전략을 **탐욕 알고리즘(greedy)** 이라 하며, 이 책의 제3부에서 다시 만나게 됩니다.

**문제** 1000원을 내고 N원짜리 물건을 샀습니다. 500원, 100원, 50원, 10원 동전으로 거스름돈을 가장 적은 개수로 줄 때, 각 동전의 개수를 차례로 출력하십시오.

**제한** 10 ≤ N ≤ 1000, N은 10의 배수

**예제 입력**

```
370
```

**예제 출력**

```
1 1 0 3
```

<details>
<summary>💡 힌트 보기</summary>

거스름돈을 500으로 나눈 몫이 500원 동전의 개수입니다. 남은 금액으로 같은 일을 되풀이하십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
change = 1000 - int(input())
counts = []
for coin in (500, 100, 50, 10):
    q, change = divmod(change, coin)
    counts.append(q)
print(*counts)
```

`print(*counts)`의 별표는 리스트를 풀어서 각 원소를 따로따로 넘겨 줍니다. 그래서 공백으로 구분되어 출력됩니다. 탐욕 전략이 언제나 최적인 것은 아닙니다. 동전이 1, 3, 4원뿐이라면 6원을 탐욕법으로 거슬러 주면 4+1+1(3개)이 되지만, 3+3(2개)이 더 적습니다. 우리나라 동전처럼 큰 단위가 작은 단위의 배수일 때만 안심하고 쓸 수 있습니다.

</details>

## 013. 체스판 위의 밀알

체스를 발명한 현자가 왕에게 보상으로, 첫 칸에 밀 한 알, 다음 칸에 두 알, 그다음 칸에 네 알… 이렇게 두 배씩 놓아 달라고 했다는 전설이 있습니다. 마지막 칸에 놓일 밀알 2⁶³개만 해도 인류가 수확한 밀을 모두 합친 것보다 많습니다.

**문제** 정수 n이 주어질 때 2ⁿ이 **몇 자리 수인지** 출력하십시오.

**제한** 0 ≤ n ≤ 10000

**예제 입력 1**

```
10
```

**예제 출력 1**

```
4
```

**예제 입력 2**

```
64
```

**예제 출력 2**

```
20
```

<details>
<summary>💡 힌트 보기</summary>

거듭제곱 연산자는 `**`입니다. 수의 자릿수는 문자열로 바꾼 뒤의 길이와 같습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
print(len(str(2 ** n)))
```

파이썬 정수는 메모리가 허락하는 한 얼마든지 커질 수 있어서 2¹⁰⁰⁰⁰(3011자리)도 정확히 계산합니다. 주의할 점이 하나 있습니다. 파이썬 3.11부터는 보안상 이유로 **4300자리를 넘는 정수를 문자열로 바꾸면 `ValueError`** 가 납니다(`sys.set_int_max_str_digits()`로 한도를 조절할 수 있습니다). 수학적으로는 `int(n * math.log10(2)) + 1`로 문자열 변환 없이 구할 수도 있습니다.

</details>

## 014. 반올림의 함정

파이썬에서 `round(2.5)`를 실행하면 3이 아니라 2가 나옵니다. 오류가 아닙니다. 끝자리가 정확히 5일 때 짝수 쪽으로 보내는 **은행가의 반올림**이 국제 표준 IEEE 754의 기본 규칙이기 때문입니다. 이렇게 하면 반올림을 여러 번 해도 오차가 한쪽으로 쌓이지 않습니다.

**문제** 0 이상의 실수 x(소수점 아래 최대 두 자리)가 주어집니다. 우리가 학교에서 배운 **사사오입** 방식으로 반올림한 정수를 출력하십시오.

**제한** 0 ≤ x < 10⁶

**예제 입력 1**

```
2.5
```

**예제 출력 1**

```
3
```

**예제 입력 2**

```
2.4
```

**예제 출력 2**

```
2
```

<details>
<summary>💡 힌트 보기</summary>

0.5를 더한 뒤 소수 부분을 버리면 어떻게 될까요?

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
x = float(input())
print(int(x + 0.5))
```

음이 아닌 수라면 `int(x + 0.5)`가 사사오입입니다. 음수까지 다루려면 `math.floor(x + 0.5)`가 필요합니다. 돈 계산처럼 엄밀해야 할 때는 `decimal` 모듈의 `ROUND_HALF_UP`을 씁니다. 실수는 2진수로 저장되므로 `round(2.675, 2)`가 2.68이 아니라 2.67이 되는 것과 같은 일도 생깁니다.

</details>

## 015. 자릿수의 합

어떤 수의 각 자릿수를 더한 값은 그 수를 9로 나눈 나머지와 깊은 관련이 있습니다. 옛 회계사들이 장부를 검산할 때 쓴 '구거법(九去法)'이 바로 이 성질을 이용한 것입니다.

**문제** 최대 100자리인 양의 정수가 주어질 때 각 자릿수의 합을 출력하십시오.

**예제 입력 1**

```
1234
```

**예제 출력 1**

```
10
```

**예제 입력 2**

```
1000000007
```

**예제 출력 2**

```
8
```

<details>
<summary>💡 힌트 보기</summary>

입력을 정수로 바꾸지 말고 문자열 그대로 한 글자씩 살펴보십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
print(sum(map(int, input())))
```

문자열은 글자들의 나열이므로 `map(int, "1234")`는 1, 2, 3, 4를 차례로 내놓습니다. 정수로 풀고 싶다면 `while n: total += n % 10; n //= 10`처럼 10으로 나눈 나머지를 반복해 떼어 내면 됩니다. 두 방법을 모두 써 보는 것을 권합니다.

</details>
