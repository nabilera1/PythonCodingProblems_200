## 021. 세 후보의 결선

토너먼트는 둘씩 겨루어 이긴 쪽만 다음 판으로 올리는 방식입니다. 세 수 가운데 가장 큰 수를 찾는 일도 이와 같습니다. 두 수를 먼저 겨루게 하고, 이긴 수를 남은 하나와 다시 겨루게 하면 됩니다.

**문제** 한 줄에 정수 세 개가 주어집니다. 내장 함수 `max()`를 **쓰지 말고** 가장 큰 수를 출력하십시오.

**제한** −10⁹ ≤ 각 수 ≤ 10⁹

**예제 입력 1**

```
3 7 5
```

**예제 출력 1**

```
7
```

**예제 입력 2**

```
-1 -5 -3
```

**예제 출력 2**

```
-1
```

<details>
<summary>💡 힌트 보기</summary>

변수 `best`에 첫 번째 수를 담아 두고, 나머지 두 수와 차례로 비교하며 더 큰 쪽으로 바꾸어 가십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
a, b, c = map(int, input().split())
best = a
if b > best:
    best = b
if c > best:
    best = c
print(best)
```

`if`-`elif`로 여섯 가지 순서를 모두 따지는 풀이는 수가 늘어나면 감당할 수 없습니다. '지금까지의 최댓값'을 들고 다니며 하나씩 비교하는 방식은 수가 백만 개가 되어도 그대로 통합니다. 반복문과 리스트를 배우면 이 방식이 `for x in nums: if x > best: best = x`로 바뀝니다. 실전에서는 물론 `max(a, b, c)`를 쓰면 됩니다.

</details>

## 022. 데카르트의 사분면

1637년 데카르트는 『방법서설』의 부록 「기하학」에서 도형을 수의 쌍으로 나타내는 길을 열었습니다. 두 축이 평면을 네 조각으로 나누는데, 오른쪽 위에서부터 시계 반대 방향으로 제1, 2, 3, 4사분면이라 부릅니다.

**문제** 점의 좌표 `x y`(정수)가 주어집니다. 점이 속한 사분면의 번호를 출력하십시오. 점이 축 위에 있으면 `축 위`를 출력합니다.

**예제 입력 1**

```
3 5
```

**예제 출력 1**

```
1
```

**예제 입력 2**

```
0 -2
```

**예제 출력 2**

```
축 위
```

<details>
<summary>💡 힌트 보기</summary>

축 위인 경우를 먼저 걸러 내면, 남은 경우는 x의 부호와 y의 부호만으로 정해집니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
x, y = map(int, input().split())
if x == 0 or y == 0:
    print("축 위")
elif x > 0:
    print(1 if y > 0 else 4)
else:
    print(2 if y > 0 else 3)
```

`A if 조건 else B`는 **조건 표현식**입니다. 값 하나를 고르는 짧은 분기는 이렇게 한 줄로 쓰면 읽기 좋습니다. 바깥 조건으로 x의 부호를 나누고 안쪽에서 y의 부호를 나누는 구조가 곧 **중첩 조건**입니다.

</details>

## 023. 가위바위보의 산술

가위는 보를, 보는 바위를, 바위는 가위를 이깁니다. 이렇게 물고 물리는 관계를 순환이라 합니다. 순환은 나머지 연산과 잘 어울립니다.

**문제** 두 줄에 걸쳐 A와 B가 낸 것(`가위`, `바위`, `보` 중 하나)이 주어집니다. `A 승`, `B 승`, `무승부` 중 하나를 출력하십시오.

**예제 입력 1**

```
가위
보
```

**예제 출력 1**

```
A 승
```

**예제 입력 2**

```
바위
바위
```

**예제 출력 2**

```
무승부
```

<details>
<summary>💡 힌트 보기</summary>

`가위`, `바위`, `보`에 차례로 0, 1, 2를 붙여 보십시오. 이기는 쪽은 언제나 상대보다 1이 큰 쪽입니다(3으로 나눈 나머지 기준).

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
hands = ["가위", "바위", "보"]
a = hands.index(input())
b = hands.index(input())
d = (b - a) % 3
if d == 0:
    print("무승부")
elif d == 1:
    print("B 승")
else:
    print("A 승")
```

아홉 가지 경우를 `if`로 모두 나열해도 답은 나옵니다. 하지만 번호를 붙이면 승패가 `(b - a) % 3`이라는 수 하나로 정리됩니다. 파이썬의 `%`는 음수에도 0, 1, 2 중 하나를 돌려주므로 `(0 - 2) % 3 == 1`처럼 경계에서도 안전합니다. 이처럼 **규칙을 수로 바꾸는 눈**은 경시 문제에서 큰 힘이 됩니다.

</details>

## 024. 놀이기구와 드모르간

19세기 영국의 수학자 오거스터스 드모르간은 '그리고'와 '또는'을 부정할 때 둘이 서로 자리를 바꾼다는 법칙을 정리했습니다. 'A이고 B이다'의 부정은 'A가 아니거나 B가 아니다'입니다.

**문제** 어느 놀이기구는 **키가 120cm 이상이고, 나이가 10세 이상이거나 보호자가 함께 있어야** 탈 수 있습니다. 한 줄에 키(정수), 나이(정수), 보호자 동반 여부(`Y` 또는 `N`)가 주어질 때 `탑승 가능` 또는 `탑승 불가`를 출력하십시오.

**예제 입력 1**

```
130 9 Y
```

**예제 출력 1**

```
탑승 가능
```

**예제 입력 2**

```
119 15 Y
```

**예제 출력 2**

```
탑승 불가
```

<details>
<summary>💡 힌트 보기</summary>

`split()`으로 나눈 뒤 앞의 두 값만 정수로 바꾸십시오. `and`가 `or`보다 먼저 묶이므로 괄호가 필요합니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
h, a, g = input().split()
h, a = int(h), int(a)
if h >= 120 and (a >= 10 or g == "Y"):
    print("탑승 가능")
else:
    print("탑승 불가")
```

'탑승 불가' 조건을 직접 쓰고 싶다면 드모르간 법칙으로 뒤집으면 됩니다. `h < 120 or (a < 10 and g != "Y")`가 됩니다. 괄호를 빠뜨리면 `h >= 120 and a >= 10 or g == "Y"`로 읽혀서, 키가 아무리 작아도 보호자만 있으면 탈 수 있는 위험한 놀이기구가 됩니다.

</details>

## 025. 단락 평가

`A and B`에서 A가 거짓이면 파이썬은 B를 아예 계산하지 않습니다. 결과가 이미 거짓으로 정해졌기 때문입니다. 이를 **단락 평가(short-circuit evaluation)** 라 하며, 위험한 계산 앞에 안전 점검을 세워 두는 데 쓰입니다.

**문제** 정수 a와 b가 주어집니다. b가 a의 약수이면 `약수`, 아니면 `약수 아님`을 출력하십시오. **b는 0일 수도 있으며**, 0은 어떤 수의 약수도 아닙니다.

**예제 입력 1**

```
12 3
```

**예제 출력 1**

```
약수
```

**예제 입력 2**

```
12 0
```

**예제 출력 2**

```
약수 아님
```

<details>
<summary>💡 힌트 보기</summary>

`a % 0`은 `ZeroDivisionError`를 일으킵니다. 나머지를 계산하기 전에 b가 0이 아닌지 먼저 확인하십시오. 순서가 핵심입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
a, b = map(int, input().split())
print("약수" if b != 0 and a % b == 0 else "약수 아님")
```

`b != 0`이 거짓이면 `a % b`는 계산되지 않으므로 오류가 나지 않습니다. 두 조건의 순서를 바꾸면 곧바로 오류가 납니다. 0은 7로 나누어떨어지므로(0 = 7 × 0) 7은 0의 약수라는 점도 확인해 보십시오.

</details>
