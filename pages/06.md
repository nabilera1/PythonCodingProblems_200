## 026. 어린 가우스의 덧셈

전해 오는 이야기에 따르면, 수업 시간에 1부터 100까지 더하라는 과제를 받은 어린 가우스는 곧바로 5050이라 답했습니다. 1+100, 2+99, …처럼 짝을 지으면 101이 50쌍이라는 것을 꿰뚫어 본 것입니다.

**문제** 자연수 n이 주어질 때 1부터 n까지의 합을 **`for` 문으로** 구해 출력하십시오.

**제한** 1 ≤ n ≤ 10⁶

**예제 입력 1**

```
100
```

**예제 출력 1**

```
5050
```

**예제 입력 2**

```
10
```

**예제 출력 2**

```
55
```

<details>
<summary>💡 힌트 보기</summary>

`range(1, n + 1)`은 1부터 n까지를 만듭니다. 끝값은 포함되지 않는다는 점에 주의하십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
total = 0
for i in range(1, n + 1):
    total += i
print(total)
```

`range(a, b)`가 b를 포함하지 않는 **반열린 구간**인 덕분에 `range(0, n)`은 정확히 n개를 만들고, 구간을 이어 붙여도 겹치는 곳이 생기지 않습니다. 가우스의 방법을 따르면 `n * (n + 1) // 2` 한 줄로 끝나며, n이 10¹⁸이어도 즉시 답이 나옵니다. 반복보다 생각이 빠른 경우입니다.

</details>

## 027. 구구단

'구구단'이라는 이름은, 옛 중국에서 이 표를 9×9=81부터 거꾸로 외웠던 데서 왔다고 전해집니다.

**문제** 정수 n이 주어질 때 n단을 `n x i = 결과` 형식으로 i = 1부터 9까지 아홉 줄에 걸쳐 출력하십시오.

**제한** 1 ≤ n ≤ 19

**예제 입력**

```
7
```

**예제 출력**

```
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
```

<details>
<summary>💡 힌트 보기</summary>

반복 변수 `i`를 f-string 안에서 그대로 쓸 수 있습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
for i in range(1, 10):
    print(f"{n} x {i} = {n * i}")
```

f-string의 중괄호 안에는 변수뿐 아니라 `n * i` 같은 **식**도 넣을 수 있습니다. 곱셈 기호로 알파벳 `x`를 쓰는 것은 키보드로 입력하기 쉽게 하려는 관례입니다.

</details>

## 028. 크람프의 느낌표

1부터 n까지 모두 곱한 값을 n의 계승(팩토리얼)이라 합니다. 1808년 프랑스의 수학자 크리스티앙 크람프가 이를 `n!`로 적자고 제안했습니다. 놀라움을 나타내는 기호를 고른 것이 잘 어울립니다. 계승은 놀라울 만큼 빠르게 커지기 때문입니다.

**문제** 정수 n이 주어질 때 n!을 출력하십시오. 0! = 1로 약속합니다.

**제한** 0 ≤ n ≤ 100

**예제 입력 1**

```
5
```

**예제 출력 1**

```
120
```

**예제 입력 2**

```
0
```

**예제 출력 2**

```
1
```

<details>
<summary>💡 힌트 보기</summary>

합을 구할 때 0에서 시작했다면, 곱을 구할 때는 무엇에서 시작해야 할까요?

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
result = 1
for i in range(2, n + 1):
    result *= i
print(result)
```

곱셈의 항등원 1에서 출발하면 n = 0일 때 반복이 한 번도 돌지 않아 자연스럽게 1이 나옵니다. 0! = 1이라는 약속이 코드 속에서도 자연스럽게 맞아떨어집니다. 20!까지는 64비트 정수에 들어가지만 21!부터는 넘칩니다. 파이썬은 신경 쓰지 않아도 됩니다. 표준 라이브러리에는 `math.factorial(n)`이 있습니다.

</details>

## 029. range의 세 번째 인자

`range(start, stop, step)`의 세 번째 인자는 보폭입니다. 보폭이 음수이면 거꾸로 걷습니다. 다만 끝값 stop은 언제나 포함되지 않습니다.

**문제** 정수 a, b, s가 주어집니다. a에서 시작해 s씩 더해 가며 **b를 넘지 않는(b 포함)** 수들을 한 줄에 공백으로 구분해 출력하십시오. s가 음수이면 거꾸로 셉니다. 해당하는 수가 하나도 없으면 빈 줄을 출력합니다.

**제한** −1000 ≤ a, b ≤ 1000, s ≠ 0

**예제 입력 1**

```
1 10 3
```

**예제 출력 1**

```
1 4 7 10
```

**예제 입력 2**

```
10 1 -3
```

**예제 출력 2**

```
10 7 4 1
```

<details>
<summary>💡 힌트 보기</summary>

b를 포함하려면 stop을 b에서 '보폭 방향으로 한 칸' 더 간 곳으로 잡아야 합니다. 보폭이 양수일 때와 음수일 때 그 한 칸의 방향이 다릅니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
a, b, s = map(int, input().split())
stop = b + 1 if s > 0 else b - 1
print(*range(a, stop, s))
```

`range(10, 1, -3)`은 10, 7, 4에서 멈추므로 1을 넣으려면 stop을 0으로 잡아야 합니다. 그래서 음수 보폭일 때는 `b - 1`입니다. `print(*range(...))`는 범위가 비어 있으면 아무 인자도 받지 않아 빈 줄만 출력합니다. 별도의 처리가 필요 없습니다.

</details>

## 030. 28의 약수

피타고라스학파는 자기 자신을 뺀 약수들의 합이 자신과 같은 수를 '완전수'라 부르며 신성하게 여겼습니다. 6 = 1+2+3, 28 = 1+2+4+7+14가 그 예입니다.

**문제** 자연수 n의 모든 약수를 오름차순으로 한 줄에 출력하십시오.

**제한** 1 ≤ n ≤ 10⁶

**예제 입력 1**

```
28
```

**예제 출력 1**

```
1 2 4 7 14 28
```

**예제 입력 2**

```
1
```

**예제 출력 2**

```
1
```

<details>
<summary>💡 힌트 보기</summary>

1부터 n까지 하나씩 나누어 보며 나머지가 0인 수를 모으십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
divisors = []
for d in range(1, n + 1):
    if n % d == 0:
        divisors.append(d)
print(*divisors)
```

이 방법은 n번 나눗셈을 합니다. 약수는 d와 n // d로 짝을 이루므로 √n까지만 살펴보면 짝을 함께 얻을 수 있습니다. 그러면 10¹²처럼 큰 수도 백만 번 안에 끝납니다. 이 개선은 제2부 '정수론 맛보기'에서 다룹니다. 덤으로 `sum(divisors) - n == n`인지 확인하면 완전수 판정기가 됩니다.

</details>
