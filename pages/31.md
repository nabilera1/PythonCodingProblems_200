## 151. 구간 합 질의

54번에서 만든 누적합 리스트의 진가가 드러나는 문제입니다. 질의가 20만 개라면 매번 구간을 더하는 방식으로는 수백억 번의 덧셈이 필요하지만, 누적합이 있으면 질의 하나에 뺄셈 한 번이면 됩니다.

**문제** 길이 N의 수열과 Q개의 질의가 주어집니다. 각 질의 `l r`마다 l번째부터 r번째까지(1부터 셈, 양 끝 포함) 원소의 합을 출력하십시오.

**입력** 첫째 줄에 N과 Q, 둘째 줄에 N개의 정수, 이어서 Q줄에 l과 r이 주어집니다.

**출력** 질의마다 한 줄에 답을 출력합니다.

**제한** 1 ≤ N, Q ≤ 2×10⁵, |원소| ≤ 10⁹, 1 ≤ l ≤ r ≤ N, 시간 제한 2초

**예제 입력**

```
5 3
3 -1 4 1 5
1 3
2 5
4 4
```

**예제 출력**

```
6
9
1
```

<details>
<summary>💡 힌트 보기</summary>

P[i] = 앞의 i개 원소의 합(P[0] = 0)이라 하면 l~r의 합은 P[r] − P[l−1]입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
from itertools import accumulate
data = sys.stdin.buffer.read().split()
n, q = int(data[0]), int(data[1])
P = [0] + list(accumulate(map(int, data[2:2 + n])))
idx = 2 + n
out = []
for _ in range(q):
    l, r = int(data[idx]), int(data[idx + 1])
    idx += 2
    out.append(P[r] - P[l - 1])
print("\n".join(map(str, out)))
```

전처리 O(N), 질의당 O(1)입니다. P[0] = 0을 두는 것이 핵심입니다. l = 1일 때 `P[l−1]`이 자연스럽게 0이 되어 경계를 따로 처리할 필요가 없습니다. 입력이 40만 줄에 이르므로 `sys.stdin.buffer.read().split()`으로 한꺼번에 읽어 토큰 리스트로 다루었습니다. 파이썬에서 대용량 입력을 가장 빠르게 읽는 방법입니다.

</details>

## 152. 나머지의 비둘기집

누적합 두 개의 차가 구간의 합입니다. 그렇다면 두 누적합을 K로 나눈 **나머지가 같으면** 그 사이 구간의 합은 K의 배수입니다. 구간을 세는 문제가 나머지별로 짝을 세는 문제로 바뀌는 순간입니다.

**문제** 정수 N개로 된 수열과 자연수 K가 주어집니다. 합이 K의 배수인 연속 구간의 개수를 구하십시오.

**입력** 첫째 줄에 N과 K, 둘째 줄에 N개의 정수가 주어집니다.

**출력** 구간의 개수를 출력합니다.

**제한** 1 ≤ N ≤ 2×10⁵, 1 ≤ K ≤ 10⁶, |aᵢ| ≤ 10⁹ (음수 포함), 시간 제한 2초

**예제 입력 1**

```
5 3
1 2 3 4 5
```

**예제 출력 1**

```
7
```

**예제 입력 2**

```
4 5
-5 5 -10 3
```

**예제 출력 2**

```
6
```

<details>
<summary>💡 힌트 보기</summary>

구간 [l, r]의 합은 S[r] − S[l−1]입니다. 두 누적합의 **나머지**가 같으면 무슨 일이 생길까요?

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
input = sys.stdin.readline
n, k = map(int, input().split())
cnt = [0] * k
cnt[0] = 1
s = ans = 0
for x in map(int, input().split()):
    s = (s + x) % k
    ans += cnt[s]
    cnt[s] += 1
print(ans)
```

누적합을 K로 나눈 나머지가 r인 위치가 c개 있으면, 그 가운데 두 위치를 고르는 C(c, 2)개의 구간이 모두 답이 됩니다. 위 코드는 누적합을 하나씩 만들 때마다 '앞에서 같은 나머지가 몇 번 나왔는가'를 더하므로 같은 값을 계산합니다. O(N²) 완전 탐색을 O(N)으로 줄이는 고전 기법입니다. 파이썬의 `%`는 음수에도 항상 0 이상 K 미만의 값을 돌려주기 때문에, C++에서라면 필요한 `((s % k) + k) % k` 같은 보정이 필요 없습니다.

</details>

## 153. 목표를 넘는 가장 짧은 구간

모든 원소가 양수라면 구간을 오른쪽으로 늘리면 합이 커지고, 왼쪽을 줄이면 합이 작아집니다. 이 **단조성** 덕분에 두 포인터가 각각 한 방향으로만 움직이며 모든 후보를 살펴볼 수 있습니다.

**문제** 양의 정수 N개로 된 수열에서 합이 S 이상인 연속 구간 가운데 가장 짧은 것의 길이를 구하십시오. 그런 구간이 없으면 0을 출력합니다.

**입력** 첫째 줄에 N과 S, 둘째 줄에 N개의 양의 정수가 주어집니다.

**출력** 가장 짧은 구간의 길이를 출력합니다.

**제한** 1 ≤ N ≤ 2×10⁵, 1 ≤ S ≤ 10¹⁵, 1 ≤ aᵢ ≤ 10⁴, 시간 제한 2초

**예제 입력 1**

```
8 15
5 1 3 5 10 7 4 9
```

**예제 출력 1**

```
2
```

**예제 입력 2**

```
3 100
1 2 3
```

**예제 출력 2**

```
0
```

<details>
<summary>💡 힌트 보기</summary>

오른쪽 끝 r을 하나씩 늘려 가며 합에 더하고, 합이 S 이상인 동안 길이를 기록하면서 왼쪽 끝 l을 줄이십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
input = sys.stdin.readline
n, s = map(int, input().split())
a = list(map(int, input().split()))
best = n + 1
total = l = 0
for r in range(n):
    total += a[r]
    while total >= s:
        best = min(best, r - l + 1)
        total -= a[l]
        l += 1
print(best if best <= n else 0)
```

l과 r은 각각 최대 N번만 증가하므로 이중 반복처럼 보여도 전체 O(N)입니다(134번의 분할 상환 분석과 같습니다). 단조성이 깨지는 **음수**가 섞이면 투 포인터는 쓸 수 없습니다. 그때는 누적합과 단조 덱 같은 다른 도구가 필요합니다. 기법이 성립하는 **전제 조건**을 늘 확인하십시오. 숨은 테스트의 두 번째 큰 입력은 전체 합이 S보다 작을 수도 있는 경우입니다.

</details>

## 154. K가지 맛의 아이스크림

아이스크림 가게 앞에 놓인 통들 가운데, 맛이 K가지 이하가 되도록 연속한 통들을 가장 길게 고르려 합니다. 오른쪽으로 늘릴 때 맛의 종류가 K를 넘으면 왼쪽을 줄이는 투 포인터와, 맛별 개수를 세는 딕셔너리가 짝을 이룹니다.

**문제** 길이 N의 수열에서 서로 다른 값이 K개 이하인 연속 구간 가운데 가장 긴 것의 길이를 구하십시오.

**입력** 첫째 줄에 N과 K, 둘째 줄에 N개의 정수가 주어집니다.

**출력** 가장 긴 구간의 길이를 출력합니다.

**제한** 1 ≤ K ≤ N ≤ 2×10⁵, 1 ≤ aᵢ ≤ 10⁹, 시간 제한 2초

**예제 입력**

```
9 2
1 2 1 3 4 3 3 4 5
```

**예제 출력**

```
5
```

<details>
<summary>💡 힌트 보기</summary>

`count` 딕셔너리에 구간 안의 값별 개수를 기록합니다. 오른쪽 원소를 넣은 뒤 `len(count) > K`인 동안 왼쪽 원소를 빼십시오. 개수가 0이 된 값은 딕셔너리에서 지워야 `len`이 정확합니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
input = sys.stdin.readline
n, k = map(int, input().split())
a = input().split()
count = {}
best = l = 0
for r in range(n):
    count[a[r]] = count.get(a[r], 0) + 1
    while len(count) > k:
        x = a[l]
        count[x] -= 1
        if count[x] == 0:
            del count[x]
        l += 1
    best = max(best, r - l + 1)
print(best)
```

값을 정수로 바꾸지 않고 문자열 그대로 딕셔너리 키로 썼습니다. 같은 수는 같은 문자열이므로 결과는 같고 변환 비용을 아낍니다(입력에 앞자리 0이 없다는 전제가 필요합니다). 예제의 답은 `3 4 3 3 4` 구간입니다. 딕셔너리 연산이 평균 O(1)이므로 전체 O(N)입니다.

</details>

## 155. 차분 배열

'l번째부터 r번째까지 모두 v를 더하라'는 명령이 수십만 번 쏟아집니다. 매번 구간을 직접 고치면 너무 느립니다. 누적합의 **역연산**인 차분 배열을 쓰면 명령 하나를 두 칸만 고쳐서 처리하고, 마지막에 누적합 한 번으로 결과를 복원할 수 있습니다.

**문제** 길이 N의 수열에 M개의 명령 `l r v`(l~r번째 원소에 v를 더함)를 차례로 적용한 결과를 출력하십시오.

**입력** 첫째 줄에 N과 M, 둘째 줄에 N개의 정수, 이어서 M줄에 l, r, v가 주어집니다.

**출력** 최종 수열을 한 줄에 출력합니다.

**제한** 1 ≤ N, M ≤ 2×10⁵, 1 ≤ l ≤ r ≤ N, |원소|, |v| ≤ 10⁹, 시간 제한 2초

**예제 입력**

```
5 3
1 2 3 4 5
1 3 10
2 5 -1
5 5 100
```

**예제 출력**

```
11 11 12 3 104
```

<details>
<summary>💡 힌트 보기</summary>

D[l]에 v를 더하고 D[r+1]에서 v를 빼 두면, D의 누적합이 각 위치에 더해진 총량이 됩니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
data = sys.stdin.buffer.read().split()
n, m = int(data[0]), int(data[1])
a = list(map(int, data[2:2 + n]))
D = [0] * (n + 1)
idx = 2 + n
for _ in range(m):
    l, r, v = int(data[idx]), int(data[idx + 1]), int(data[idx + 2])
    idx += 3
    D[l - 1] += v
    D[r] -= v
run = 0
for i in range(n):
    run += D[i]
    a[i] += run
print(*a)
```

차분 배열 D는 '이 위치부터 v만큼 더 높아진다, r+1부터는 다시 원래대로'를 기록합니다. 명령당 O(1), 마지막 복원 O(N)으로 전체 O(N + M)입니다. 누적합과 차분은 미적분의 적분과 미분처럼 서로 역연산입니다. 이 쌍을 2차원으로 확장하면 '직사각형 영역에 더하기'도 같은 방식으로 처리할 수 있습니다.

</details>
