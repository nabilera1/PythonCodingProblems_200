## 041. 기러기 토마토

'기러기', '토마토', 'level'처럼 앞에서 읽으나 뒤에서 읽으나 같은 말을 회문(palindrome)이라 합니다. 그리스어로 '다시 달린다'는 뜻입니다.

**문제** 공백 없는 문자열이 주어질 때 회문이면 `회문`, 아니면 `회문 아님`을 출력하십시오.

**제한** 1 ≤ 길이 ≤ 1000

**예제 입력 1**

```
기러기
```

**예제 출력 1**

```
회문
```

**예제 입력 2**

```
python
```

**예제 출력 2**

```
회문 아님
```

<details>
<summary>💡 힌트 보기</summary>

슬라이싱 `s[::-1]`은 문자열을 뒤집습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
s = input()
print("회문" if s == s[::-1] else "회문 아님")
```

`s[시작:끝:보폭]`에서 보폭이 −1이면 거꾸로 읽습니다. 시작과 끝을 비우면 처음부터 끝까지입니다. 반복문으로 풀고 싶다면 `s[i]`와 `s[-1 - i]`를 길이의 절반만큼 비교하면 됩니다. 음수 인덱스 `-1`이 마지막 글자를 가리킨다는 점을 활용합니다.

</details>

## 042. 모음의 개수

영어 알파벳 26자 가운데 a, e, i, o, u 다섯 자가 모음 글자입니다. 일상 영어에서는 글자 다섯 개 중 두 개꼴로 모음이 나옵니다.

**문제** 영어 문장 한 줄이 주어질 때 모음 글자(a, e, i, o, u)의 개수를 **대소문자 구분 없이** 세어 출력하십시오.

**예제 입력 1**

```
Hello, World!
```

**예제 출력 1**

```
3
```

**예제 입력 2**

```
rhythm
```

**예제 출력 2**

```
0
```

<details>
<summary>💡 힌트 보기</summary>

문장을 `lower()`로 모두 소문자로 바꾼 뒤, 글자마다 `in "aeiou"`로 검사하십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
s = input().lower()
count = 0
for ch in s:
    if ch in "aeiou":
        count += 1
print(count)
```

`in` 연산자는 문자열 안에 그 글자가 있는지 알려 줍니다. 위 코드는 `sum(ch in "aeiou" for ch in s)` 한 줄로 줄일 수 있습니다. `True`를 1로 더하는 셈입니다. 'The quick brown fox…'는 알파벳 26자를 모두 담은 팡그램(pangram)으로, 글꼴 견본에 쓰입니다.

</details>

## 043. 두문자어

NASA, UNESCO, PNG처럼 여러 단어의 첫 글자를 모아 만든 말을 두문자어(acronym)라 합니다. 긴 이름을 짧게 부르려는 지혜입니다.

**문제** 영어 단어들이 공백으로 구분되어 한 줄로 주어집니다(공백이 여러 개일 수도 있습니다). 각 단어의 첫 글자를 대문자로 모아 출력하십시오.

**예제 입력 1**

```
portable network graphics
```

**예제 출력 1**

```
PNG
```

**예제 입력 2**

```
as soon as possible
```

**예제 출력 2**

```
ASAP
```

<details>
<summary>💡 힌트 보기</summary>

`split()`을 인자 없이 쓰면 공백이 몇 개든, 앞뒤에 공백이 있든 알아서 단어만 골라냅니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
words = input().split()
result = ""
for w in words:
    result += w[0].upper()
print(result)
```

`split()`과 `split(" ")`의 차이를 꼭 기억하십시오. 공백 하나를 기준으로 자르는 `split(" ")`은 연속 공백 사이에서 빈 문자열을 만들어 내고, 그러면 `w[0]`에서 `IndexError`가 납니다. 한 줄로는 `print("".join(w[0] for w in input().split()).upper())`라고 쓸 수 있습니다.

</details>

## 044. 황금 벌레의 암호

1843년 에드거 앨런 포의 단편 『황금 벌레』에서 주인공은 기호로 된 암호문의 해독에 도전합니다. 영어에서 가장 자주 쓰이는 글자가 e라는 사실에서 출발해 해적의 보물 위치를 알아냅니다. 이 방법을 **빈도 분석**이라 합니다.

**문제** 문장 한 줄이 주어질 때 가장 많이 나온 알파벳 글자를 소문자로 출력하십시오. 대소문자는 구분하지 않고, 알파벳이 아닌 글자는 무시합니다. 빈도가 같으면 알파벳 순서로 앞선 글자를 출력합니다. 알파벳은 적어도 한 글자 들어 있습니다.

**예제 입력 1**

```
hello world
```

**예제 출력 1**

```
l
```

**예제 입력 2**

```
abcABC
```

**예제 출력 2**

```
a
```

<details>
<summary>💡 힌트 보기</summary>

'a'부터 'z'까지 26글자를 차례로 돌면서 `count()`로 개수를 세고, 더 많은 글자가 나올 때만 기록을 바꾸십시오. 같을 때 바꾸지 않으면 앞선 글자가 남습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
s = input().lower()
best, best_count = "", -1
for ch in "abcdefghijklmnopqrstuvwxyz":
    c = s.count(ch)
    if c > best_count:
        best, best_count = ch, c
print(best)
```

`>`를 쓰고 `>=`를 쓰지 않았기 때문에 동점일 때 먼저 본 글자, 곧 알파벳 순서가 앞선 글자가 남습니다. 비교 연산자 하나가 동점 처리 규칙을 정하는 셈입니다. `string.ascii_lowercase`에 'abc…z'가 미리 들어 있습니다. 나중에 배울 `collections.Counter`를 쓰면 더 간결해집니다.

</details>

## 045. @ 앞과 뒤

1971년 레이 톰린슨은 최초의 네트워크 전자우편을 보내면서 사용자 이름과 컴퓨터 이름 사이에 @를 넣었습니다. 영어로 'at', 곧 '어디에 있는'이라는 뜻이 딱 들어맞았기 때문입니다.

**문제** 전자우편 주소 한 줄이 주어집니다(@는 정확히 하나). 첫째 줄에 아이디(@ 앞), 둘째 줄에 도메인(@ 뒤)을 출력하십시오. **`split()`을 쓰지 말고** `find()`와 슬라이싱으로 푸십시오.

**예제 입력**

```
student@school.kr
```

**예제 출력**

```
student
school.kr
```

<details>
<summary>💡 힌트 보기</summary>

`s.find("@")`는 @의 위치(인덱스)를 돌려줍니다. 그 앞까지는 `s[:i]`, 그 뒤부터는 `s[i+1:]`입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
s = input()
i = s.find("@")
print(s[:i])
print(s[i + 1:])
```

슬라이싱 `s[a:b]`는 a번 글자부터 b번 글자 **바로 앞까지**입니다. 그래서 `s[:i]`에는 @가 들어가지 않고, `s[i+1:]`은 @ 다음 글자부터 시작합니다. 실전에서는 `user, domain = s.split("@")`가 가장 간결합니다. `find()`는 찾는 글자가 없으면 −1을 돌려주고, 비슷한 `index()`는 오류를 낸다는 차이도 알아 두십시오.

</details>
