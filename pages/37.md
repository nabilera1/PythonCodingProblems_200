## 181. 다익스트라

1956년 에츠허르 다익스트라는 암스테르담의 한 카페 테라스에서 약혼녀와 커피를 마시다가 20분 만에 이 알고리즘을 고안했다고 회고했습니다. 아직 확정되지 않은 정점 가운데 **가장 가까운 것을 확정해 나가는** 그리디입니다.

**문제** N개의 정점과 M개의 방향 간선(가중치 양수)으로 된 그래프에서, 시작 정점 S로부터 모든 정점까지의 최단 거리를 구하십시오.

**입력** 첫째 줄에 N, M, S, 이어서 M줄에 간선 u v w(u에서 v로 가는 가중치 w)가 주어집니다.

**출력** 1번부터 N번 정점까지 한 줄에 하나씩 최단 거리를 출력하되, 갈 수 없으면 `INF`를 출력합니다.

**제한** 1 ≤ N ≤ 10⁵, 0 ≤ M ≤ 2×10⁵, 1 ≤ w ≤ 10⁶, 시간 제한 3초

**예제 입력**

```
5 6 1
1 2 2
1 3 3
2 3 4
2 4 5
3 4 6
5 1 1
```

**예제 출력**

```
0
2
3
7
INF
```

<details>
<summary>💡 힌트 보기</summary>

`heapq`에 (거리, 정점)을 넣고, 꺼낸 거리가 이미 기록된 거리보다 크면 낡은 항목이므로 건너뛰십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys, heapq
data = sys.stdin.buffer.read().split()
n, m, s = int(data[0]), int(data[1]), int(data[2])
adj = [[] for _ in range(n + 1)]
for i in range(m):
    u, v, w = int(data[3 + 3 * i]), int(data[4 + 3 * i]), int(data[5 + 3 * i])
    adj[u].append((v, w))
INF = float('inf')
dist = [INF] * (n + 1)
dist[s] = 0
heap = [(0, s)]
while heap:
    d, u = heapq.heappop(heap)
    if d > dist[u]:
        continue
    for v, w in adj[u]:
        nd = d + w
        if nd < dist[v]:
            dist[v] = nd
            heapq.heappush(heap, (nd, v))
print('\n'.join('INF' if x == INF else str(x) for x in dist[1:]))
```

파이썬의 `heapq`에는 '키 감소' 연산이 없어서, 거리가 줄어들 때마다 새 항목을 넣고 낡은 항목은 꺼낼 때 무시합니다(지연 삭제). 힙의 크기는 최대 M이 되지만 시간은 O(M log M)으로 충분합니다. `if d > dist[u]: continue` 한 줄을 빠뜨리면 낡은 항목으로도 이웃을 다시 갱신하게 되어 최악의 경우 매우 느려집니다. 가중치가 모두 양수라는 조건이 그리디의 근거입니다. 음수 간선이 있으면 이미 확정한 거리가 나중에 줄어들 수 있어 다익스트라는 틀립니다. 그래서 184번이 필요합니다.

</details>

## 182. 벽 부수기의 최소 횟수

간선의 가중치가 0 또는 1뿐이라면 다익스트라의 힙 대신 **덱**(양방향 큐)으로 충분합니다. 비용 0인 이동은 덱의 앞에, 비용 1인 이동은 뒤에 넣으면, 덱은 언제나 거리 순서를 유지합니다. 이것이 0-1 BFS입니다.

**문제** R×C 격자에서 `0`은 빈칸, `1`은 벽입니다. 왼쪽 위에서 오른쪽 아래까지 상하좌우로 이동할 때, 부숴야 하는 벽의 최소 개수를 구하십시오. 벽을 부수면 그 칸을 지나갈 수 있습니다.

**입력** 첫째 줄에 R과 C, 이어서 R줄에 격자가 주어집니다.

**출력** 최소로 부숴야 하는 벽의 수를 출력합니다.

**제한** 1 ≤ R, C ≤ 700, 시작 칸과 도착 칸은 `0`, 시간 제한 4초

**예제 입력 1**

```
3 4
0011
1110
0000
```

**예제 출력 1**

```
1
```

**예제 입력 2**

```
3 3
011
111
110
```

**예제 출력 2**

```
3
```

<details>
<summary>💡 힌트 보기</summary>

덱에서 칸을 꺼내 이웃을 볼 때, 이웃이 빈칸이면 같은 비용으로 `appendleft`, 벽이면 비용 +1로 `append` 하십시오. 더 작은 비용을 찾았을 때만 갱신합니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
from collections import deque
input = sys.stdin.readline
r, c = map(int, input().split())
g = [input().rstrip() for _ in range(r)]
INF = 1 << 30
dist = [[INF] * c for _ in range(r)]
dist[0][0] = 0
dq = deque([(0, 0)])
while dq:
    x, y = dq.popleft()
    d = dist[x][y]
    for nx, ny in ((x + 1, y), (x - 1, y), (x, y + 1), (x, y - 1)):
        if 0 <= nx < r and 0 <= ny < c:
            w = 1 if g[nx][ny] == '1' else 0
            if d + w < dist[nx][ny]:
                dist[nx][ny] = d + w
                if w:
                    dq.append((nx, ny))
                else:
                    dq.appendleft((nx, ny))
print(dist[r - 1][c - 1])
```

비용은 **칸에 들어갈 때** 생기므로 간선 가중치는 '도착 칸이 벽이면 1'입니다. 이렇게 격자 문제를 그래프의 간선 가중치로 바꾸어 생각하면 알려진 알고리즘을 그대로 쓸 수 있습니다. 0-1 BFS에서는 한 칸이 덱에 여러 번 들어갈 수 있지만 각 칸의 거리는 많아야 두 번 갱신되므로 전체 O(RC)입니다. 힙을 쓰는 다익스트라(O(RC log RC))보다 빠르고 코드도 짧습니다.

</details>

## 183. 모든 쌍 최단 거리

1962년 로버트 플로이드가 발표한 알고리즘은 삼중 반복문 세 줄이 전부입니다. '정점 k를 거쳐 가는 것이 더 짧은가?'를 k = 1부터 차례로 묻는 이 방법은 동적 계획법의 아름다운 예입니다.

**문제** N개의 정점과 M개의 방향 간선(가중치 양수, 같은 쌍에 여러 간선 가능)이 주어질 때, 모든 정점 쌍 (i, j)의 최단 거리를 구하십시오.

**입력** 첫째 줄에 N과 M, 이어서 M줄에 u v w가 주어집니다.

**출력** N줄에 걸쳐 i행 j열에 i에서 j까지의 최단 거리를 출력합니다. 자기 자신은 0, 갈 수 없으면 −1입니다.

**제한** 1 ≤ N ≤ 100, 0 ≤ M ≤ 10⁴, 1 ≤ w ≤ 10⁶, 시간 제한 3초

**예제 입력**

```
4 5
1 2 4
2 3 1
1 3 7
3 1 2
4 3 1
```

**예제 출력**

```
0 4 5 -1
3 0 1 -1
2 6 0 -1
3 7 1 0
```

<details>
<summary>💡 힌트 보기</summary>

D[i][j]를 간선 가중치의 최솟값으로 초기화한 뒤(없으면 ∞, 자기 자신은 0), k = 1..N에 대해 D[i][j] = min(D[i][j], D[i][k] + D[k][j])를 모든 i, j에 적용하십시오. k가 **가장 바깥** 반복이어야 합니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
input = sys.stdin.readline
n, m = map(int, input().split())
INF = float('inf')
D = [[INF] * n for _ in range(n)]
for i in range(n):
    D[i][i] = 0
for _ in range(m):
    u, v, w = map(int, input().split())
    if w < D[u - 1][v - 1]:
        D[u - 1][v - 1] = w
for k in range(n):
    Dk = D[k]
    for i in range(n):
        dik = D[i][k]
        if dik == INF:
            continue
        D[i] = [a if a <= dik + b else dik + b for a, b in zip(D[i], Dk)]
for row in D:
    print(*(-1 if x == INF else x for x in row))
```

k번째 단계가 끝나면 D[i][j]는 '1~k번 정점만 중간에 거쳐 가는 최단 거리'가 됩니다. 이 의미 때문에 k가 바깥 반복이어야 하며, 순서를 바꾸면 틀린 답이 나옵니다. N = 100이면 100만 번 갱신입니다. 가장 안쪽 반복을 `zip`과 리스트 컴프리헨션으로 바꾸어 파이썬의 반복 비용을 크게 줄였습니다(174번과 같은 최적화). 검증용 풀이는 같은 문제를 '정점마다 다익스트라'라는 전혀 다른 방법으로 풉니다. 서로 다른 알고리즘의 답이 일치하는지 대조하는 것은 출제자의 기본 검증 방법입니다.

</details>

## 184. 음수 간선과 벨먼–포드

환율 차익 거래를 찾는 문제를 생각해 봅시다. 환율에 로그를 취해 부호를 바꾸면 '이익이 나는 환전 순환'은 '음수 사이클'이 됩니다. 1958년 무렵 벨먼과 포드가 정리한 알고리즘은 모든 간선을 N−1번 완화하고, 그다음에도 줄어드는 거리가 있으면 음수 사이클을 찾아냅니다.

**문제** N개의 정점과 M개의 방향 간선(가중치는 음수일 수 있음)이 주어집니다. 1번 정점에서 도달할 수 있는 음수 사이클이 있으면 `음수 사이클`을 출력하십시오. 그렇지 않으면 2번부터 N번 정점까지 1번에서의 최단 거리를 한 줄에 하나씩 출력하되, 갈 수 없으면 `도달 불가`를 출력하십시오.

**입력** 첫째 줄에 N과 M, 이어서 M줄에 u v w가 주어집니다.

**출력** 위의 형식대로 출력합니다.

**제한** 2 ≤ N ≤ 300, 0 ≤ M ≤ 3000, |w| ≤ 10⁴, 시간 제한 3초

**예제 입력 1**

```
3 4
1 2 4
1 3 3
2 3 -1
3 1 -2
```

**예제 출력 1**

```
4
3
```

**예제 입력 2**

```
3 4
1 2 4
1 3 3
2 3 -4
3 1 -2
```

**예제 출력 2**

```
음수 사이클
```

<details>
<summary>💡 힌트 보기</summary>

거리 배열을 ∞로 두고 dist[1] = 0. 모든 간선 (u, v, w)에 대해 dist[u]가 ∞가 아니고 dist[u] + w < dist[v]이면 갱신하는 일을 N−1번 반복합니다. N번째에도 갱신이 일어나면 음수 사이클입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
input = sys.stdin.readline
n, m = map(int, input().split())
E = [tuple(map(int, input().split())) for _ in range(m)]
INF = float('inf')
dist = [INF] * (n + 1)
dist[1] = 0
cycle = False
for it in range(n):
    changed = False
    for u, v, w in E:
        du = dist[u]
        if du != INF and du + w < dist[v]:
            dist[v] = du + w
            changed = True
    if not changed:
        break
    if it == n - 1:
        cycle = True
if cycle:
    print('음수 사이클')
else:
    print('\n'.join('도달 불가' if d == INF else str(d) for d in dist[2:]))
```

음수 사이클이 없으면 최단 경로는 정점을 많아야 N개 지나므로 간선 N−1개 이하로 이루어집니다. 그래서 N−1번 완화하면 충분하고, N번째에도 줄어든다면 무한히 줄어드는 순환이 있다는 뜻입니다. `dist[u] != INF` 검사가 '1번에서 도달할 수 있는' 음수 사이클만 찾게 해 줍니다. 숨은 테스트 두 번째는 1번에서 닿지 않는 음수 사이클이 있는 경우로, 답이 `음수 사이클`이 아니어야 합니다. 검증용 풀이는 음수 가중치에서도 동작하는 플로이드–워셜로 같은 판정을 합니다(D[v][v] < 0이면 v는 음수 사이클 위에 있습니다).

</details>

## 185. 최단 경로의 개수

내비게이션이 '같은 시간이 걸리는 경로가 3개 있습니다'라고 알려 줄 때가 있습니다. 다익스트라로 거리를 확정하면서 각 정점까지 최단 경로가 몇 개인지도 함께 세어 나갈 수 있습니다. 거리를 줄이는 이웃을 찾으면 개수를 **물려받고**, 같은 거리를 찾으면 **더합니다**.

**문제** N개의 정점과 M개의 양방향 도로(가중치 양수)가 주어질 때, 1번에서 N번까지의 최단 거리와 최단 경로의 개수(1,000,000,007로 나눈 나머지)를 공백으로 구분해 출력하십시오. 갈 수 없으면 −1을 출력합니다.

**입력** 첫째 줄에 N과 M, 이어서 M줄에 u v w가 주어집니다.

**출력** 최단 거리와 경로 수, 또는 −1을 출력합니다.

**제한** 2 ≤ N ≤ 10⁵, 0 ≤ M ≤ 2×10⁵, 1 ≤ w ≤ 10⁴, 시간 제한 3초

**예제 입력 1**

```
4 5
1 2 1
2 4 1
1 3 1
3 4 1
1 4 3
```

**예제 출력 1**

```
2 2
```

**예제 입력 2**

```
3 1
1 2 5
```

**예제 출력 2**

```
-1
```

<details>
<summary>💡 힌트 보기</summary>

다익스트라에서 `nd < dist[v]`이면 dist[v] = nd, cnt[v] = cnt[u]; `nd == dist[v]`이면 cnt[v] += cnt[u]. 개수가 확정되려면 u가 확정된 뒤에만 전파해야 합니다. 힙에서 꺼낸 낡은 항목은 건너뛰십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys, heapq
data = sys.stdin.buffer.read().split()
n, m = int(data[0]), int(data[1])
MOD = 1_000_000_007
adj = [[] for _ in range(n + 1)]
for i in range(m):
    u, v, w = int(data[2 + 3 * i]), int(data[3 + 3 * i]), int(data[4 + 3 * i])
    adj[u].append((v, w))
    adj[v].append((u, w))
INF = float('inf')
dist = [INF] * (n + 1)
cnt = [0] * (n + 1)
dist[1], cnt[1] = 0, 1
heap = [(0, 1)]
while heap:
    d, u = heapq.heappop(heap)
    if d > dist[u]:
        continue
    for v, w in adj[u]:
        nd = d + w
        if nd < dist[v]:
            dist[v] = nd
            cnt[v] = cnt[u]
            heapq.heappush(heap, (nd, v))
        elif nd == dist[v]:
            cnt[v] = (cnt[v] + cnt[u]) % MOD
print(f'{dist[n]} {cnt[n]}' if dist[n] < INF else -1)
```

이 방법이 옳은 이유는, 정점 u를 힙에서 꺼내 확정하는 시점에 u로 들어오는 모든 최단 경로가 이미 세어져 있기 때문입니다. 가중치가 양수이므로 u의 최단 경로 위의 앞 정점들은 모두 u보다 먼저 확정됩니다. 숨은 테스트 하나는 같은 두 정점 사이에 간선이 두 개씩 놓인 사슬 10만 개입니다. 경로 수가 2¹⁰⁰⁰⁰⁰가지이므로 나머지 연산이 꼭 필요합니다. 가중치가 0인 간선이 있다면 같은 거리의 정점들 사이에 순서 문제가 생겨 이 방법이 깨질 수 있습니다. 문제 조건(w ≥ 1)이 왜 중요한지 생각해 보십시오.

</details>
