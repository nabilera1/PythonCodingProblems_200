## 081. 홀수의 제곱

컴프리헨션은 수학의 집합 조건제시법 {x² | x는 홀수, x ≤ n}을 거의 그대로 옮겨 놓은 문법입니다. 파이썬은 이 표기를 1950년대 언어 SETL과 함수형 언어 하스켈에서 빌려 왔습니다.

**문제** 자연수 n이 주어질 때 n 이하인 홀수들의 제곱을 한 줄에 출력하십시오. **리스트 컴프리헨션 한 줄**로 만드십시오.

**제한** 1 ≤ n ≤ 1000

**예제 입력**

```
10
```

**예제 출력**

```
1 9 25 49 81
```

<details>
<summary>💡 힌트 보기</summary>

`[식 for 변수 in 범위 if 조건]`의 꼴입니다. `range`의 보폭을 2로 하면 조건이 필요 없습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
print(*[x * x for x in range(1, n + 1, 2)])
```

`[x * x for x in range(1, n + 1) if x % 2 == 1]`도 같은 결과를 냅니다. 다만 위 풀이처럼 범위를 처음부터 홀수만 만들면 조건 검사를 절반 아낄 수 있습니다. 컴프리헨션은 빈 리스트를 만들고 `append`하는 세 줄짜리 반복문을 한 줄로 줄여 줄 뿐 아니라, 대개 더 빠르기도 합니다.

</details>

## 082. 행렬의 전치

행렬의 행과 열을 맞바꾸는 것을 전치라 합니다. 파이썬에서는 `zip(*행렬)`이라는, 마법 같은 한 줄로 전치를 할 수 있습니다.

**문제** 첫째 줄에 R과 C, 이어서 R줄에 C개씩 정수가 주어집니다. 전치 행렬(C행 R열)을 출력하십시오.

**제한** 1 ≤ R, C ≤ 100

**예제 입력**

```
2 3
1 2 3
4 5 6
```

**예제 출력**

```
1 4
2 5
3 6
```

<details>
<summary>💡 힌트 보기</summary>

행렬을 `[input().split() for _ in range(r)]`로 읽은 뒤, `zip(*m)`이 무엇을 내놓는지 출력해 보십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
r, c = map(int, input().split())
m = [input().split() for _ in range(r)]
for col in zip(*m):
    print(*col)
```

`zip(*m)`에서 별표는 행렬의 각 행을 따로따로 `zip`에 넘깁니다. `zip(행1, 행2, …)`은 각 행의 첫 원소끼리, 둘째 원소끼리 묶어 내놓으므로, 그 결과가 곧 전치 행렬의 행입니다. 컴프리헨션으로는 `[[m[i][j] for i in range(r)] for j in range(c)]`입니다. 이중 컴프리헨션에서 **바깥 for가 먼저** 읽힌다는 점을 눈여겨보십시오.

</details>

## 083. 글자의 첫 등장

딕셔너리 컴프리헨션 `{키: 값 for …}`은 표를 한 줄로 만들어 냅니다. 같은 키가 여러 번 나오면 나중 값이 앞의 값을 덮어쓴다는 점을 기억해 두면 유용합니다.

**문제** 영어 소문자 단어가 주어질 때, 단어에 쓰인 각 글자가 **처음** 나타나는 위치(0부터)를 글자의 사전 순서로 `글자:위치` 형식으로 한 줄에 출력하십시오.

**제한** 1 ≤ 길이 ≤ 1000

**예제 입력 1**

```
banana
```

**예제 출력 1**

```
a:1 b:0 n:2
```

**예제 입력 2**

```
python
```

**예제 출력 2**

```
h:3 n:5 o:4 p:0 t:2 y:1
```

<details>
<summary>💡 힌트 보기</summary>

`{ch: w.index(ch) for ch in set(w)}` 또는, 거꾸로 훑으며 덮어쓰는 `{ch: i for i, ch in reversed(list(enumerate(w)))}`.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
w = input()
first = {ch: i for i, ch in reversed(list(enumerate(w)))}
print(" ".join(f"{ch}:{first[ch]}" for ch in sorted(first)))
```

뒤에서부터 넣으면 같은 글자는 앞쪽 위치가 나중에 들어와 덮어쓰므로 결국 **처음 위치**만 남습니다. 이 방법은 단어를 한 번만 훑습니다. `{ch: w.index(ch) for ch in set(w)}`도 정답입니다. 다만 `index`가 매번 앞에서부터 찾으므로 글자 종류가 많으면 느려집니다. 덮어쓰기 성질을 거꾸로 이용하면 `{ch: i for i, ch in enumerate(w)}`는 **마지막 위치** 표가 됩니다.

</details>

## 084. 라마누잔의 고도 합성수

1915년 라마누잔은 자기보다 작은 어떤 수보다도 약수가 많은 수를 '고도 합성수'라 이름 붙이고 깊이 연구했습니다. 1, 2, 4, 6, 12, 24, 36, 48, 60, 120, …. 시계가 12시간, 원이 360도인 것은 우연이 아닙니다.

**문제** 자연수 n이 주어질 때, 1 이상 n 이하의 수 가운데 약수가 가장 많은 수와 그 약수의 개수를 출력하십시오. 그런 수가 여럿이면 가장 작은 수를 출력합니다. 약수의 개수는 **컴프리헨션**으로 세십시오.

**제한** 1 ≤ n ≤ 1000

**예제 입력 1**

```
10
```

**예제 출력 1**

```
6 4
```

**예제 입력 2**

```
1
```

**예제 출력 2**

```
1 1
```

<details>
<summary>💡 힌트 보기</summary>

`counts = [sum(1 for d in range(1, k + 1) if k % d == 0) for k in range(1, n + 1)]`로 약수 개수 표를 만든 뒤 최댓값과 그 첫 위치를 찾으십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
counts = [sum(1 for d in range(1, k + 1) if k % d == 0) for k in range(1, n + 1)]
best = max(counts)
print(counts.index(best) + 1, best)
```

`sum(1 for … if …)`처럼 대괄호 없이 쓴 것은 **제너레이터 표현식**입니다. 리스트를 메모리에 만들지 않고 값을 하나씩 흘려보냅니다. 1000 이하에서 답은 840(약수 32개)입니다. 840 = 2³ × 3 × 5 × 7처럼 작은 소수를 고루 가진 수가 약수가 많습니다. 이 풀이는 약 50만 번 나눗셈을 합니다. n이 커지면 '각 d의 배수마다 1씩 더하는' 체 방식으로 바꾸면 훨씬 빨라집니다.

</details>

## 085. 서로 다른 합

집합 컴프리헨션 `{…}`은 만들면서 동시에 중복을 없앱니다. '가능한 결과가 몇 가지인가'를 물을 때 가장 먼저 떠올릴 도구입니다.

**문제** 첫째 줄에 N, 둘째 줄에 N개의 정수가 주어집니다. 서로 다른 위치의 두 수를 골라 더해서 만들 수 있는 **서로 다른 합**의 개수를 출력하십시오.

**제한** 1 ≤ N ≤ 300, |각 수| ≤ 10⁶

**예제 입력 1**

```
4
1 2 3 4
```

**예제 출력 1**

```
5
```

**예제 입력 2**

```
3
5 5 5
```

**예제 출력 2**

```
1
```

<details>
<summary>💡 힌트 보기</summary>

`{a[i] + a[j] for i in range(n) for j in range(i + 1, n)}`의 크기를 구하십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
a = list(map(int, input().split()))
print(len({a[i] + a[j] for i in range(n) for j in range(i + 1, n)}))
```

`j`를 `i + 1`부터 시작하게 하면 같은 원소를 두 번 고르는 일도, (i, j)와 (j, i)를 두 번 세는 일도 피할 수 있습니다. 1 2 3 4의 쌍 6개의 합은 3, 4, 5, 5, 6, 7이고 서로 다른 것은 5개입니다. N = 1이면 쌍이 없으므로 빈 집합이 되어 0입니다. `itertools.combinations(a, 2)`를 쓰면 `{x + y for x, y in combinations(a, 2)}`로 더 읽기 좋게 쓸 수 있습니다.

</details>
