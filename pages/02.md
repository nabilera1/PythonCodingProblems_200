## 006. 이름을 부르는 프로그램

`input()`은 프로그램이 사용자의 말을 듣는 귀입니다. 사용자가 엔터를 누를 때까지 기다렸다가, 입력된 한 줄을 문자열로 돌려줍니다.

**문제** 이름 한 줄을 입력받아 `안녕하세요, 이름님!` 형식으로 출력하십시오.

**예제 입력**

```
동균
```

**예제 출력**

```
안녕하세요, 동균님!
```

<details>
<summary>💡 힌트 보기</summary>

f-string 안에 변수를 `{name}`처럼 넣을 수 있습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
name = input()
print(f"안녕하세요, {name}님!")
```

`print("안녕하세요,", name + "님!")`도 같은 결과를 냅니다. 다만 f-string이 더 읽기 쉽고 실수도 적습니다. 채점 환경에서는 `input("이름: ")`처럼 안내 문구를 넣지 마십시오. 안내 문구도 출력으로 취급되어 오답이 됩니다.

</details>

## 007. A + B

수많은 온라인 채점 사이트가 첫 문제로 두 수의 합을 냅니다. 쉬워 보이지만, 한 줄에 공백으로 구분된 여러 값을 읽는 법은 앞으로 200문제 내내 쓰일 기본기입니다.

**문제** 한 줄에 정수 A와 B가 공백으로 구분되어 주어집니다. A + B를 출력하십시오.

**제한** −10¹⁸ ≤ A, B ≤ 10¹⁸

**예제 입력**

```
3 5
```

**예제 출력**

```
8
```

<details>
<summary>💡 힌트 보기</summary>

`input().split()`은 문자열을 공백 기준으로 나눈 리스트를 돌려줍니다. 각 원소에 `int`를 적용하려면 `map`을 쓰십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
a, b = map(int, input().split())
print(a + b)
```

`map(int, ...)`은 각 조각에 `int`를 적용하고, `a, b = ...`는 그 결과를 두 변수에 풀어 담습니다(언패킹). 파이썬 정수는 크기 제한이 없어서 10¹⁸끼리 더해도 C/C++처럼 오버플로가 나지 않습니다.

</details>

## 008. 섭씨와 화씨

1724년 파렌하이트가, 1742년 셀시우스가 각자의 온도 눈금을 내놓았습니다. 두 눈금은 F = C × 9/5 + 32라는 일차식으로 이어집니다.

**문제** 섭씨온도(실수) 하나를 입력받아 화씨온도를 소수점 아래 첫째 자리까지 출력하십시오.

**예제 입력 1**

```
36.5
```

**예제 출력 1**

```
97.7
```

**예제 입력 2**

```
100
```

**예제 출력 2**

```
212.0
```

<details>
<summary>💡 힌트 보기</summary>

`input()`은 언제나 문자열을 줍니다. 실수로 바꾸려면 `float()`를 쓰십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
c = float(input())
print(f"{c * 9 / 5 + 32:.1f}")
```

−40을 넣어 보십시오. 두 눈금이 만나는 유일한 온도입니다. `/`는 언제나 실수(float)를 돌려주고 `//`는 몫(정수 나눗셈)을 돌려준다는 차이도 함께 기억해 두십시오.

</details>

## 009. 세 수의 평균

평균은 자료를 하나의 수로 대표하는 가장 오래된 방법입니다. 다만 나눗셈 결과는 끝없는 소수가 되기 쉬워서 자릿수를 정해 출력해야 합니다.

**문제** 한 줄에 정수 세 개가 주어집니다. 세 수의 평균을 소수점 아래 둘째 자리까지 출력하십시오.

**예제 입력 1**

```
1 2 4
```

**예제 출력 1**

```
2.33
```

**예제 입력 2**

```
90 85 77
```

**예제 출력 2**

```
84.00
```

<details>
<summary>💡 힌트 보기</summary>

`map(int, input().split())`의 결과에 바로 `sum()`을 적용할 수 있습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
nums = list(map(int, input().split()))
print(f"{sum(nums) / len(nums):.2f}")
```

`len(nums)`로 나누면 값이 몇 개든 그대로 쓸 수 있는 코드가 됩니다. `:.2f`는 `84`도 `84.00`으로 보여 주므로, 자릿수를 고정해야 하는 출력에 알맞습니다.

</details>

## 010. 문자열 3과 정수 3

`"3"`과 `3`은 겉모습만 같을 뿐 전혀 다른 존재입니다. 같은 `+` 기호라도 문자열끼리는 이어 붙이고, 정수끼리는 더합니다.

**문제** 두 줄에 걸쳐 정수가 하나씩 주어집니다. 첫째 줄에는 두 입력을 **문자열로 이어 붙인 결과**를, 둘째 줄에는 **정수로 더한 결과**를 출력하십시오.

**예제 입력**

```
3
4
```

**예제 출력**

```
34
7
```

<details>
<summary>💡 힌트 보기</summary>

입력을 문자열 그대로 보관해 두고, 더할 때만 `int()`로 바꾸십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
a = input()
b = input()
print(a + b)
print(int(a) + int(b))
```

`type(a)`를 출력하면 `<class 'str'>`이 나옵니다. 자료형은 값이 무엇이냐뿐 아니라 그 값으로 **무엇을 할 수 있느냐**를 정합니다. `"3" + 4`처럼 섞어 쓰면 `TypeError`가 납니다. 파이썬은 형을 몰래 바꾸지 않는 언어입니다.

</details>
