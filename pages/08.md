## 036. 별의 피라미드

기자의 대피라미드는 아래에서 위로 갈수록 한 단씩 좁아지는 돌의 층으로 이루어져 있습니다. 화면에 별로 피라미드를 쌓으려면 층마다 '공백 몇 개, 별 몇 개'를 정확히 세어야 합니다.

**문제** 자연수 n이 주어질 때 높이 n인 피라미드를 출력하십시오. i번째 줄(1부터)에는 공백 n−i개 뒤에 별 2i−1개가 옵니다.

**제한** 1 ≤ n ≤ 50

**예제 입력**

```
4
```

**예제 출력**

```
   *
  ***
 *****
*******
```

<details>
<summary>💡 힌트 보기</summary>

각 줄에서 공백의 개수와 별의 개수를 i로 나타내 보십시오. 문자열 곱셈을 쓰면 안쪽 반복문 없이도 됩니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
for i in range(1, n + 1):
    print(" " * (n - i) + "*" * (2 * i - 1))
```

이중 `for`로 공백과 별을 한 글자씩 찍어도 되지만, 파이썬에서는 `"*" * k`가 안쪽 반복을 대신합니다. 핵심은 그림을 보고 **i번째 줄의 규칙을 식으로 쓰는 능력**입니다. 연습 삼아 역피라미드나 다이아몬드도 만들어 보십시오.

</details>

## 037. 곱셈표

표를 만드는 일은 컴퓨터의 가장 오래된 쓰임 가운데 하나입니다. 1940년대 초기 컴퓨터들이 맡은 일 중 상당수가 포탄의 궤적표 같은 수표를 계산하는 일이었습니다.

**문제** 자연수 n이 주어질 때 n × n 곱셈표를 출력하십시오. i행 j열에는 i × j가 오며, 각 수는 **폭 4로 오른쪽 정렬**합니다.

**제한** 1 ≤ n ≤ 12

**예제 입력**

```
3
```

**예제 출력**

```
   1   2   3
   2   4   6
   3   6   9
```

<details>
<summary>💡 힌트 보기</summary>

바깥 반복은 행, 안쪽 반복은 열을 맡습니다. 한 행 안에서는 `print(..., end="")`로 줄을 바꾸지 말고 이어 쓰십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
for i in range(1, n + 1):
    for j in range(1, n + 1):
        print(f"{i * j:4d}", end="")
    print()
```

`:4d`는 폭 4칸에 오른쪽 정렬입니다. 안쪽 반복이 끝나면 빈 `print()`로 줄을 바꿉니다. 한 행을 `"".join(f"{i * j:4d}" for j in range(1, n + 1))`처럼 문자열로 만든 뒤 한 번에 출력할 수도 있습니다. 이런 표현은 제17단원 '컴프리헨션'에서 배웁니다.

</details>

## 038. 플림프톤 322

미국 컬럼비아 대학교에 소장된 점토판 '플림프톤 322'는 기원전 1800년 무렵 바빌로니아에서 만들어졌습니다. 이 점토판에는 a² + b² = c²을 만족하는 정수 쌍들이 빼곡히 새겨져 있습니다. 피타고라스보다 천 년 이상 앞선 기록입니다.

**문제** 자연수 n이 주어질 때, a < b < c ≤ n이고 a² + b² = c²인 모든 정수 (a, b, c)를 한 줄에 하나씩 `a b c` 형식으로 출력하십시오. c가 작은 것부터, c가 같으면 a가 작은 것부터 출력합니다. 하나도 없으면 `없음`을 출력합니다.

**제한** 1 ≤ n ≤ 100

**예제 입력 1**

```
13
```

**예제 출력 1**

```
3 4 5
6 8 10
5 12 13
```

**예제 입력 2**

```
4
```

**예제 출력 2**

```
없음
```

<details>
<summary>💡 힌트 보기</summary>

c를 가장 바깥 반복에, a를 그다음에, b를 가장 안쪽에 두면 출력 순서가 저절로 맞습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
found = False
for c in range(1, n + 1):
    for a in range(1, c):
        for b in range(a + 1, c):
            if a * a + b * b == c * c:
                print(a, b, c)
                found = True
if not found:
    print("없음")
```

반복의 **순서**가 곧 출력의 순서가 된다는 점이 이 문제의 핵심입니다. 삼중 반복이지만 n = 100에서 약 16만 번이라 금방 끝납니다. 더 빠르게 하려면 b를 돌리지 말고 `b = math.isqrt(c*c - a*a)`로 계산한 뒤 확인하면 됩니다. 반복이 한 겹 줄어듭니다.

</details>

## 039. 동전 지갑

같은 금액이라도 동전을 고르는 방법은 여러 가지입니다. 경우의 수를 세는 가장 정직한 방법은 가능한 조합을 하나도 빠짐없이 모두 살펴보는 **완전 탐색**입니다.

**문제** 지갑에 500원짜리 A개, 100원짜리 B개, 50원짜리 C개가 있습니다. 이 동전들로 정확히 K원을 만드는 방법의 수를 출력하십시오. 같은 종류의 동전끼리는 구별하지 않습니다.

**제한** 0 ≤ A, B, C ≤ 50, A + B + C ≥ 1, 50 ≤ K ≤ 20000, K는 50의 배수

**예제 입력 1**

```
2 2 2 100
```

**예제 출력 1**

```
2
```

**예제 입력 2**

```
5 1 0 150
```

**예제 출력 2**

```
0
```

<details>
<summary>💡 힌트 보기</summary>

500원을 i개, 100원을 j개, 50원을 k개 쓰는 모든 (i, j, k)를 삼중 반복으로 살펴보십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
a, b, c, k = map(int, input().split())
count = 0
for i in range(a + 1):
    for j in range(b + 1):
        for m in range(c + 1):
            if 500 * i + 100 * j + 50 * m == k:
                count += 1
print(count)
```

각 동전은 0개부터 가진 개수까지 쓸 수 있으므로 `range(a + 1)`입니다. 최악의 경우 51³ ≈ 13만 가지라서 충분히 빠릅니다. 두 가지를 정하면 나머지 하나는 `(k - 500*i - 100*j) / 50`으로 바로 계산할 수 있습니다. 그러면 반복이 한 겹 줄어듭니다. 개수가 커지면 꼭 필요해지는 개선입니다.

</details>

## 040. 양휘의 삼각형

서양에서는 1654년 파스칼의 논문 이후 '파스칼의 삼각형'이라 부르지만, 중국에서는 1261년 양휘의 책에 이미 실려 있어 '양휘 삼각형'이라 부릅니다. 각 수는 바로 위 두 수의 합이고, n번째 줄은 (a + b)ⁿ을 전개한 계수와 같습니다.

**문제** 자연수 n이 주어질 때 파스칼의 삼각형을 n줄 출력하십시오. 각 줄의 수는 공백 하나로 구분합니다.

**제한** 1 ≤ n ≤ 30

**예제 입력**

```
5
```

**예제 출력**

```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

<details>
<summary>💡 힌트 보기</summary>

이전 줄 `row`가 있으면 다음 줄은 양 끝이 1이고, 가운데의 j번째 수는 `row[j-1] + row[j]`입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
row = [1]
for _ in range(n):
    print(*row)
    nxt = [1]
    for j in range(1, len(row)):
        nxt.append(row[j - 1] + row[j])
    nxt.append(1)
    row = nxt
```

반복 변수를 쓰지 않을 때는 관례적으로 `_`로 이름 붙입니다. 바깥 반복은 줄을, 안쪽 반복은 줄 안의 수를 만듭니다. `[1] + [a + b for a, b in zip(row, row[1:])] + [1]`처럼 한 줄로 쓸 수도 있습니다. 각 줄의 합이 2의 거듭제곱(1, 2, 4, 8, …)이라는 점도 확인해 보십시오.

</details>
