## 016. 양수, 음수, 그리고 영

628년 인도의 수학자 브라마굽타는 0을 '어떤 수에서 그 수 자신을 뺀 결과'로 정의하고, 0을 다른 수와 똑같이 셈에 쓰는 규칙을 처음으로 체계화했습니다.

**문제** 정수 하나를 입력받아 양수이면 `양수`, 음수이면 `음수`, 0이면 `영`을 출력하십시오.

**예제 입력 1**

```
5
```

**예제 출력 1**

```
양수
```

**예제 입력 2**

```
0
```

**예제 출력 2**

```
영
```

<details>
<summary>💡 힌트 보기</summary>

`if`, `elif`, `else` 세 갈래로 나누십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
if n > 0:
    print("양수")
elif n < 0:
    print("음수")
else:
    print("영")
```

세 경우가 서로 겹치지 않고 빠짐없이 모든 경우를 덮는지 확인하는 습관이 중요합니다. 마지막 `else`는 앞의 조건이 모두 거짓일 때만 실행되므로, 여기서는 '0일 때'라고 따로 적을 필요가 없습니다.

</details>

## 017. 그레고리력의 윤년

1582년, 교황 그레고리우스 13세는 율리우스력이 천 년 넘게 쌓아 온 열흘의 오차를 바로잡으려고 새 역법을 공포했습니다. 규칙은 간결합니다. **4로 나누어떨어지는 해는 윤년이다. 단, 100으로 나누어떨어지면 평년이고, 다시 400으로 나누어떨어지면 윤년이다.**

**문제** 연도 y를 입력받아 윤년이면 `True`, 아니면 `False`를 출력하십시오.

**예제 입력 1**

```
2024
```

**예제 출력 1**

```
True
```

**예제 입력 2**

```
1900
```

**예제 출력 2**

```
False
```

**예제 입력 3**

```
2000
```

**예제 출력 3**

```
True
```

<details>
<summary>💡 힌트 보기</summary>

세 조건은 `and`와 `or` 하나씩으로 한 줄에 묶을 수 있습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
y = int(input())
print(y % 4 == 0 and (y % 100 != 0 or y % 400 == 0))
```

비교식은 그 자체로 `True` 또는 `False` 값이므로 `if` 문이 필요 없습니다. 괄호를 빼면 `and`가 `or`보다 먼저 계산되어 뜻이 달라지니 주의하십시오. 표준 라이브러리의 `calendar.isleap(y)`도 같은 일을 합니다.

</details>

## 018. 만 나이

2023년 6월 28일부터 우리나라의 법적·사회적 나이는 '만 나이'로 통일되었습니다. 만 나이는 기준일까지 생일을 몇 번 지났는지를 셉니다.

**문제** 첫째 줄에 생년월일, 둘째 줄에 기준일이 `연 월 일` 형식으로 주어집니다. 기준일의 만 나이를 출력하십시오. (생일 당일에 한 살이 늘어납니다.)

**제한** 생년월일 ≤ 기준일, 2월 29일생은 주어지지 않음

**예제 입력 1**

```
2009 3 15
2026 11 22
```

**예제 출력 1**

```
17
```

**예제 입력 2**

```
2008 11 23
2026 11 22
```

**예제 출력 2**

```
17
```

<details>
<summary>💡 힌트 보기</summary>

연도 차에서, 올해 생일이 아직 오지 않았다면 1을 빼면 됩니다. '아직 오지 않았다'는 (월, 일) 두 값을 한꺼번에 비교해서 알아낼 수 있습니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
y1, m1, d1 = map(int, input().split())
y2, m2, d2 = map(int, input().split())
print(y2 - y1 - ((m2, d2) < (m1, d1)))
```

튜플은 **사전식**으로 비교됩니다. 첫 원소를 먼저 비교하고, 같으면 다음 원소로 넘어갑니다. 그래서 `(m2, d2) < (m1, d1)`이 곧 '생일 전'이라는 뜻이 됩니다. 또 `True`와 `False`는 각각 정수 1과 0처럼 셈에 쓸 수 있으므로 `if` 없이 한 줄로 끝납니다.

</details>

## 019. 유클리드의 삼각형

유클리드 『원론』 제1권 명제 20은 '삼각형의 두 변의 합은 나머지 한 변보다 크다'고 말합니다. 세 막대로 삼각형을 만들 수 있는지는 이 한 문장으로 판가름 납니다.

**문제** 세 변의 길이(양의 정수)가 주어집니다. 삼각형을 만들 수 없으면 `불가능`을 출력하십시오. 만들 수 있으면 `정삼각형`, `이등변삼각형`, `직각삼각형`, `일반삼각형` 중 **앞에 있는 것부터 먼저** 따져서 해당하는 이름을 출력하십시오.

**제한** 1 ≤ 각 변 ≤ 1000, 변의 순서는 임의

**예제 입력 1**

```
3 4 5
```

**예제 출력 1**

```
직각삼각형
```

**예제 입력 2**

```
1 2 3
```

**예제 출력 2**

```
불가능
```

<details>
<summary>💡 힌트 보기</summary>

먼저 정렬해서 가장 긴 변을 c로 정해 두면, 모든 조건이 간단해집니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
a, b, c = sorted(map(int, input().split()))
if a + b <= c:
    print("불가능")
elif a == c:
    print("정삼각형")
elif a == b or b == c:
    print("이등변삼각형")
elif a * a + b * b == c * c:
    print("직각삼각형")
else:
    print("일반삼각형")
```

정렬하면 a ≤ b ≤ c이므로 '두 변의 합 > 나머지 변' 세 가지는 `a + b > c` 하나로 줄어듭니다. 정삼각형 판정도 `a == c` 하나면 됩니다. 1 2 3처럼 합이 같은 경우는 납작한 선분이 될 뿐 삼각형이 아니라는 점에 유의하십시오. 덧붙여, 세 변이 정수이면 직각이등변삼각형은 생기지 않습니다(√2가 무리수이기 때문입니다).

</details>

## 020. 뉴턴의 프리즘

1666년 무렵, 젊은 뉴턴은 어두운 방의 작은 구멍으로 들어온 햇빛을 프리즘에 통과시켜 흰빛이 여러 색으로 갈라지는 것을 관찰했습니다. 오늘날 우리는 빛의 색을 파장으로 설명합니다.

**문제** 빛의 파장(nm, 정수)이 주어질 때 아래 표에 따라 색 이름을 출력하십시오. 어느 구간에도 속하지 않으면 `가시광선 아님`을 출력합니다.

| 구간 | 색 |
|---|---|
| 380 이상 450 미만 | 보라 |
| 450 이상 495 미만 | 파랑 |
| 495 이상 570 미만 | 초록 |
| 570 이상 590 미만 | 노랑 |
| 590 이상 620 미만 | 주황 |
| 620 이상 750 미만 | 빨강 |

**예제 입력 1**

```
700
```

**예제 출력 1**

```
빨강
```

**예제 입력 2**

```
450
```

**예제 출력 2**

```
파랑
```

<details>
<summary>💡 힌트 보기</summary>

`380 <= w < 450`처럼 연쇄 비교를 쓰면 수학 표기 그대로 적을 수 있습니다. 구간이 차례로 이어져 있으니 `elif`에서는 위쪽 경계만 비교해도 됩니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
w = int(input())
if w < 380 or w >= 750:
    print("가시광선 아님")
elif w < 450:
    print("보라")
elif w < 495:
    print("파랑")
elif w < 570:
    print("초록")
elif w < 590:
    print("노랑")
elif w < 620:
    print("주황")
else:
    print("빨강")
```

범위를 벗어난 경우를 먼저 걸러 내면 나머지 `elif`들은 위쪽 경계만 보면 됩니다. 앞의 조건이 거짓이라는 사실이 아래쪽 경계를 보장해 주기 때문입니다. 구간이 많아지면 `bisect` 모듈로 `colors[bisect.bisect_right([450, 495, 570, 590, 620], w)]`처럼 표를 찾는 방식이 더 우아합니다. 제2부에서 다시 다룹니다.

</details>
