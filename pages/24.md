## 116. 지뢰 찾기

1990년대 초 윈도우와 함께 퍼진 지뢰 찾기의 숫자는 그 칸을 둘러싼 8칸에 숨은 지뢰의 수입니다. 격자에서 '이웃 세기'는 113번 생명 게임과 같은 기술입니다.

**문제** 첫째 줄에 R과 C, 이어서 R줄에 `*`(지뢰)와 `.`(빈칸)으로 된 격자가 주어집니다. 지뢰 칸은 `*`로 두고, 빈칸은 주변 8칸의 지뢰 수(0~8)로 바꾸어 출력하십시오.

**제한** 1 ≤ R, C ≤ 100

**예제 입력**

```
3 4
*...
..*.
....
```

**예제 출력**

```
*211
12*1
0111
```

<details>
<summary>💡 힌트 보기</summary>

격자 바깥쪽에 빈칸 한 겹을 덧대면(패딩) 경계 검사를 하지 않아도 됩니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
r, c = map(int, input().split())
g = [input() for _ in range(r)]
out = []
for i in range(r):
    row = []
    for j in range(c):
        if g[i][j] == "*":
            row.append("*")
        else:
            row.append(str(sum(g[x][y] == "*" for x in range(max(0, i - 1), min(r, i + 2))
                               for y in range(max(0, j - 1), min(c, j + 2)))))
    out.append("".join(row))
print("\n".join(out))
```

`range(max(0, i - 1), min(r, i + 2))`는 격자 안에 있는 이웃 행만 고릅니다. 빈칸 자신은 지뢰가 아니므로 3×3 영역 전체를 세도 결과가 같습니다. 그래서 '자기 자신 빼기'를 따로 하지 않았습니다. 가장자리를 매번 검사하는 대신 격자 둘레에 `.`을 한 겹 둘러 (R+2)×(C+2)로 만들면 코드가 더 단순해집니다. 이 **패딩** 기법은 격자 문제에서 자주 쓰입니다.

</details>

## 117. 행렬 회전

스마트폰을 옆으로 돌리면 화면의 이미지가 90° 회전합니다. 이미지는 결국 화소의 2차원 배열이므로, 회전도 행렬의 원소를 옮기는 일입니다.

**문제** 첫째 줄에 n, 이어서 n×n 행렬이 주어집니다. 행렬을 **시계 방향으로 90°** 회전한 결과를 출력하십시오.

**제한** 1 ≤ n ≤ 100

**예제 입력**

```
3
1 2 3
4 5 6
7 8 9
```

**예제 출력**

```
7 4 1
8 5 2
9 6 3
```

<details>
<summary>💡 힌트 보기</summary>

시계 방향 90° 회전은 '위아래 뒤집기 → 전치'와 같습니다. 82번의 `zip(*m)`을 떠올려 보십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
m = [input().split() for _ in range(n)]
for row in zip(*m[::-1]):
    print(*row)
```

원래 (i, j)의 원소는 회전 후 (j, n−1−i)로 갑니다. 이 식을 직접 써도 되지만, 기하 변환을 '뒤집기'와 '전치'의 합성으로 보면 한 줄이 됩니다. 반시계 방향은 `zip(*m)` 뒤에 위아래를 뒤집으면 되고(`list(zip(*m))[::-1]`), 180°는 행 순서와 각 행을 모두 뒤집으면 됩니다.

</details>

## 118. 빙고

빙고는 18세기 이탈리아의 복권 놀이에서 유래했다고 알려져 있습니다. 5×5 판에서 가로, 세로, 대각선 줄을 먼저 채우는 사람이 이깁니다.

**문제** 첫째 줄에 목표 줄 수 K, 이어서 5줄에 빙고판(1~25의 서로 다른 수), 그다음 5줄에 사회자가 부르는 수 25개가 차례로 주어집니다. 완성된 줄(가로 5, 세로 5, 대각선 2 가운데)이 **처음으로 K개 이상**이 되는 것은 몇 번째 수를 불렀을 때인지 출력하십시오.

**제한** 1 ≤ K ≤ 12

**예제 입력**

```
2
5 12 7 6 24
22 3 9 2 1
20 19 10 15 13
16 14 18 8 25
21 23 17 11 4
4 23 1 16 24
14 18 8 10 5
15 21 2 6 19
3 17 25 20 12
9 13 7 11 22
```

**예제 출력**

```
16
```

<details>
<summary>💡 힌트 보기</summary>

수 → (행, 열) 위치를 딕셔너리에 담아 두면, 부를 때마다 위치를 바로 찾을 수 있습니다. 표시한 뒤 완성된 줄 수를 다시 세십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
k = int(input())
board = [list(map(int, input().split())) for _ in range(5)]
pos = {board[i][j]: (i, j) for i in range(5) for j in range(5)}
marked = [[False] * 5 for _ in range(5)]
calls = [x for _ in range(5) for x in map(int, input().split())]

def lines():
    cnt = sum(all(row) for row in marked)
    cnt += sum(all(marked[i][j] for i in range(5)) for j in range(5))
    cnt += all(marked[i][i] for i in range(5))
    cnt += all(marked[i][4 - i] for i in range(5))
    return cnt

for t, x in enumerate(calls, 1):
    i, j = pos[x]
    marked[i][j] = True
    if lines() >= k:
        print(t)
        break
```

`all()`은 모든 칸이 참일 때만 참이고, 참은 1로 더해지므로 완성된 줄의 수를 바로 셀 수 있습니다. 부를 때마다 12줄을 전부 다시 세어도 25 × 12 × 5번이라 충분히 빠릅니다. 판이 크다면 줄마다 '표시된 칸 수'를 저장해 두고 해당 줄만 갱신하는 방식이 필요합니다. 25개를 모두 부르면 12줄이 모두 완성되므로 언제나 답이 존재합니다.

</details>

## 119. 가장 비옥한 땅

2차원 누적합 표가 있으면 어떤 직사각형 영역의 합이든 덧셈과 뺄셈 네 번으로 구할 수 있습니다. 컴퓨터 비전에서는 이를 '적분 영상(integral image)'이라 부르며, 2001년 비올라와 존스의 실시간 얼굴 검출 알고리즘의 핵심이 되었습니다.

**문제** 첫째 줄에 n과 k, 이어서 n×n 격자의 비옥도(정수)가 주어집니다. k×k 정사각형 영역 가운데 비옥도 합이 가장 큰 영역의 합을 출력하십시오.

**제한** 1 ≤ k ≤ n ≤ 300, |비옥도| ≤ 1000

**예제 입력 1**

```
3 2
1 2 3
4 5 6
7 8 9
```

**예제 출력 1**

```
28
```

**예제 입력 2**

```
2 1
-5 -2
-3 -4
```

**예제 출력 2**

```
-2
```

<details>
<summary>💡 힌트 보기</summary>

S[i][j] = (0,0)부터 (i−1, j−1)까지의 합으로 정의하면, S[i][j] = a[i−1][j−1] + S[i−1][j] + S[i][j−1] − S[i−1][j−1]입니다. 영역의 합은 '큰 직사각형 − 위 − 왼쪽 + 겹친 부분'입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
input = sys.stdin.readline
n, k = map(int, input().split())
S = [[0] * (n + 1) for _ in range(n + 1)]
for i in range(1, n + 1):
    row = list(map(int, input().split()))
    acc = 0
    for j in range(1, n + 1):
        acc += row[j - 1]
        S[i][j] = S[i - 1][j] + acc
best = max(S[i][j] - S[i - k][j] - S[i][j - k] + S[i - k][j - k]
           for i in range(k, n + 1) for j in range(k, n + 1))
print(best)
```

영역마다 k² 칸을 더하면 최악의 경우 수십억 번이지만, 누적합을 쓰면 영역 하나에 연산 네 번입니다. 54번의 1차원 누적합을 2차원으로 확장한 것입니다. 행 안의 누적합 `acc`에 바로 위 행의 누적합을 더하는 방식으로 계산하면, 포함·배제 공식을 따로 쓰지 않고도 표를 만들 수 있습니다. 예제 2처럼 모든 값이 음수일 수 있으므로 최댓값의 초깃값을 0으로 두면 틀립니다. `max()`에 모든 후보를 넘긴 것은 그 함정을 피하기 위해서입니다.

</details>

## 120. 오른쪽과 아래로만

바둑판 같은 도시에서 오른쪽과 아래쪽으로만 걸어 목적지까지 가는 길의 수는 조합론의 고전입니다. 장애물이 없으면 이항계수 하나로 답이 나오지만, 막힌 칸이 섞이면 칸마다 차근차근 세어야 합니다. 이것이 **동적 계획법**의 첫 모습입니다.

**문제** 첫째 줄에 R과 C, 이어서 R줄에 `.`(빈칸)과 `#`(막힌 칸)으로 된 격자가 주어집니다. 왼쪽 위에서 오른쪽 아래까지 오른쪽 또는 아래로만 한 칸씩 움직여 가는 경로의 수를 1,000,000,007로 나눈 나머지를 출력하십시오.

**제한** 1 ≤ R, C ≤ 500

**예제 입력 1**

```
3 3
...
.#.
...
```

**예제 출력 1**

```
2
```

**예제 입력 2**

```
2 2
.#
#.
```

**예제 출력 2**

```
0
```

<details>
<summary>💡 힌트 보기</summary>

어떤 칸에 이르는 경로의 수 = 위 칸에 이르는 경로의 수 + 왼쪽 칸에 이르는 경로의 수입니다(막힌 칸은 0). 왼쪽 위 칸은 1에서 시작합니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
input = sys.stdin.readline
MOD = 1_000_000_007
r, c = map(int, input().split())
g = [input().rstrip() for _ in range(r)]
ways = [0] * c
for i in range(r):
    for j in range(c):
        if g[i][j] == "#":
            ways[j] = 0
        elif i == 0 and j == 0:
            ways[j] = 1
        elif j > 0:
            ways[j] = (ways[j] + ways[j - 1]) % MOD
print(ways[c - 1])
```

2차원 표 대신 1차원 리스트 하나만 썼습니다. `ways[j]`에는 갱신 직전까지 **위 칸**의 값이 들어 있고, `ways[j - 1]`에는 이미 이번 행의 **왼쪽 칸** 값이 들어 있기 때문입니다. 이런 메모리 절약 기법을 '슬라이딩 배열'이라 합니다. 장애물이 없는 500×500 격자의 경로 수는 C(998, 499)로, 약 300자리의 수입니다. 파이썬은 큰 정수를 다룰 수 있지만, 매번 나머지를 취하는 것이 훨씬 빠르고 대회의 표준 관례이기도 합니다.

</details>
