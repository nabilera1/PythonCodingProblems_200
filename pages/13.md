## 061. 벤 다이어그램

1880년 영국의 논리학자 존 벤은 집합 사이의 관계를 겹친 원으로 그리는 방법을 널리 알렸습니다. 파이썬의 집합은 `&`(교집합), `|`(합집합), `-`(차집합) 연산자로 이 그림을 그대로 계산합니다.

**문제** 두 줄에 걸쳐 집합 A와 B의 원소(정수)들이 주어집니다. 같은 수가 여러 번 나올 수 있지만 집합에서는 한 번으로 칩니다. |A ∩ B|, |A ∪ B|, |A − B|를 공백으로 구분해 출력하십시오.

**제한** 각 줄에 1개 이상 1000개 이하의 정수

**예제 입력 1**

```
1 2 3 4
3 4 5
```

**예제 출력 1**

```
2 5 2
```

**예제 입력 2**

```
1 1 1
1
```

**예제 출력 2**

```
1 1 0
```

<details>
<summary>💡 힌트 보기</summary>

`set(map(int, input().split()))`로 집합을 만든 뒤 `&`, `|`, `-` 연산자를 쓰십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
a = set(map(int, input().split()))
b = set(map(int, input().split()))
print(len(a & b), len(a | b), len(a - b))
```

집합은 원소가 '있느냐 없느냐'만 기억합니다. 순서도 개수도 기억하지 않습니다. 대신 `x in s` 검사가 원소 수와 관계없이 매우 빠릅니다. 리스트의 `in`은 처음부터 끝까지 훑어야 하는 것과 대조적입니다. 대칭차집합 `a ^ b`(둘 중 한쪽에만 있는 원소)도 있습니다. 포함·배제의 원리 |A ∪ B| = |A| + |B| − |A ∩ B|가 성립하는지 확인해 보십시오.

</details>

## 062. 처음 겹친 수

해시(hash)는 데이터에서 짧은 지문을 뽑아 '전에 본 적이 있는가'를 순식간에 답하게 해 줍니다. 파이썬의 집합과 딕셔너리는 해시 테이블로 만들어져 있습니다.

**문제** 첫째 줄에 N, 둘째 줄에 N개의 정수가 주어집니다. 앞에서부터 읽어 갈 때 **이미 앞에서 나온 적이 있는 값**을 처음 만나면 그 값을 출력하십시오. 끝까지 그런 값이 없으면 `없음`을 출력합니다.

**제한** 1 ≤ N ≤ 10⁵, |각 수| ≤ 10⁹

**예제 입력 1**

```
6
3 1 4 1 5 3
```

**예제 출력 1**

```
1
```

**예제 입력 2**

```
3
1 2 3
```

**예제 출력 2**

```
없음
```

<details>
<summary>💡 힌트 보기</summary>

지금까지 본 값들을 집합 `seen`에 넣어 두면서, 새 값이 `seen`에 이미 있는지 검사하십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
seen = set()
answer = "없음"
for x in map(int, input().split()):
    if x in seen:
        answer = x
        break
    seen.add(x)
print(answer)
```

`seen`을 리스트로 만들면 `in` 검사 한 번에 최대 N번 비교하므로 전체가 N²번, 곧 100억 번이 됩니다. 집합으로 바꾸기만 해도 거의 즉시 끝납니다. **자료구조의 선택이 곧 알고리즘의 속도**라는 것을 체감할 수 있는 문제입니다. 숨은 테스트에는 10만 개짜리 입력이 들어 있습니다.

</details>

## 063. 셰익스피어의 어휘

학자들은 셰익스피어의 작품 전체에 서로 다른 단어가 3만 개 가까이 쓰였다고 추정합니다. 텍스트에 서로 다른 단어가 몇 개 쓰였는지를 세는 일은 문체 연구의 출발점입니다.

**문제** 영어 문장 한 줄이 주어질 때 **서로 다른 단어**의 개수를 출력하십시오. 대소문자는 구별하지 않으며, 단어 앞뒤에 붙은 문장부호 `.,!?;:'"`는 떼어 내고 셉니다.

**예제 입력**

```
To be, or not to be: that is the question.
```

**예제 출력**

```
8
```

<details>
<summary>💡 힌트 보기</summary>

각 단어에 `.lower()`와 `.strip(".,!?;:'\"")`를 적용한 뒤 집합에 넣으십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
words = set()
for w in input().split():
    words.add(w.strip(".,!?;:'\"").lower())
print(len(words))
```

`strip(문자들)`은 양 끝에서 주어진 문자들을 모두 벗겨 냅니다. 가운데 있는 문자는 건드리지 않으므로 `don't`의 작은따옴표는 남습니다. 'To be, or not to be: that is the question.'에는 단어가 10개 있지만 to와 be가 두 번씩 나오므로 서로 다른 단어는 8개입니다. 제17단원에서는 이 코드를 `len({w.strip(...).lower() for w in input().split()})` 한 줄로 줄이는 법을 배웁니다.

</details>

## 064. 별자리 지도

2차원 좌표는 `(x, y)` 튜플로 나타내는 것이 자연스럽습니다. 튜플은 앞 원소부터 비교되므로 정렬하면 x 순서로, x가 같으면 y 순서로 저절로 정리됩니다.

**문제** 첫째 줄에 점의 수 N, 이어서 N줄에 `x y`가 주어집니다. 점들을 x가 작은 순서로, x가 같으면 y가 작은 순서로 정렬해 한 줄에 하나씩 출력하십시오.

**제한** 1 ≤ N ≤ 10⁵, |x|, |y| ≤ 10⁵

**예제 입력**

```
5
3 4
1 1
1 -1
2 2
3 3
```

**예제 출력**

```
1 -1
1 1
2 2
3 3
3 4
```

<details>
<summary>💡 힌트 보기</summary>

각 점을 `(x, y)` 튜플로 리스트에 담고 `sort()` 하면 끝입니다. 줄이 많으므로 출력은 `"\n".join(...)`으로 한 번에 하십시오.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
input = sys.stdin.readline
n = int(input())
points = [tuple(map(int, input().split())) for _ in range(n)]
points.sort()
print("\n".join(f"{x} {y}" for x, y in points))
```

입력과 출력이 10만 줄이 되면 `input()`과 `print()`를 반복해서 부르는 비용이 커집니다. `sys.stdin.readline`으로 읽고 결과를 모아 한 번에 출력하는 것은 제3부의 필수 습관이니 여기서 미리 익혀 두십시오. 튜플은 **변경할 수 없는(immutable)** 리스트라고 생각하면 됩니다. 바로 그 성질 덕분에 집합의 원소나 딕셔너리의 키로 쓸 수 있습니다. 리스트는 그럴 수 없습니다.

</details>

## 065. 생일 역설

한 반에 23명만 모여도 생일이 같은 두 사람이 있을 확률이 50%를 넘습니다. 직관과 너무 달라 '생일 역설'이라 불립니다. 비교해야 할 **쌍**의 수가 23 × 22 ÷ 2 = 253개나 되기 때문입니다.

**문제** 첫째 줄에 사람 수 N, 이어서 N줄에 생일이 `월 일` 형식으로 주어집니다. 생일이 같은 두 사람이 있으면 `있음`, 없으면 `없음`을 출력하십시오.

**제한** 1 ≤ N ≤ 400

**예제 입력 1**

```
3
3 15
12 25
3 15
```

**예제 출력 1**

```
있음
```

**예제 입력 2**

```
2
1 1
11 1
```

**예제 출력 2**

```
없음
```

<details>
<summary>💡 힌트 보기</summary>

생일을 `(월, 일)` 튜플로 만들어 집합에 넣으십시오. 집합의 크기가 사람 수보다 작아졌다면 무슨 뜻일까요?

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
n = int(input())
birthdays = {tuple(map(int, input().split())) for _ in range(n)}
print("있음" if len(birthdays) < n else "없음")
```

집합은 중복을 하나로 합치므로 크기가 줄었다면 겹친 생일이 있다는 뜻입니다. 생일은 366가지뿐이므로 367명이 모이면 반드시 겹칩니다. 이것이 **비둘기집 원리**입니다. 튜플을 집합에 넣을 수 있다는 점이 핵심입니다. `[3, 15]` 같은 리스트는 변경할 수 있어서 해시를 만들 수 없기 때문에 집합에 넣을 수 없습니다.

</details>
