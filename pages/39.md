## 191. 펜윅 트리

1994년 피터 펜윅이 발표한 이 자료구조는 '갱신'과 '구간 합'을 모두 O(log N)에 처리합니다. 핵심은 `i & -i`, 곧 i의 가장 낮은 1비트입니다. 배열 칸마다 이 비트의 크기만큼의 구간 합을 맡깁니다.

**문제** 길이 N의 수열에 Q개의 명령을 처리하십시오. `1 i v`는 i번째 원소를 v로 **바꾸고**, `2 l r`은 l~r번째 원소의 합을 출력합니다.

**입력** 첫째 줄에 N과 Q, 둘째 줄에 N개의 정수, 이어서 Q줄에 명령이 주어집니다.

**출력** `2` 명령마다 한 줄에 답을 출력합니다.

**제한** 1 ≤ N, Q ≤ 10⁵, |원소|, |v| ≤ 10⁹, 시간 제한 3초

**예제 입력**

```
5 4
1 2 3 4 5
2 2 4
1 3 10
2 1 5
2 3 3
```

**예제 출력**

```
9
22
10
```

<details>
<summary>💡 힌트 보기</summary>

'바꾸기'는 '차이만큼 더하기'로 처리합니다. 현재 값 배열을 따로 두고 delta = v − a[i]를 트리에 더하십시오. 합은 prefix(r) − prefix(l−1)입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
data = sys.stdin.buffer.read().split()
n, q = int(data[0]), int(data[1])
a = [0] + list(map(int, data[2:2 + n]))
tree = a[:]
for i in range(1, n + 1):
    j = i + (i & -i)
    if j <= n:
        tree[j] += tree[i]

def prefix(i):
    s = 0
    while i > 0:
        s += tree[i]
        i -= i & -i
    return s

out = []
idx = 2 + n
for _ in range(q):
    op, x, y = data[idx], int(data[idx + 1]), int(data[idx + 2])
    idx += 3
    if op == b'1':
        delta = y - a[x]
        a[x] = y
        while x <= n:
            tree[x] += delta
            x += x & -x
    else:
        out.append(prefix(y) - prefix(x - 1))
print('\n'.join(map(str, out)))
```

트리를 처음 만들 때 원소마다 N번 갱신하면 O(N log N)이지만, 위처럼 '자기 값을 책임 구간의 부모(i + (i & −i))에 넘기는' 방식으로 O(N)에 만들 수 있습니다. `i & -i`는 2의 보수 표현 덕분에 i의 가장 낮은 1비트만 남깁니다. 예를 들어 12(1100₂)에서는 4(100₂)입니다. 펜윅 트리는 이 비트 연산 하나로 트리 구조를 배열 안에 숨겨 둔 우아한 설계입니다. 명령이 '더하기'가 아니라 '바꾸기'라는 점이 함정입니다. 원래 값을 기억해 두지 않으면 차이를 구할 수 없습니다.

</details>

## 192. 구간 최솟값

합과 달리 최솟값은 '빼기'로 되돌릴 수 없어서 펜윅 트리로는 구간 최솟값을 구하기 어렵습니다. **세그먼트 트리**는 구간을 반씩 나눈 이진 트리의 각 마디에 그 구간의 답을 저장해, 어떤 구간이든 O(log N)개의 마디로 덮어 답합니다.

**문제** 길이 N의 수열에 Q개의 명령을 처리하십시오. `1 i v`는 i번째 원소를 v로 바꾸고, `2 l r`은 l~r번째 원소의 최솟값을 출력합니다.

**입력** 첫째 줄에 N과 Q, 둘째 줄에 N개의 정수, 이어서 Q줄에 명령이 주어집니다.

**출력** `2` 명령마다 한 줄에 답을 출력합니다.

**제한** 1 ≤ N, Q ≤ 10⁵, |원소|, |v| ≤ 10⁹, 시간 제한 3초

**예제 입력**

```
6 4
5 2 8 6 3 7
2 1 3
2 4 6
1 2 9
2 1 3
```

**예제 출력**

```
2
3
5
```

<details>
<summary>💡 힌트 보기</summary>

크기 2N의 배열에서 잎을 N~2N−1에 두고, 부모 i는 자식 2i와 2i+1의 최솟값을 갖게 하십시오(바텀업 세그먼트 트리). 질의는 양 끝에서 안쪽으로 올라가며 처리합니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
data = sys.stdin.buffer.read().split()
n, q = int(data[0]), int(data[1])
t = [0] * n + list(map(int, data[2:2 + n]))
for i in range(n - 1, 0, -1):
    t[i] = t[2 * i] if t[2 * i] < t[2 * i + 1] else t[2 * i + 1]
out = []
idx = 2 + n
for _ in range(q):
    op, x, y = data[idx], int(data[idx + 1]), int(data[idx + 2])
    idx += 3
    if op == b'1':
        i = x - 1 + n
        t[i] = y
        i >>= 1
        while i:
            t[i] = t[2 * i] if t[2 * i] < t[2 * i + 1] else t[2 * i + 1]
            i >>= 1
    else:
        l, r = x - 1 + n, y + n
        res = 1 << 62
        while l < r:
            if l & 1:
                if t[l] < res: res = t[l]
                l += 1
            if r & 1:
                r -= 1
                if t[r] < res: res = t[r]
            l >>= 1
            r >>= 1
        out.append(res)
print('\n'.join(map(str, out)))
```

바텀업 세그먼트 트리는 재귀 없이 배열 하나로 구현되어 파이썬에서 특히 빠릅니다. 질의에서 l이 오른쪽 자식(홀수)이면 그 마디는 부모로 올라가면 구간 밖이 섞이므로 지금 답에 반영하고 오른쪽으로 한 칸 옮깁니다. r도 대칭으로 처리합니다. N이 2의 거듭제곱이 아니어도 이 방식은 올바르게 동작합니다(아주 우아한 사실이니 작은 예로 확인해 보십시오). 최솟값 자리에 최댓값, 최대공약수, 행렬 곱 같은 **결합 법칙이 성립하는 연산**이면 무엇이든 넣을 수 있습니다. 세그먼트 트리가 만능 도구라 불리는 이유입니다.

</details>

## 193. K번째 사탕

사탕 상자에서 맛있는 순위로 K번째 사탕을 꺼내야 합니다. 사탕은 계속 들어오고 나갑니다. 맛 등급별 개수를 펜윅 트리에 담아 두면, '앞에서부터 개수를 더해 K에 처음 이르는 등급'을 트리를 **위에서 아래로 내려가며** O(log N)에 찾을 수 있습니다.

**문제** 빈 상자에 Q개의 명령을 처리하십시오. `1 x`는 맛 등급 x인 사탕을 하나 넣고, `2 x`는 맛 등급 x인 사탕을 하나 꺼내며(반드시 있음), `3 k`는 등급이 낮은 쪽부터 k번째 사탕의 등급을 출력하고 그 사탕을 꺼냅니다(k번째 사탕은 반드시 있음).

**입력** 첫째 줄에 Q, 이어서 Q줄에 명령이 주어집니다.

**출력** `3` 명령마다 한 줄에 답을 출력합니다.

**제한** 1 ≤ Q ≤ 10⁵, 1 ≤ x ≤ 10⁶, 시간 제한 3초

**예제 입력**

```
6
1 5
1 3
1 5
3 2
2 3
3 1
```

**예제 출력**

```
5
5
```

<details>
<summary>💡 힌트 보기</summary>

펜윅 트리의 '이분 내려가기': pos = 0에서 시작해 step = 2^19, 2^18, …에 대해 tree[pos + step] < k이면 k에서 빼고 pos를 늘리십시오. 끝나면 pos + 1이 k번째 등급입니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
data = sys.stdin.buffer.read().split()
q = int(data[0])
N = 1 << 20
tree = [0] * (N + 1)

def add(i, v):
    while i <= N:
        tree[i] += v
        i += i & -i

out = []
idx = 1
for _ in range(q):
    op, x = data[idx], int(data[idx + 1])
    idx += 2
    if op == b'1':
        add(x, 1)
    elif op == b'2':
        add(x, -1)
    else:
        pos, k, step = 0, x, N
        while step:
            if pos + step <= N and tree[pos + step] < k:
                pos += step
                k -= tree[pos]
            step >>= 1
        out.append(pos + 1)
        add(pos + 1, -1)
print('\n'.join(map(str, out)))
```

누적합으로 이분 탐색하면 O(log² N)이지만, 펜윅 트리의 구조를 따라 큰 단계부터 내려가면 O(log N)입니다. tree[pos + step]이 정확히 (pos, pos + step] 구간의 합이기 때문에 가능한 일입니다. 값의 범위(10⁶)만큼 배열을 잡았습니다. 값이 10⁹처럼 크다면 121번의 좌표 압축을 먼저 해야 합니다(질의를 미리 모두 읽어야 하므로 '오프라인' 처리가 됩니다). 검증용 풀이는 정렬된 리스트에 직접 넣고 빼는 방식입니다. 작은 입력에서는 이것이 가장 믿을 만한 기준입니다.

</details>

## 194. 구간 더하기, 구간 합

구간에 더하고 구간의 합을 묻는 문제는 보통 '느리게 전파되는(lazy)' 세그먼트 트리로 풉니다. 하지만 펜윅 트리 **두 개**를 쓰는 대수적 요령이 있습니다. 코드가 훨씬 짧고 파이썬에서도 빠릅니다.

**문제** 길이 N의 수열에 Q개의 명령을 처리하십시오. `1 l r v`는 l~r번째 원소에 모두 v를 더하고, `2 l r`은 l~r번째 원소의 합을 출력합니다.

**입력** 첫째 줄에 N과 Q, 둘째 줄에 N개의 정수, 이어서 Q줄에 명령이 주어집니다.

**출력** `2` 명령마다 한 줄에 답을 출력합니다.

**제한** 1 ≤ N, Q ≤ 10⁵, |원소|, |v| ≤ 10⁶, 시간 제한 3초

**예제 입력**

```
5 4
1 2 3 4 5
1 2 4 10
2 1 5
1 1 1 -1
2 1 2
```

**예제 출력**

```
45
12
```

<details>
<summary>💡 힌트 보기</summary>

155번의 차분 배열 D를 펜윅 트리에 담으면 원소값은 prefix(D)입니다. 앞의 i개 원소의 합은 Σ D[j]·(i − j + 1) = (i + 1)·ΣD[j] − Σ j·D[j]이므로, D와 j·D를 각각 펜윅 트리로 관리하면 됩니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
data = sys.stdin.buffer.read().split()
n, q = int(data[0]), int(data[1])
base = [0] * (n + 1)
for i in range(n):
    base[i + 1] = base[i] + int(data[2 + i])
B1 = [0] * (n + 2)
B2 = [0] * (n + 2)

def add(t, i, v):
    while i <= n:
        t[i] += v
        i += i & -i

def query(t, i):
    s = 0
    while i > 0:
        s += t[i]
        i -= i & -i
    return s

def prefix(i):
    return base[i] + (i + 1) * query(B1, i) - query(B2, i)

out = []
idx = 2 + n
for _ in range(q):
    if data[idx] == b'1':
        l, r, v = int(data[idx + 1]), int(data[idx + 2]), int(data[idx + 3])
        idx += 4
        add(B1, l, v); add(B1, r + 1, -v)
        add(B2, l, v * l); add(B2, r + 1, -v * (r + 1))
    else:
        l, r = int(data[idx + 1]), int(data[idx + 2])
        idx += 3
        out.append(prefix(r) - prefix(l - 1))
print('\n'.join(map(str, out)))
```

식 Σ_{j≤i} D[j]·(i − j + 1)에서 i에 의존하는 부분과 j에 의존하는 부분을 분리하는 것이 요령의 전부입니다. 수식 한 줄의 변형이 자료구조 하나를 대신하는 아름다운 예입니다. 초기 수열의 누적합(`base`)은 따로 두고 갱신분만 트리에 넣었습니다. `add(B1, r + 1, …)`에서 r + 1이 N + 1이 될 수 있는데, 반복 조건 `i <= n` 덕분에 아무 일도 일어나지 않습니다. 범위 갱신 + 범위 최솟값처럼 이런 대수적 분리가 불가능한 연산에는 lazy 세그먼트 트리가 필요합니다.

</details>

## 195. 구간의 서로 다른 수

질의를 받는 순서대로 답할 필요가 없다면, 질의를 **오른쪽 끝 순서로 정렬**해 처리하는 길이 열립니다. 오른쪽으로 나아가며 각 값의 '가장 최근 위치'에만 1을 표시해 두면, 구간 [l, r]의 서로 다른 수의 개수는 그 구간에 있는 1의 개수가 됩니다.

**문제** 길이 N의 수열과 Q개의 질의 `l r`이 주어집니다. 각 질의마다 l~r번째 원소 가운데 서로 다른 값의 개수를 출력하십시오.

**입력** 첫째 줄에 N, 둘째 줄에 N개의 정수, 셋째 줄에 Q, 이어서 Q줄에 l과 r이 주어집니다.

**출력** 질의마다 한 줄에 답을 입력 순서대로 출력합니다.

**제한** 1 ≤ N, Q ≤ 10⁵, 1 ≤ 원소 ≤ 10⁹, 시간 제한 3초

**예제 입력**

```
6
1 2 1 3 2 1
4
1 3
2 5
1 6
4 4
```

**예제 출력**

```
2
3
3
1
```

<details>
<summary>💡 힌트 보기</summary>

질의를 r 순으로 정렬합니다. 위치 i를 처리할 때 값 a[i]가 전에 위치 p에 나왔다면 p의 1을 지우고 i에 1을 표시하십시오(펜윅 트리). r = i인 질의들은 sum(l..r)로 답합니다.

</details>

<details>
<summary>✅ 정답과 해설 보기</summary>

```python
import sys
data = sys.stdin.buffer.read().split()
n = int(data[0])
a = data[1:1 + n]
q = int(data[1 + n])
qs = sorted((int(data[3 + n + 2 * k]), int(data[2 + n + 2 * k]), k) for k in range(q))
tree = [0] * (n + 1)

def add(i, v):
    while i <= n:
        tree[i] += v
        i += i & -i

def pre(i):
    s = 0
    while i > 0:
        s += tree[i]
        i -= i & -i
    return s

last = {}
ans = [0] * q
qi = 0
for i in range(1, n + 1):
    x = a[i - 1]
    if x in last:
        add(last[x], -1)
    last[x] = i
    add(i, 1)
    while qi < q and qs[qi][0] == i:
        r, l, k = qs[qi]
        ans[k] = pre(r) - pre(l - 1)
        qi += 1
print('\n'.join(map(str, ans)))
```

오른쪽 끝이 r로 고정된 상태에서는 각 값을 가장 최근 위치에서만 세면 됩니다. 구간 [l, r]에 그 값이 있다면 가장 최근 위치도 반드시 그 안에 있기 때문입니다. 이 관찰이 '서로 다른 값 세기'를 '1의 개수 세기'로 바꿉니다. 답을 입력 순서대로 출력해야 하므로 질의마다 원래 번호 k를 함께 정렬하고, 답을 `ans[k]`에 넣었습니다. **오프라인 질의 처리**의 기본 형태입니다. 온라인으로(질의가 오는 즉시) 답해야 한다면 퍼시스턴트 세그먼트 트리 같은 더 무거운 도구가 필요합니다.

</details>
