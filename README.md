# 구글 계정 하나로 시작하는 파이썬 200제

구글 계정 하나로, 설치 없이, 브라우저에서 바로 푸는 파이썬 200문제.
기초 100제 · 응용 50제 · 정보올림피아드(KOI 고등부 수준) 50제로 이루어져 있으며, 모든 문제는 Google Colab에서 자동 채점됩니다.

안녕하세요. 정보 교사 김동균입니다.

코딩 테스트 문제를 처음 풀다 보면, 문제는 이해했는데 첫 줄을 어떻게 써야 할지 막막할 때가 있습니다. 예제는 잘 나오는데 제출하면 틀렸다는 메시지가 뜨기도 하지요. 그럴 때는 잠시 코드를 내려놓고 작은 예시를 손으로 풀어 보세요. 내가 어떤 순서로 답을 찾았는지 적어 보면, 그 순서가 알고리즘의 출발점이 됩니다.

대학 시절 프로그래밍 경시대회(ACM-ICPC)에 참가한 경험이 프로그래밍을 이해하는데 큰 도움이 되었습니다. 교사가 된 뒤에는 교실과 여러 대회에서 학생들이 문제를 푸는 과정을 함께했습니다. 학생이 막혔을 때 제가 자주 건네는 질문이 있습니다. “지금까지 알아낸 것부터 이야기해 볼까요?” 문제에서 주어진 조건을 하나씩 짚다 보면, 어디까지 이해했고 어디서부터 다시 생각해야 할지 선명해집니다. 『실전! 파이썬 알고리즘 코딩 테스트 200제』를 읽는 동안에도 제가 옆에서 그 질문을 건네는 교사였으면 합니다.

한 문제를 펼치면 먼저 무엇이 주어지고 무엇을 구해야 하는지 자기 말로 한 문장씩 적어 보세요. 작은 입력으로 답을 직접 구한 뒤, 그 과정을 파이썬 코드로 옮겨 봅니다. 제출 결과가 예상과 다르면 입력이 하나뿐이거나 같은 값이 반복되는 경우처럼 놓치기 쉬운 예를 만들어 보세요. 해설을 읽은 뒤에는 책을 잠시 덮고 풀이를 다시 적어 보세요. 마지막으로 “왜 이 방법으로 답을 구할 수 있을까?”를 자기 말로 설명해 보면, 비슷한 문제를 만났을 때 그 풀이를 다시 떠올리기 쉬워집니다.

하루에 한 문제를 풀어도 좋고, 어제 막혔던 한 문제를 다시 펼쳐도 좋습니다. 저도 해마다 새로운 목표를 세우고 도전하면서 실수하고, 다시 배웁니다. 며칠 전에는 손도 대기 어려웠던 문제에서 오늘은 첫 줄을 쓸 수 있게 되는 순간이 있습니다. 공부하는 동안 그런 작은 기쁨을 자주 만나셨으면 합니다.
